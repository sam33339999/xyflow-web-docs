[React Flow Playground](https://play.reactflow.dev/) 被創建來讓您可以試驗屬性，並分享流程及其節點、邊緣和設定。在左側，您可以找到一個側邊欄來調整傳遞給 `<ReactFlow />` 元件和每個節點的屬性。在右側，您可以看到產生的流程。您可以平移和縮放流程、選擇節點並互動式地調整它們。您可以建立設定的唯一連結，以便與他人分享。

### 互動式調整 `<ReactFlow />` 屬性

React Flow Playground 允許您互動式地調整傳遞給主要 `<ReactFlow />` 元件的屬性。當您將滑鼠懸停在屬性上時，您會看到一個包含說明的提示，當您調整其值時，流程會更新。您可以實驗與流程外觀和互動行為相關的每個設定選項：顏色主題、鍵盤快捷鍵、選擇模式、縮放、平移等等。

### 節點與邊緣編輯器

當您在 React Flow playground 中選擇一個節點時，您將能夠互動式地檢查它。您將能夠變更節點的位置、大小、控制點的數量和位置等等。您還可以載入和儲存自訂節點資料集、試驗巢狀節點階層，以及修改節點的互動行為。

### 佈局演算法

React Flow Playground 允許您在瀏覽器中試用不同的圖形佈局程式庫，然後再在您的專案中使用它們。您可以試用 Dagre、ElkJS 和 D3 Hierarchy：當您選擇一個佈局程式庫時，您將能夠在側邊欄中設定佈局演算法的參數，例如流程中節點的方向、對齊和間距。就像 playground 中的屬性編輯器一樣，當您將滑鼠懸停在參數上時，您會看到一個包含說明的提示，當您調整任何參數時，您會看到流程即時更新。

### 分享流程

所以您已經找到了 React Flow 應用程式的完美設定，想與他人分享？您將能夠建立流程的可分享連結，並與您的朋友和同事分享。
