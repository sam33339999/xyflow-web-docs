## 等等，什麼是 Svelte Flow？

對於剛接觸 Svelte Flow 的人，它是一個用於建立基於節點的應用程式的 Svelte 函式庫，例如工作流程編輯器、資料管道或視覺化程式設計環境。只需幾行程式碼，你就能獲得一個具有縮放、平移、連接節點等功能的互動式流程圖。

```svelte filename="App.svelte"
<script>
  import { SvelteFlow, Background, Controls, Minimap } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([
    {
      id: '1',
      type: 'input',
      position: { x: 0, y: 0 },
      data: { label: 'Hello' },
    },
    {
      id: '2',
      type: 'output',
      position: { x: 100, y: 100 },
      data: { label: 'World' },
    },
  ]);

  let edges = $state.raw([
    { id: '1-2', source: '1', target: '2', type: 'smoothstep', label: 'to the' },
  ]);
</script>

<SvelteFlow bind:nodes bind:edges fitView>
  <Background />
  <Controls />
  <Minimap />
</SvelteFlow>
```

# 新功能和改進

我們第一個主要版本的目標之一是縮小 Svelte Flow 和 React Flow 之間最後剩餘的差距。對我們來說，這也標誌著我們承諾同步開發這兩個函式庫的新功能。所以請持續關注未來的版本！👀

- **[重新連接連線](https://svelteflow.dev/examples/edges/reconnect-edge)**：你可以使用新的 `<EdgeReconnectAnchor />` 元件重新連接連線。它可以用來在自訂連線上添加自訂重新連接點。
- **鍵盤導航與無障礙**：我們新增了鍵盤導航支援並改進了螢幕閱讀器的無障礙功能。現在你可以使用方向鍵瀏覽節點和連線。
- **點擊連接**：現在你可以透過逐一點擊控制點來建立新連接。
- **[增強的 ViewportPortal](https://svelteflow.dev/api-reference/components/viewport-portal)**：我們新增了一個新的 `<ViewportPortal />` 元件，讓你可以在流程圖的視口中渲染內容。這對於渲染自訂覆蓋層或提示框很有用。
- **改進的 [fitView](https://svelteflow.dev/api-reference/hooks/use-svelte-flow#fitview)**：我們微調了 `fitView` 函數，使其更好地處理動態新增的節點。
- 以及無數其他小改進...

# 擁抱 runes

為了創建一個穩定的未來 API，我們完全擁抱 signals，將所有 [stores](https://svelte.dev/docs/svelte/stores) 轉換為 [runes](https://svelte.dev/docs/svelte/what-are-runes)。在某些情況下，這就像將 `writable` 替換為 `$state` 一樣簡單。在其他情況下，這需要我們重新思考整體架構。然而，經過大量的修改、效能測試和無數個夢見 runes 的不眠之夜後，我們成功簡化了函式庫的許多部分，甚至讓它更高效。

特別感謝 Svelte 團隊在 Svelte 5 候選版本動盪時期的幫助！修復通常在幾個[小時](https://github.com/sveltejs/svelte/issues/12652)內完成，有時甚至在幾[分鐘](https://github.com/sveltejs/svelte/issues/12302)內！？
