# React Flow 目前狀態

不久前，我們將套件名稱從 `reactflow` 重新命名為 `@xyflow/react`，以便在新的「xyflow」品牌傘下統一我們的專案。自那次變更以來，我們發布了多次更新，目前已經到達版本 **12.4.4**！如您在下方所見，我們的新套件下載量幾乎已經與舊的 `reactflow` 套件持平，這令人鼓舞。

# React Flow 元件與模板

去年年底，我們推出了 [React Flow Components](https://reactflow.dev/components)：一套即用型元件，您可以輕鬆整合到您的節點式編輯器或工作流程應用程式中。這些元件建構在 [shadcn/ui](https://ui.shadcn.com/) 之上。基於這些元件，我們還發布了第一個模板——[工作流程編輯器 UI 模板](https://reactflow.dev/components/templates/workflow-editor)，具有自動佈局、拖放側邊欄、深色模式和簡化的工作流程邏輯。這是一個 Pro 模板，可透過我們的[入門訂閱](https://reactflow.dev/pro)取得。

# Svelte Flow 與 Svelte 5

隨著幾個月前 Svelte 5 的發布，我們（特別是 Peter 🤙）努力跟上所有變更。一月份，我們發布了基於 Svelte 5 建構的 Svelte Flow 1.0 alpha 版本。您可以透過以下方式安裝並試用：`npm install @xyflow/svelte`。

我們必須進行許多調整和重寫，但 Svelte 5 簡化了維護工作，讓我們移除了大量程式碼。由於 Svelte Flow 目前還沒有商業模式，我們無法像 React Flow 那樣快速工作，但我們希望在可能的情況下跟上所有新功能，並希望能在未來幾個月內發布穩定的 Svelte Flow 1.0 版本。如果您想開始使用 Svelte Flow 1.0 alpha，可以查看[遷移指南](https://next.svelteflow.dev/learn/troubleshooting/migrate-to-v1)或[下一版本的網站](https://next.svelteflow.dev/)。

# 文件

除了我們的程式庫，我們的網站是產品的核心。最近，我們遷移到 Next.js App Router 和 [nextra 4](https://nextra.site/)——非常感謝 [Dima](https://github.com/dimaMachina) 的幫助！Abbey 也修訂了所有範例，現在所有內容都以漂亮、乾淨的主題呈現。

我們也在探索將 Pro 平台整合到文件中，為訂閱者提供單一、統一的體驗。此外，我們正在努力直接從程式碼庫生成 API 參考文件。為此，我們已經將所有描述和範例移到原始碼中，這大大改善了開發體驗 :)
