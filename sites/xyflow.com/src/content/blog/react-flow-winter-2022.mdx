嘿！我們想在我們把自己裹在毯子裡冬眠到新年之前分享一個更新（我們將從今天到 1 月 2 日關閉筆電 ⛄）。讓我們來看看過去幾個月發生的事情、即將到來的內容，以及我們現在感到興奮的事情。

## 使用 v11.4.0 小版本發布，像你最喜歡的設計工具一樣平移、縮放和選擇 💫

在[最新的小版本發布](https://github.com/xyflow/xyflow/releases/tag/11.4.0)中，你終於可以配置控制項，使其表現得像 Figma、Miro 或 Sketch 一樣。這包括點擊拖曳來進行選擇、[按住空白鍵進行平移和滾動縮放](https://reactflow.dev/learn/concepts/the-viewport)。你還可以配置如果節點完全在選擇區域內/部分在選擇區域內是否被選中。

## 新的輔助元件：超越節點和連線

在我們對使用 React Flow 的應用程式進行研究時，我們注意到很多人在 React Flow 之上自訂建立許多類似的元素（或使用第三方函式庫）。為了幫助解決這個問題，我們開始建立輔助元件，包括[邊緣標籤](https://reactflow.dev/api-reference/components/edge-label-renderer)、[節點調整大小](https://reactflow.dev/api-reference/components/node-resizer)、[工具列和提示框](https://reactflow.dev/api-reference/components/node-toolbar)。我們正在小心謹慎地進行這項工作，以確保我們不會損害核心函式庫的低階簡潔性，同時確保 React Flow 包含建立基於節點的應用程式所需的所有元件。

我們希望繼續沿著這條路走下去，這意味著與你們中的一些人交談（是的，研究！）關於你正在使用 React Flow 建立的應用程式，以及我們如何支援你建立它們。

## 更多新範例！

**[交集](https://reactflow.dev/examples/nodes/intersections/)**：此範例使用新的[交集輔助函數](https://reactflow.dev/api-reference/types/react-flow-instance/#isnodeintersecting)來檢測節點是否與另一個節點相交。

  width={476}

**[調整大小和旋轉](https://reactflow.dev/examples/nodes/resize-rotate)：**這曾經是一個 Pro 範例，但我們決定將原始碼提供給我們公開文件中的所有人，以避免人們在使用第三方調整大小函式庫時遇到的問題。我們還重構了程式碼以使用新的[調整大小元件](https://reactflow.dev/api-reference/components/node-resizer)。

**[動態分組](https://reactflow.dev/examples/nodes/dynamic-grouping)**（Pro 範例 💎）：輕鬆分組節點！透過從抽屜拖曳節點或使用「分組節點」按鈕來建立新分組或將節點新增到現有分組。
