今天我們很高興推出 Svelte Flow！🎉⚡️ Svelte Flow 是一個用於創建工作流程建構器、資料庫視覺化工具、資料處理工具，以及任何你能想像到的螢幕上節點應用的函式庫。

使用 `npm install @xyflow/svelte` 試試看，或查看 [Github 儲存庫](https://github.com/xyflow/xyflow)。Svelte Flow 採用 MIT 授權，由創建和維護 [React Flow](https://reactflow.dev/) 的團隊從頭開始建立。

🕹 **開箱即用的互動性：**拖曳節點、縮放、平移、選擇多個節點，以及新增/移除連線都已內建。

💅🏻 **易於自訂：**Svelte Flow 節點是易於自訂的元件，可以隨心所欲地調整和修改。Svelte Flow 專注於應用程式的 UI 和畫布，你負責提供資料和版面配置函式庫。

🔌 **內建元件：**Background、Minimap、Controls 和 Panel 元件在安裝後即可使用。

## 只需幾行程式碼即可開始執行

安裝 `@xyflow/svelte` 後，將以下內容複製貼上到你的專案中以開始使用 Hello World。

```jsx
<script lang="ts">
  import { writable } from 'svelte/store';
  import {
    SvelteFlow,
    Controls,
    Background,
    MiniMap,
  } from '@xyflow/svelte';

  import '@xyflow/svelte/dist/style.css'

  const nodes = writable([
    {
      id: '1',
      data: { label: 'Hello' },
      position: { x: 0, y: 0 }
    },
    {
      id: '2',
      data: { label: 'World' },
      position: { x: 100, y: 100 }
    }
  ]);

  const edges = writable([
    {
      id: '1-2',
      source: '1',
      target: '2',
    }
  ]);
</script>

<SvelteFlow {nodes} {edges} fitView>
  <Controls />
  <Background />
  <MiniMap />
</SvelteFlow>
```

## 誰建立了 Svelte Flow？

我們是 xyflow 團隊\*，React Flow 和 Svelte Flow 的創造者。自 2019 年以來，我們一直在維護 React Flow 函式庫及其生態系統。今年初，我們受到 Svelte 社群的啟發，創建了一個原型，展示如果用 Svelte 建立我們的工具會是什麼樣子。這讓我們將 React Flow 的核心抽象為 vanilla js 並將函式庫移植到 Svelte，同時改進了兩個函式庫的效能。

現在 Svelte Flow 已經推出，我們很興奮看到 Svelte 社群如何使用這個函式庫，並準備好持續改進它並解決你在使用過程中發現的任何錯誤。
