## 推出 v11 及發布後的維護工作

React Flow v11 在十月初上線了（太棒了！<Emoji content="🎉" />），如果您還沒看過，Moritz 寫了一篇[完整的部落格文章](https://reactflow.dev/blog/react-flow-v11/)介紹它。

發布後，我們花了幾週時間整理目前的結構。我們修復了 v11 中無障礙功能更新的一些問題（感謝一些很棒的使用者回饋 <Emoji content="💕" />），新增了 `nodesFocusable` 和 `edgesFocusable` 屬性以使鍵盤處理更易於設定，並花了一些時間為年底重新聚焦。（向 Supabase 的[發布後週](https://github.com/supabase/supabase/releases/tag/0.22.09)致敬。）

慢慢地但確實地，大家開始使用我們的新套件名稱。`react-flow-renderer` 已經過時，`reactflow` 萬歲！（數據來自 [npm trends](https://npmtrends.com/react-flow-renderer-vs-reactflow)）

## 接下來是什麼？

隨著我們進入冬季，我們正在思考如何結束今年，以及 2023 年將帶來什麼。我們最近問自己的一些大問題是：

- 我們如何幫助開發者改善他們流程的使用者體驗？（也許是主題、樣式指南，或分享更多自訂樣式？）
- 為 React Flow 社群提供更多回饋和討論的機會
- 更公開地展示和講述我們在 React Flow 做什麼以及如何做
