我們很高興宣布，我們剛剛將 Pro 平台開源！🚀 Pro 平台是 React Flow Pro 訂閱者可以存取和檢視「[Pro 範例](https://reactflow.dev/pro/examples)」、管理訂閱以及讓團隊成員存取平台的地方。我們希望有些人看一看，為他們自己的專案獲得靈感，並且我們的 Pro 訂閱者喜歡我們建立的新功能 💫

查看 [Github 儲存庫](https://github.com/xyflow/pro-platform)或透過[在 Pro 平台上註冊](https://pro.reactflow.dev)來現場試用。

### 為什麼要開源它？

我們相信開源是製作東西的更好方式 - 資訊自由、問責制、從使用者那裡收集貢獻和錯誤回報的簡單方式、讓其他人做得更好等等。我們也喜歡[開源維護者為他們的工作獲得報酬](https://www.xyflow.com/blog/asking-for-money-for-open-source)，我們可以想像其他人在他們自己的開源專案周圍使用我們的 Pro 平台（作為 [Ghost](https://ghost.org/) 或 [Patreon](https://www.patreon.com/) 等程式碼導向的替代方案）。當然，我們距離那還很遠，但開源它並讓人們窺探內部是一個開始的方式。

### 更新的 Pro 範例 💫

我們所有的 Pro 範例現在都是獨立的 Vite 應用程式。這使它們更容易運行，也更容易讓我們開發。

We noticed that [Dagre](https://github.com/dagrejs/dagre) no longer has the “deprecated” tag! Our [Workflow Builder](https://reactflow.dev/examples/layout/workflow-builder-starter) and [Expand / Collapse](https://reactflow.dev/examples/layout/expand-collapse) Pro Examples have been rebuilt with dagre, so that you can switch between the d3 and dagre versions.

形狀 Pro 範例已重構，現在包括拖放形狀節點、調整大小、顏色選擇器、深色模式和更新的迷你地圖等功能。在接下來的幾個月裡，我們計劃重構其他一些範例，所以請留意這些更新。

### 底層改進 🏎

在新平台中，我們已遷移到最新的 Nextjs 版本（使用 app router），用 TailwindCSS 和我們自己的 UI 套件取代了 ChakraUI，並將所有內容從 JS 轉換為 TypeScript。

當我們去年建立 Pro 平台時，它的開發方式使得 Pro 範例（不是開源的）與託管它們的平台無法分離。Pro 範例程式碼現在位於一個私有儲存庫中，與平台的儲存庫分開。
