# React Flow：更少的錯誤、改進的效能 🧼

過去幾個月的最新版本帶來了：

- 新的 [`nodeDragThreshold` prop](https://reactflow.dev/api-reference/react-flow/#nodedragthreshold) 來延遲節點拖曳事件 [11.9.0](https://github.com/xyflow/xyflow/blob/main/packages/reactflow/CHANGELOG.md)
- 與 Astro、Remix 以及較舊的設定（如 webpack4 和 React 17）相容 [11.9.0](https://github.com/xyflow/xyflow/blob/main/packages/reactflow/CHANGELOG.md)
- 改進帶有小地圖的大型圖表效能 [#3153](https://github.com/xyflow/xyflow/pull/3153)
- 為 Windows 使用者提供更好的按鍵預設值和滾動行為 [11.8.0](https://github.com/xyflow/xyflow/blob/main/packages/reactflow/CHANGELOG.md#1180)
- 更好的預設連線路徑和標籤位置 [11.8.0](https://github.com/xyflow/xyflow/blob/main/packages/reactflow/CHANGELOG.md)

而且，非常非常多的錯誤已經被修復了。舊錯誤、新錯誤。我們感覺像是剛發現蟻丘的 6 歲小孩。要查看完整清單，請見我們的[變更日誌](https://github.com/xyflow/xyflow/blob/main/packages/reactflow/CHANGELOG.md)。

Hayleigh 一直在努力重構我們的文件，在經過幾年的有機成長後，這些文件非常需要一些關注和整理。你將在我們網站重新設計的發布中看到這些更新（繼續閱讀以了解更多）。

# Svelte Flow Alpha 上線了！🎉

對於眼尖的人，你可能已經注意到 react-flow 儲存庫中有一個 xyflow 分支，那是因為我們已經將 React Flow 移植到 Svelte，現在你可以安裝並試用它了！！🚀

```bash npm2yarn
npm install @xyflow/svelte
```

你可以查看我們的 [Github Readme](https://github.com/xyflow/xyflow/tree/xyflow/packages/svelte#svelte-flow-alpha)，並在我們創建 Svelte Flow 文件時參考我們的 React Flow 文件。因為我們還在 alpha 階段，API 可能會改變。

對我們最大的幫助是，如果你能與任何使用 Svelte 的人分享，或者如果你自己使用 Svelte，試用它並提交你遇到的錯誤或問題（我們的 [Discord](https://discord.gg/TmAJQbwWDM) 是討論的好地方）- 我們預計會有很多 😄

已經有一個 Svelte Flow Alpha 應用程式在實際應用中了！https://ffmpeg.lav.io/

一如既往，它採用 MIT 授權。

### Svelte Flow 的計劃是什麼？

就像 React Flow 一樣，我們預計在推出後的幾週和幾個月內會聽到很多錯誤和功能請求，我們將關注這些並盡可能回應所有請求。目前，我們希望人們試用它、建立東西，我們會敞開耳朵和收件匣接收回饋。最重要的是，我們期待看到人們建立什麼！

推出 Svelte Flow 也意味著我們要維護兩個函式庫而不是一個。如你所見，我們的團隊已經擴大了一點來幫助我們完成這項工作。

在建立 Svelte Flow 的過程中，還有一個額外的收穫是我們將 React Flow 核心泛化為 vanilla JS，讓我們能夠重構和清理函式庫的基礎。這可能讓我們在未來更容易將函式庫移植到其他語言。

一旦 Svelte Flow 開始成形，我們很快意識到「React Flow」是一個不夠靈活的名稱。想像一下「npm install reactflow/svelte」😬😬

「xyflow」很快將成為 React Flow 和 Svelte Flow 的共同屋頂。我們喜歡「xy」可以代表一個變數（「xy」可以替換為「react」或「svelte」來創建個別函式庫的名稱），以及圖表的 xy 座標。至於如何發音...呃...我們會再回覆你。

因此套件名稱會有所改變，我們將在「正式」推出所有這些時提供明確的更改說明。
