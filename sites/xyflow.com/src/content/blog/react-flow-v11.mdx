自從我們六個月前發布上一篇部落格文章以來，發生了很多事情。我們獲得了第一批 pro 訂閱者，我們聘請了 John 協助我們處理文件、溝通和社群事務，而且我們現在都全職投入 React Flow 了 <Emoji content="🥳" />。今天我們發布了一個新的主要版本，帶來許多新功能和極少的破壞性變更（與上次主要更新不同...）。

**如果你正在尋找如何升級的資訊，請參考[「遷移到 v11」指南](https://reactflow.dev/learn/troubleshooting/migrate-to-v11/)。**

#### 重點整理；

- React Flow 有一個新的套件名稱 -> `reactflow`
- 預設更好的無障礙功能（鍵盤控制、aria- 預設值）
- 更清晰的 smoothstep 和 step 連線路徑
- 更好的可選擇連線，新的 `interactionWidth` 選項
- 新的 hooks：`useNodesInitialized`、`useOnViewportChange` 和 `useOnSelectionChange`

## <Emoji content="🎉" /> 新的套件名稱

最大的變化是我們獲得了一個新的套件名稱！一位非常好的人給了我們 [`reactflow` npm 套件](https://www.npmjs.com/reactflow)名稱，我們也獲得了 [`@reactflow` 組織](https://www.npmjs.com/org/reactflow)。所以從現在開始，你可以透過以下方式安裝 React Flow：

```bash npm2yarn
npm install reactflow
```

然後像以前一樣使用它：

```jsx
import { ReactFlow,  Controls, Background } from '@xyflow/react';
import '@xyflow/react/dist/style.css';

...

<ReactFlow nodes={nodes} edges={edges}>
  <Controls />
  <Background />
</ReactFlow>
```

看起來不錯，對吧？在底層，我們在 `@reactflow` 組織中單獨發布套件。這些套件由主要的 `reactflow` 套件使用，也可以[單獨使用](https://reactflow.dev/learn/concepts/packages/)。為此，我們將 React Flow 重建為由 [Turborepo](https://turborepo.org/)、[Rollup](https://rollupjs.org/) 和 [Vite](https://vitejs.dev/) 提供支援的 monorepo。

## <Emoji content="✨" /> 新功能

對於這次發布，我們專注於無障礙功能（沒有什麼比 a11y 更適合 v11 發布了！）和連線，以及一些其他較小的更新和穩定性修復。

### 無障礙功能

在之前的版本中，無障礙功能相當有限，我們投入了大量工作使其預設更好。現在你可以使用鍵盤與流程圖互動。你可以使用 `Tab` 聚焦節點和連線，使用 `Enter` 選擇元素，並使用方向鍵移動節點。

此外，我們為畫布上的所有元素添加了預設的 aria-labels，並使用新的 `ariaLabel` 選項讓節點和連線可以配置。你可以參考新的[無障礙指南](https://reactflow.dev/learn/advanced-use/accessibility)了解更多資訊。

### 連線路徑和連線選擇

在 v10 中，節點稍微更受關注，這次我們特別關注連線。很多人抱怨細連線很難選擇。我們透過引入新的 [`interactionWidth` 連線選項](https://reactflow.dev/api-reference/types/edge)來解決這個問題。它的預設值是 20，意味著在可見連線下方繪製了一條 20px 寬的不可見連線，以便更容易互動。

另一個重大更新是完全重寫了 `smoothstep` 和 `step` 連線類型的連線路徑。

這還不是全部。我們還修訂了連線[更新行為](https://twitter.com/reactflowdev/status/1564966917517021184)，為 `default` 和 `smoothstep` 連線添加了 [`pathOptions`](https://reactflow.dev/api-reference/types/edge)，以及一個新的 `deletable` 標記。為了讓開發自訂連線更容易，我們導出了一個 [`<BaseEdge />` 元件](https://reactflow.dev/api-reference/components/base-edge)，它可以為你繪製不可見的輔助連線和標籤。

### 節點定位

為了讓版面配置更容易，我們添加了一個名為 [`nodeOrigin`](https://reactflow.dev/api-reference/react-flow) 的新 prop。原點始終在左上角，這意味著你需要減去一半的寬度和高度來居中節點。現在你可以設置 `nodeOrigin={[0.5, 0.5]}` 將原點設置為中心，或 `nodeOrigin={[1, 1]}` 將其設置為右下角。

此外，我們實現了一個 [`useNodesInitialized` hook](https://reactflow.dev/api-reference/hooks/use-nodes-initialized)。它返回一個布林值，可用於確定所有節點是否已初始化，例如是否應該進行新的版面配置。另一個小變化是，當節點不可拖曳時，你可以在節點上平移，這使得導航更大的流程圖更容易。

### 新的 Hooks

未來我們希望擺脫一些 `<ReactFlow />` 元件 props（有 140+ 個 <Emoji content="😵‍💫" />）。一個想法是透過 hooks 替換一些 props。在這次發布中，我們添加了 [`useOnViewportChange`](https://reactflow.dev/api-reference/hooks/use-on-viewport-change) 和 [`useOnSelectionChange`](https://reactflow.dev/api-reference/hooks/use-on-selection-change) hook。在此版本之前，你只能透過使用 `onMoveStart`、`onMove` 和 `onMoveEnd` 來監聽視口變化。使用新的 `useOnViewportChange` hook，你可以輕鬆地在每個元件中監聽變化。

### 其他

背景獲得了[新的變體 `cross`](https://reactflow.dev/api-reference/components/background/#prop-types)，你可以為所有變體單獨控制水平和垂直的間隙大小。我們添加了新的處理程序，使向畫布（節點下方的區域）添加滑鼠事件處理程序更容易：[`onPaneMouseEnter`、`onPaneMouseMove` 和 `onPaneMouseLeave`](https://reactflow.dev/api-reference/react-flow/#pane)。最後但同樣重要的是，在拖曳畫布或節點時游標是抓取手勢，當節點不可拖曳時你可以在節點上平移。奇怪的是這不是一直都是這樣？！

## 接下來是什麼？

React Flow 不僅僅是函式庫。它是帶有文件和範例的網站、pro 平台以及 Github 和 Discord 上的社群！在接下來的幾週和幾個月裡，我們希望讓開發者，特別是初學者開發者的上手更容易。為此，我們正在製作深入的入門指南和更容易理解的文件。我們還在重新整理 pro 平台，以便你可以從 pro 範例中獲得更多。
