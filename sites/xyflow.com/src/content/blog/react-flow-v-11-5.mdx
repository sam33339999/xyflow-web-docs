又見面了！我非常興奮能分享 React Flow 的最新改進。新的自動平移功能和連接半徑讓連接節點和處理更大的流程圖變得更容易。除此之外，我們還改進了觸控裝置的可用性。

## 自動平移

在使用 Blender 幾何節點工作一段時間後，我知道我想添加這個功能。每當你將節點、選擇框或連線線拖到畫布邊框時，它會自動朝那個方向平移。這讓使用者可以在不需要滾動的情況下連接節點，並更輕鬆地組織節點。如果你不喜歡它，可以使用 [`autoPanOnConnect={false}`](https://reactflow.dev/api-reference/react-flow#autopanonconnect-1) 和 [`autoPanOnNodeDrag={false}`](https://reactflow.dev/api-reference/react-flow/#autopanonnodedrag-1) 停用這個新功能。

## 連接半徑

有[幾種](https://reactflow.dev/examples/nodes/easy-connect/)[方式](https://reactflow.dev/examples/nodes/proximity-connect/)來連接節點。內建的方式是從一個控制點拖曳連線線到另一個控制點。為了讓這更容易，我們添加了 [`connectionRadius` prop](https://reactflow.dev/api-reference/react-flow/#connectionradius-1)。連接半徑指定控制點周圍的半徑，你可以在該範圍內放下連線線。不再需要將它直接放在控制點上方 <Emoji content="🙌" />。

## 錯誤處理

我們添加了一個新的 [`onError`](https://reactflow.dev/api-reference/react-flow/#onerror-1) 處理程序，你可以使用它在發生錯誤時收到通知。如果你想記錄錯誤或向使用者顯示通知，這會很有用。

## 觸控支援

自 v10 以來，我們透過點擊連接支援觸控裝置上的連接。從現在開始，你也可以在觸控裝置上拖曳連線線，就像使用滑鼠一樣。當然，自動平移和連接半徑功能也適用於觸控裝置！

## 節點類型（僅限 TS）

我們擴展了泛型 `Node` 類型，現在你可以透過向 `Node` 傳遞第二個參數來指定 `type`。

```ts
type MyCustomNode = Node<MyCustomNodeData, 'custom-node-type'>;
```

這讓你可以創建更具體的節點類型，這些類型知道它們的 `data` 結構和 `type`。

# <Emoji content="👉" /> Node Resizer 2.0 <Emoji content="👈" />

我們還發布了 [`@reactflow/node-resizer` 套件](https://reactflow.dev/api-reference/components/node-resizer)的新主要版本。現在你可以傳遞一個 `shouldResize` 處理程序來取消調整大小事件。此外，我們為 `onResize` 和 `shouldResize` 的調整大小參數添加了一個 `direction` 屬性。
