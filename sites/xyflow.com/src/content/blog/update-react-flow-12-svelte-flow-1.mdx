鳥兒又開始鳴叫了──等等不對，在下雪。等等不對。我已經搞不清楚了，但距離上次我們跟大家分享團隊近況確實已經有一段時間了。讓我們來看看 React Flow 12、Svelte 5 中的 Svelte Flow 1.0.0、2023 年終使用者調查、可編輯連線，以及探索我們團隊的工作節奏。

## React Flow 12 🪁

今年初，我們邀請大家試用 React Flow 12 的測試版本並回報任何發現的錯誤，非常感謝那些勇敢的靈魂 🙏🏻。我們花時間處理了所有問題，確保準備好發布穩定版本。

這次發布的重點項目包括：

1. **支援 SSG/ SSR**：現在可以在伺服器端渲染流程圖（[範例](https://codesandbox.io/p/devbox/reactflow-v12-next-3xlx3n?workspaceId=25a0577d-5515-44d9-bab2-59b9181e01e3)）
2. **計算流程**：新的 hooks 和輔助函數來簡化資料流程（[範例](https://codesandbox.io/p/sandbox/reactflow-reactive-flow-34lk98?file=/src/Flow.tsx)）
3. **深色模式**：新的基礎樣式和輕鬆切換內建顏色模式的方法（[範例](https://codesandbox.io/p/sandbox/reactflow-dark-mode-256l99)）

[完整功能清單請見此處](https://github.com/xyflow/xyflow/discussions/3764)

很多人問「什麼時候發布？」，我們最好的答案是「快了！！」讓這個版本問世是我們目前最優先的工作，我們會給它所需的時間。我們非常期待將這個版本發布到世界上。

## 為 Svelte 5 重寫 Svelte Flow 🚚

Svelte 5 在去年九月發布，我們一直密切關注這個版本！我們喜歡所看到的內容，例如 props 的預設值，這對我們作為函式庫維護者很有幫助。我們決定 1.0.0 候選版本將使用 Svelte 5 編寫（Svelte Flow 0.0.x 將繼續提供給想要堅持使用 Svelte 4 的使用者），敬請期待。

## 2023 年終調查 ✅

我們在去年底向 React Flow 使用者發送了一份調查，收到了 82 份回覆（謝謝大家！！）。我們團隊檢視了調查結果，並將它們整合成可分享的報告。這些發現已經幫助我們在年初朝正確的方向前進。

以下是調查結果的搶先看：

- API 參考是我們文件中最常使用的部分
- 版面配置、狀態管理、「智慧」連線和效能是使用者遇到的一些最大困難/需求
- 四分之一的人表示在使用 React Flow 遇到問題時會使用 ChatGPT 尋求協助
