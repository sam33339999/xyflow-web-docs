大約兩年前，我們[開源了 React Flow](https://webkid.io/blog/react-flow-node-based-graph-library/)，這是為我們基於流程的資料處理工具 [Datablocks](https://datablocks.pro) 建立的。從那時起，我們在 React Flow 上投入了越來越多的時間，它獲得了很大的吸引力（每月 25k+ 網站訪客、Github 上 9k+ 顆星、1k+ Discord 成員、npm 上每週 100k+ 下載量）。
我們對 React Flow 周圍發展起來的進展和社群感到非常高興。我們認為這個函式庫在解決許多開發團隊在建立基於節點的編輯器時面臨的問題方面具有很大的潛力。

經過幾個月的努力工作，今天我們終於可以宣布 React Flow 版本 10 的發布。隨著新的函式庫版本，我們還發布了一個完全修訂的文件，現在由 [Docusaurus](https://docusaurus.io/) 提供支援。最後但同樣重要的是，我們發布了 [React Flow Pro](https://pro.reactflow.dev/pricing)，這是我們為 React Flow 推出的新訂閱模式，我們希望建立它來確保函式庫的進一步開發和維護。在這篇文章中，我們描述了 React Flow 版本 10 的所有新聞。如果你想從 v9 遷移到 v10，請參考[遷移指南](https://reactflow.dev/learn/troubleshooting/migrate-to-v10)。

## 新功能

版本 10 帶來了許多新功能和改進。除了完全重寫內部狀態管理、將圖形元素分離為節點和連線、幾個錯誤修復和重構之外，以下是最重要的新功能：

- **子流程**：支援子流程、嵌套流程和節點分組
- **觸控裝置支援**：改進了觸控裝置上連接節點的用戶體驗
- **按鍵處理**：現在支援多個按鍵和按鍵組合
- **幾個新的 hooks**：`useReactFlow`、`useNodes`、`useEdges`、`useViewport`、`useKeypress` 已被重構以提供更好的開發體驗
- **Fit View 屬性**：在不編寫自訂邏輯的情況下初始適配所有節點和連線
- **連線標記**：更多選項來配置連線的開始和結束標記

最大和最受期待的新功能（當你查看 [Github 討論](https://github.com/xyflow/xyflow/discussions/1024)時）是對子流程和分組的支援。在 React Flow v10 中，節點可以指定 `parentNode`，這會影響其定位和拖曳行為。子節點相對於其父節點定位，並與父節點一起移動。還可以將子節點限制在父節點的邊界內。這使 React Flow 使用者能夠視覺化嵌套資料結構並實現展開/收合或縮放到子流程等功能。

另一個非常重要的改進是對觸控裝置的支援。由於我們將 [datablocks](https://datablocks.pro) 設計為僅限桌面的應用程式，因此在以前的版本中無法在觸控裝置上連接節點。使用 v10，你可以透過連續點擊兩個控制點來建立連接。

React Flow 帶有一些用於移除、多選和繪製選擇框的按鍵處理程序。這些處理程序現在有更多選項可以配置。你不僅可以傳遞單個按鍵，還可以傳遞多個按鍵或按鍵組合。

為了更新節點、連線和視口，我們實現了一個新的 hook：`useReactFlow`。它帶有有用的輔助函數，如 `getNode`、`fitView` 或 `setCenter`。我們還添加了新的 hooks，如 `useNodes`、`useEdges`、`useViewport` 和 `useKeypress`。

還有更多！你可以在[遷移指南](https://reactflow.dev/learn/troubleshooting/migrate-to-v10)中找到新功能和破壞性變更的詳細解釋清單。

## React Flow Pro

隨著新的函式庫版本，我們還發布了一個名為 [React Flow Pro](https://pro.reactflow.dev/pricing) 的訂閱模式。在過去的兩年裡，我們花了很多時間改進函式庫、添加新功能、組織問題和修復錯誤。透過 React Flow Pro，我們現在想邁出下一步：在財務上確保 React Flow 的未來。我們的目標是保持函式庫開源、免費並採用 MIT 授權。同時，我們希望給那些將 React Flow 作為業務重要部分的公司保證，函式庫將繼續開發和更新。

為了滿足這兩個要求，我們想出了為 React Flow 渲染器添加小歸屬的想法。[入門](https://pro.reactflow.dev/pricing)或[企業](https://pro.reactflow.dev/pricing)計劃的訂閱者可以從他們的應用程式中移除歸屬。其他人可以像以前一樣使用 React Flow，只要顯示歸屬。除了移除歸屬外，Pro 訂閱者還可以存取內部 Discord 頻道並安排支援電話。
我們對這個改變感到興奮，我們希望它能被良好接受並能確保我們在 React Flow 上的工作。你可以在 [React Flow Pro 網站](https://pro.reactflow.dev/pricing)上查看計劃和功能。
