# 主題化

Svelte Flow 帶有最小的預設樣式,並設計為完全可自訂。我們的許多用戶完全改變了 Svelte Flow 的外觀和感覺,以匹配他們自己的品牌或設計系統。本指南將向你介紹自訂 Svelte Flow 外觀的不同方法。

## 預設樣式

Svelte Flow 的預設樣式足以讓你開始使用內建節點。它們為填充、邊框半徑和動畫邊等樣式提供了一些合理的預設值。你可以在下面看到它們的樣子:

```js
import '@xyflow/svelte/dist/style.css';
```

## 基礎樣式

如果你只想載入 Svelte Flow 正常工作所需的基本樣式,你可以改為匯入基礎樣式:

```js
import '@xyflow/svelte/dist/base.css';
```

<Callout type="info">
  這些基礎樣式是 Svelte Flow 正確運作所**必需**的。如果你不匯入它們或用自己的樣式覆寫它們,某些功能可能無法如預期運作!
</Callout>

## 自訂

你可以透過不同的方式自訂 Svelte Flow 的外觀:

- 在自訂節點和邊中使用作用域 CSS
- 用自訂 CSS 覆寫內建類別
- 覆寫 Svelte Flow 使用的 CSS 變數
- 透過 `style` 屬性傳遞行內樣式

### 使用內建類別

如果你想覆寫預設樣式,可以透過覆寫內建 CSS 類別來實現。你可以在下面找到 Svelte Flow 使用的所有類別列表:

| 類別名稱                            | 描述                                                                   |
| :---------------------------------- | :--------------------------------------------------------------------- |
| `.svelte-flow`                      | 最外層容器                                                             |
| `.svelte-flow__renderer`            | 內層容器                                                               |
| `.svelte-flow__zoompane`            | 縮放和平移面板                                                         |
| `.svelte-flow__selectionpane`       | 選擇面板                                                               |
| `.svelte-flow__selection`           | 使用者選擇                                                             |
| `.svelte-flow__edges`               | 包含流程中所有邊的元素                                                 |
| `.svelte-flow__edge`                | 應用於流程中每個 [`Edge`](/api-reference/types/edge)                  |
| `.svelte-flow__edge.selected`       | 當 [`Edge`](/api-reference/types/edge) 被選中時添加                   |
| `.svelte-flow__edge.animated`       | 當 [`Edge`](/api-reference/types/edge) 的 `animated` 屬性為 `true` 時添加 |
| `.svelte-flow__edge-path`           | [`Edge`](/api-reference/types/edge) 的 SVG `<path />` 元素            |
| `.svelte-flow__edge-label`          | 邊標籤                                                                 |
| `.svelte-flow__connection`          | 應用於當前連接線                                                       |
| `.svelte-flow__connection-path`     | 連接線的 SVG `<path />`                                                |
| `.svelte-flow__nodes`               | 包含流程中所有節點的元素                                               |
| `.svelte-flow__node`                | 應用於流程中每個 [`Node`](/api-reference/types/node)                  |
| `.svelte-flow__node.selected`       | 當 [`Node`](/api-reference/types/node) 被選中時添加                   |
| `.svelte-flow__node-default`        | 當 [`Node`](/api-reference/types/node) 類型為 `"default"` 時添加      |
| `.svelte-flow__node-input`          | 當 [`Node`](/api-reference/types/node) 類型為 `"input"` 時添加        |
| `.svelte-flow__node-output`         | 當 [`Node`](/api-reference/types/node) 類型為 `"output"` 時添加       |
| `.svelte-flow__node-group`          | 當 [`Node`](/api-reference/types/node) 類型為 `"group"` 時添加        |
| `.svelte-flow__nodesselection`      | 節點選擇                                                               |
| `.svelte-flow__nodesselection-rect` | 節點選擇矩形                                                           |
| `.svelte-flow__handle`              | 應用於每個 [`<Handle />`](/api-reference/components/handle) 元件      |
| `.svelte-flow__handle-top`          | 當控制點的 [`Position`](/api-reference/types/position) 設為 `"top"` 時應用    |
| `.svelte-flow__handle-right`        | 當控制點的 [`Position`](/api-reference/types/position) 設為 `"right"` 時應用  |
| `.svelte-flow__handle-bottom`       | 當控制點的 [`Position`](/api-reference/types/position) 設為 `"bottom"` 時應用 |
| `.svelte-flow__handle-left`         | 當控制點的 [`Position`](/api-reference/types/position) 設為 `"left"` 時應用   |
| `.svelte-flow__handle.connecting`   | 當連接線位於控制點上方時應用                                           |
| `.svelte-flow__handle.valid`        | 當連接線位於控制點上方**且**連接有效時應用                             |
| `.svelte-flow__background`          | 應用於 [`<Background />`](/api-reference/components/background) 元件  |
| `.svelte-flow__minimap`             | 應用於 [`<MiniMap />`](/api-reference/components/mini-map) 元件       |
| `.svelte-flow__controls`            | 應用於 [`<Controls />`](/api-reference/components/controls) 元件      |

<Callout type="warning">
  如果你查看原始碼尋找其他要覆寫的類別,請小心。有些類別在內部使用,是函式庫正常運作所必需的。如果你替換它們,可能會遇到意外的錯誤!
</Callout>

### CSS 變數

如果你不想完全替換預設樣式,而只是想調整整體外觀和感覺,你可以覆寫我們在整個函式庫中使用的一些 CSS 變數。

這些變數大多不言自明。下面是一個表格,列出了你可能想要調整的所有變數及其預設值,以供參考:

| 變數名稱                                          | 預設值                              |
| :------------------------------------------------ | :---------------------------------- |
| `--xy-edge-stroke-default`                        | `#b1b1b7`                           |
| `--xy-edge-stroke-width-default`                  | `1`                                 |
| `--xy-edge-stroke-selected-default`               | `#555`                              |
| `--xy-connectionline-stroke-default`              | `#b1b1b7`                           |
| `--xy-connectionline-stroke-width-default`        | `1`                                 |
| `--xy-attribution-background-color-default`       | `rgba(255, 255, 255, 0.5)`          |
| `--xy-minimap-background-color-default`           | `#fff`                              |
| `--xy-background-pattern-dot-color-default`       | `#91919a`                           |
| `--xy-background-pattern-line-color-default`      | `#eee`                              |
| `--xy-background-pattern-cross-color-default`     | `#e2e2e2`                           |
| `--xy-node-color-default`                         | `inherit`                           |
| `--xy-node-border-default`                        | `1px solid #1a192b`                 |
| `--xy-node-background-color-default`              | `#fff`                              |
| `--xy-node-group-background-color-default`        | `rgba(240, 240, 240, 0.25)`         |
| `--xy-node-boxshadow-hover-default`               | `0 1px 4px 1px rgba(0, 0, 0, 0.08)` |
| `--xy-node-boxshadow-selected-default`            | `0 0 0 0.5px #1a192b`               |
| `--xy-handle-background-color-default`            | `#1a192b`                           |
| `--xy-handle-border-color-default`                | `#fff`                              |
| `--xy-selection-background-color-default`         | `rgba(0, 89, 220, 0.08)`            |
| `--xy-selection-border-default`                   | `1px dotted rgba(0, 89, 220, 0.8)`  |
| `--xy-controls-button-background-color-default`       | `#fefefe`                           |
| `--xy-controls-button-background-color-hover-default` | `#f4f4f4`                           |
| `--xy-controls-button-color-default`                  | `inherit`                           |
| `--xy-controls-button-color-hover-default`            | `inherit`                           |
| `--xy-controls-button-border-color-default`           | `#eee`                              |
| `--xy-controls-box-shadow-default`                    | `0 0 2px 1px rgba(0, 0, 0, 0.08)`   |

這些變數用於定義 Svelte Flow 各種元素的_預設值_。這意味著它們仍然可以透過行內樣式或自訂類別在每個元素的基礎上被覆寫。如果你想覆寫一個變數,可以這樣做:

```css
.svelte-flow {
  --xy-node-background-color-default: #ff5050;
}
```

### Tailwind

自訂節點和邊只是 Svelte 元件,你可以使用任何你喜歡的樣式解決方案來設計它們的樣式。例如,你可能想使用 [Tailwind](https://tailwindcss.com/) 來設計節點的樣式:

```svelte
<script lang="ts">
  import { Handle, Position, type NodeProps } from '@xyflow/svelte';

  let { data }: NodeProps = $props();
</script>

<div class="px-4 py-2 shadow-md rounded-md bg-white border-2 border-stone-400">
  <div class="flex">
    <div class="rounded-full w-12 h-12 flex justify-center items-center bg-gray-100">
      {data.emoji}
    </div>
    <div class="ml-2">
      <div class="text-lg font-bold">{data.name}</div>
      <div class="text-gray-500">{data.job}</div>
    </div>
  </div>
  <Handle
    type="target"
    position={Position.Top}
    class="w-16 !bg-teal-500 rounded-none border-none"
  />
  <Handle
    type="source"
    position={Position.Bottom}
    class="w-16 !bg-teal-500 rounded-none border-none"
  />
</div>
```

<Callout type="info">
  如果你想覆寫預設樣式,請確保最後匯入 Tailwind 的入口!
</Callout>

```js
import '@xyflow/svelte/dist/style.css';
import 'tailwind.css';
```

有關使用 Tailwind 與 Svelte Flow 的完整範例,請查看 [tailwind 範例](/examples/styling/tailwind)!
