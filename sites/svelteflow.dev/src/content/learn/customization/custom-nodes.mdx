# 自訂節點

Svelte Flow 的一個強大功能是能夠建立自訂節點。這讓您可以靈活地在節點內渲染任何想要的內容。我們通常建議建立您自己的自訂節點，而不是依賴內建節點。使用自訂節點，您可以添加任意數量的來源和目標控制點，甚至可以嵌入表單輸入、圖表和其他互動式元素。

在本節中，我們將逐步建立一個具有輸入欄位的自訂節點，該輸入欄位會更新應用程式中其他地方的文字。如需更多範例，我們建議查看我們的[自訂節點範例](/examples/nodes/custom-node)。

## 建立自訂節點

要建立自訂節點，您只需建立一個 Svelte 元件。Svelte Flow 會自動將其包裝在一個互動式容器中，該容器會注入基本的 props，如節點的 id、position 和 data，並提供選擇、拖曳和連接控制點的功能。有關所有可用的自訂節點 props 的完整參考，請查看[節點 Props](/api-reference/types/node-props)。

讓我們透過建立一個名為 `TextUpdaterNode` 的自訂節點來深入了解範例。為此，我們添加了一個帶有 oninput 處理程式的受控輸入欄位。我們簡單地使用節點資料中的 'text' 屬性作為輸入，並透過 [`updateNodeData`](/api-reference/hooks/use-svelte-flow#update-node-data) 函式更新節點的資料，該函式可以透過 [`useSvelteFlow`](/api-reference/hooks/use-svelte-flow) hook 來存取。

```svelte filename="TextUpdaterNode.svelte"
<script lang="ts">
  import { Position, useSvelteFlow, type NodeProps } from '@xyflow/svelte';

  let { id, data }: NodeProps = $props();

  let { updateNodeData } = useSvelteFlow();
</script>

<div class="text-updater-node">
  <div>
    <label for="text">Text:</label>
    <input
      id="text"
      name="text"
      value={data.text}
      oninput={(evt) => {
        updateNodeData(id, { text: evt.target.value });
      }}
      class="nodrag"
    />
  </div>
</div>
```

## 新增節點類型

現在我們需要將新的自訂節點傳達給 Svelte Flow。您可以透過傳遞
[`nodeTypes`](/api-reference/svelte-flow#node-types) prop 來新增自訂節點。

```svelte filename="App.svelte"
<script>
  import { SvelteFlow } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  import TextUpdaterNode from './TextUpdaterNode.svelte';

  const nodeTypes = { textUpdater: TextUpdaterNode };

  // [...]

</script>

<SvelteFlow
  bind:nodes
  bind:edges
  {nodeTypes}
  fitView
>
  <!-- [...] -->
</SvelteFlow>
```

定義新的節點類型後，您可以使用 `type` 節點選項來引用它：

```js
let nodes = $state.raw([
  {
    id: 'node-1',
    type: 'textUpdater',
    position: { x: 0, y: 0 },
    data: { text: 'some text' },
  },
]);
```

## 新增控制點

Svelte Flow 提供了一個 [`Handle`](/api-reference/components/handle) 元件，可用於
將控制點添加到您的自訂節點。只需掛載該元件即可。

```svelte filename="CustomNode.svelte" highlight="Handle"
<script>
  import { Handle } from '@xyflow/svelte';
</script>

<Handle type="target" position={Position.Top} />
<Handle type="source" position={Position.Bottom} />
```
