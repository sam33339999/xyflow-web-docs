# 安裝與需求

在此設定中，我們假設您已經安裝了 node.js 和 npm、yarn 或 pnpm。Svelte Flow 套件在
npm 上以 [`@xyflow/svelte`](https://www.npmjs.com/package/@xyflow/svelte) 發布，可透過以下方式安裝：

```bash copy npm2yarn
npm install @xyflow/svelte
```

現在您可以在應用程式中匯入 Svelte Flow 元件和樣式：

```js
import { SvelteFlow } from '@xyflow/svelte';
import '@xyflow/svelte/dist/style.css';
```

## 快速上手

為了讓大家能夠快速開始建構，我們在 GitHub 上提供了一個使用 Vite 和
Svelte 的範本儲存庫。您可以在[這裡](https://github.com/xyflow/vite-svelte-flow-template)找到該範本。

要使用它，您可以從範本建立一個新的儲存庫，或使用 `degit` 來
獲取範本檔案而不包含 git 歷史記錄：

```bash copy
npx degit xyflow/vite-svelte-flow-template your-app-name
```

## 所需的先備知識

Svelte Flow 是一個 Svelte 函式庫。這意味著 Svelte 開發者會覺得使用起來很舒適。
如果響應式狀態、props、元件和生命週期方法等基本 Svelte 術語和概念對您來說不熟悉，
您可能需要在完全使用 Svelte Flow 之前先學習更多關於 Svelte 的知識。如果您從未使用過 Svelte，
我們建議先透過[官方教學](https://svelte.dev/tutorial/svelte/welcome-to-svelte)來學習 Svelte。
