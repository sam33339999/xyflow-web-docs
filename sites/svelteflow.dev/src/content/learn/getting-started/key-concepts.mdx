# 核心概念

Svelte Flow 的核心是建立互動式流程圖 - 由連線連接的節點集合。雖然這在理論上聽起來很簡單，但 Svelte Flow 為建構複雜的互動式圖表提供了基礎：

- 無限的互動式畫布用於您的流程圖
- 能夠渲染節點並使用連線將它們連接起來
- **所有內容都使用標準的 Svelte 元件建構**

為了幫助您理解我們在整個文檔中使用的術語，請查看下面的範例流程圖。

<RemoteCodeViewer
  framework="svelte"
  route="/guides/concepts/"
  showEditor={false}
  showOpenInCodeSandbox={false}
  showOpenInStackblitz={false}
/>

以下是您在使用 Svelte Flow 時會遇到的核心術語：

- **Svelte Flow 元件**：渲染流程圖的主要元件
  - [**Svelte Flow Props**](/api-reference/svelte-flow)：所有配置和資料都透過 props 傳遞
- **視窗**：可以平移和縮放的流程圖可見區域
  - 當我們說某個東西「在視窗中」時，表示它會隨著視窗的轉換而移動
- [**基礎樣式**](/learn/customization/theming)：Svelte Flow 正常運作所需的基本 CSS
- [**內建元件**](/learn/getting-started/built-in-components)：即用型元件，如 Controls 和 MiniMap，可增強您的流程圖

了解這些概念後，您就可以[安裝 Svelte Flow](/learn/getting-started/installation) 並開始[建立您的第一個流程圖](/learn/getting-started/building-a-flow)了！
