# 建立流程圖

準備好建立您的第一個流程圖了嗎？本指南將逐步引導您完成整個過程。如果您還沒有
查看我們的[核心概念](/learn/getting-started/key-concepts)，我們建議您先閱讀那部分。

## 開始使用

首先，將 Svelte Flow 元件及其必要的樣式匯入到您的專案中。我們還將匯入
`Background` 元件以增強視覺效果。

```svelte
<script>
import { SvelteFlow, Background } from '@xyflow/svelte';
import '@xyflow/svelte/dist/style.css';
</script>
```

接下來，在具有定義尺寸的元素內渲染主要元件，並將
`Background` 元件放在 `SvelteFlow` 內。

<Callout type="info">
  `SvelteFlow` 內的內容會固定在視窗頂部。`Background`
  元件會轉換其圖樣以配合視窗移動。
</Callout>

```svelte
<div style:width="100vw" style:height="100vh">
    <SvelteFlow>
        <Background />
    </SvelteFlow>
</div>
```

如果一切設定正確，您應該會看到這樣的空白畫布：

<RemoteCodeViewer
  route="guides/getting-started/a"
  framework="svelte"
  editorHeight={400}
  showOpenInStackblitz={false}
  showEditor={false}
/>

## 新增節點

現在流程圖已經設定好了，讓我們加入一些節點。建立一個包含
[節點物件](/api-reference/types/node)的陣列，具有以下**必要**屬性：

- `id`：每個節點的唯一識別符
- `position`：x 和 y 座標
- `data`：用於儲存自訂資料的物件

我們將使用 [`$state.raw`](https://svelte.dev/docs/svelte/$state) rune 來使陣列具有
響應性。

<Callout color="yellow">
  單純使用 `$state` **不僅**會使陣列具有響應性，**每個節點的每個屬性也會**變成響應式。
  這可能導致[效能問題](https://github.com/sveltejs/svelte/issues/11851)，
  所以我們使用 [`$state.raw`](https://svelte.dev/docs/svelte/$state#$state.raw) 替代。
</Callout>

```js
let nodes = $state.raw([
  {
    id: '1',
    position: { x: 0, y: 0 },
    data: { label: 'Hello' },
  },
  {
    id: '2',
    position: { x: 100, y: 100 },
    data: { label: 'World' },
  },
]);
```

接下來，我們將節點[綁定](https://svelte.dev/docs/svelte/$bindable)到 `SvelteFlow`
元件。這種雙向綁定允許元件和您的程式碼都可以修改節點。

```svelte
<SvelteFlow bind:nodes>
```

如果您按照這些步驟操作，您應該會看到這樣的流程圖：

  showEditor={false}

## 新增連線

讓我們用一條連線來連接節點。使用
[`$state.raw`](https://svelte.dev/docs/svelte/$state#$state.raw) 初始化一個
[連線物件](/api-reference/types/edge)的陣列，具有以下**必要**屬性：

- `id`：連線的唯一識別符
- `source`：來源節點的 ID
- `target`：目標節點的 ID

```js
let edges = $state.raw([{ id: 'e1-2', source: '1', target: '2' }]);
```

與節點一樣，我們將連線[綁定](https://svelte.dev/docs/svelte/$bindable)到
`SvelteFlow` 元件。

```svelte
<SvelteFlow bind:nodes bind:edges>
```

## 美化流程圖

這可能已經朝著正確的方向發展，但看起來還是有點平淡和不平衡，不是嗎？

#### `fitView`

添加 [`fitView`](/api-reference/svelte-flow#fitview) prop 來自動將初始視窗
調整為可見節點的大小。

```svelte
<SvelteFlow bind:nodes bind:edges fitView>
```

#### 內建節點類型

讓我們將第一個節點的 `type` 更改為 `input`，第二個節點更改為 `output`。
這些是內建的節點類型，附帶不同的控制點配置。

```js
let nodes = $state.raw([
  {
    id: '1',
    type: 'input',
    position: { x: 0, y: 0 },
    data: { label: 'Hello' },
  },
  {
    id: '2',
    type: 'output',
    position: { x: 100, y: 100 },
    data: { label: 'World' },
  },
]);
```

#### 內建連線類型

我們將連線更改為 `smoothstep` 類型，並為其添加一個標籤！

```js
let edges = $state.raw([
  { id: 'e1-2', source: '1', target: '2', type: 'smoothstep', label: 'to the' },
]);
```
