# 內建元件

Svelte Flow 附帶了幾個額外的元件，您可以將它們插入到您的流程圖中。您只需
匯入這些元件並將它們作為子元件加入到 `SvelteFlow` 元件中。

```svelte filename="BuiltInComponents.svelte"
<script>
  import { SvelteFlow, MiniMap, Controls, Background, Panel } from '@xyflow/svelte';

  import '@xyflow/svelte/dist/style.css';
</script>

<SvelteFlow>
  <MiniMap />
  <Controls />
  <Background />
  <Panel position="top-left">
    <h1>My Flow</h1>
  </Panel>
</SvelteFlow>
```

## MiniMap

[`MiniMap`](/api-reference/components/mini-map) 提供流程圖的鳥瞰視圖，讓導航更加
容易，特別是對於較大的流程圖。您可以透過提供 `nodeColor` 函式來自訂小地圖中
節點的外觀。

## Background

網格圖樣，幫助使用者保持方向感。您可以從不同的圖樣變體中選擇，或者如果您需要
更進階的自訂，可以探索[原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/plugins/Background/Background.svelte)
來實作您自己的圖樣。
