# 快速入門

如果您想盡快開始使用，您來對地方了！本頁將在幾分鐘內帶您從零開始建立一個可運作的 Svelte Flow 應用程式。之後，您可以深入了解 Svelte Flow 的功能、查看範例，或深入研究 API 文檔。

## 依賴套件

Svelte Flow 在 npm 上以 [`@xyflow/svelte`](https://npmjs.com/package/@xyflow/svelte) 發布。

```bash copy npm2yarn
npm install @xyflow/svelte
```

## Vite 範本

如果您想立即開始，可以使用我們的 [vite 範本](https://github.com/xyflow/vite-svelte-flow-template)：

```bash copy npm2yarn
npx degit xyflow/vite-svelte-flow-template app-name
```

## 專案設定

要在本地開始，您需要準備以下內容：

- 已安裝 [Node.js](https://nodejs.org/en/)。
- npm 或其他套件管理器，如 [yarn](https://yarnpkg.com/) 或
  [pnpm](https://pnpm.io/)。
- 具備一些 [Svelte](https://svelte.dev/) 知識。您不需要是專家，但應該
  熟悉基本概念。

首先，使用您喜歡的方式建立一個新的 [Svelte](https://svelte.dev/) 專案；我們
建議使用 [Vite](https://vitejs.dev/) 和 [SvelteKit](https://svelte.dev/docs/kit/introduction)，但選擇權在您手上。

```bash copy npm2yarn
npx sv create my-svelte-flow-app
```

然後，導航到您的專案目錄並安裝 Svelte Flow 套件：

```bash copy npm2yarn
npm install @xyflow/svelte
```

## 建立您的第一個流程圖

`@xyflow/svelte` 套件匯出 `<SvelteFlow />` 元件，這是您流程圖的進入點。
只需匯入預設樣式並定義一些節點和連線，我們就可以開始了！

這裡有幾件事需要注意：

- <Emoji content="🎨" /> 您必須匯入 Svelte Flow 樣式表。
- <Emoji content="📐" /> `<SvelteFlow />` 繼承其父元素的大小。請將其包裹在一個
  具有尺寸的元素中。
- <Emoji content="⚡" /> 基於[效能考量](https://github.com/sveltejs/svelte/issues/11851)，
  請對 `nodes` 和 `edges` 使用 [`$state.raw`](https://svelte.dev/docs/svelte/$state#$state.raw)
  而非深度響應式狀態。

```svelte
<script>
  import { SvelteFlow } from '@xyflow/svelte';

  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([
    { id: '1', position: { x: 0, y: 0 }, data: { label: '1' } },
    { id: '2', position: { x: 0, y: 100 }, data: { label: '2' } },
  ]);

  let edges = $state.raw([
    { id: 'e1-2', source: '1', target: '2' },
  ]);
</script>

<div style:width="100vw" style:height="100vh">
  <SvelteFlow bind:nodes bind:edges />
</div>
```
