# 子流程

子流程是包含在節點內的流程圖。這些巢狀流程可以獨立運作,也可以與父節點外的節點連接,使它們非常適合組織和分組相關節點。本指南將向你展示如何實作子流程,並解釋子節點的可用選項。

### 定義子節點

要定義子節點,請使用 `parentId` 選項(請參閱[節點選項部分](/api-reference/types/node)中的所有可用選項)。子節點相對於其父節點定位,`{ x: 0, y: 0 }` 代表父節點的左上角。

```js highlight="parentId: 'A'"
let nodes = $state.raw([
  {
    id: 'A',
    data: { label: 'parent' },
    position: { x: 0, y: 0 },
  },
  {
    id: 'B',
    data: { label: 'child' },
    position: { x: 10, y: 10 },
    parentId: 'A',
  },
]);
```

<Callout type="info">
  <strong>節點順序:</strong>
  父節點必須在 `nodes` 陣列中出現在其子節點之前!
</Callout>

#### `extent: 'parent'`

當父節點具有定義的尺寸時,你可以通過設置 `extent: 'parent'` 來限制子節點的移動保持在父節點的邊界內。這可以防止子節點被拖動到其父節點區域之外。

### 子節點行為

當父節點移動時,子節點保持其相對位置。雖然 `parentId` 選項建立了父子關係,但子節點仍然可以定位在其父節點之外(除非設置了 `extent: 'parent'`)。但是,當拖動父節點時,它們將始終隨父節點一起移動。

在我們的範例中,我們使用內建的 `group` 節點類型作為父節點,它提供了帶有邊框的透明背景。你也可以使用[任何自訂節點類型](/learn/layouting/sub-flows#any-node-can-be-a-parent-node)作為父節點。
