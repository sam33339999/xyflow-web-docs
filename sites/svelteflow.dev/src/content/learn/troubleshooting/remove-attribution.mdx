# 移除標註

<Callout type="info">
如果你正在考慮移除標註,我們首先想提一下:

**如果你在組織中使用 Svelte Flow 並從中獲利**,我們依賴你的支持,以便在 MIT 許可證下繼續開發和維護 Svelte Flow。在你移除標註之前,[請查看你可以支持 Svelte Flow 以保持其運作的方式](/support-us)。

**你正在將 Svelte Flow 用於個人專案嗎?** 太好了!請隨意移除標註。你可以透過回報你發現的任何錯誤、向我們發送專案的截圖,以及在 [Github](https://github.com/xyflow/xyflow) 上給我們星標來支持我們。如果你將來開始使用 Svelte Flow 賺錢或在組織中使用它,我們希望你重新添加標註或成為 Github 或 Open Collective 贊助者。

感謝你支持我們 ✌🏻

- [xyflow 團隊](https://xyflow.com/about)

</Callout>

要移除應用程式角落的標註,你可以透過 `proOptions` 屬性將 `hideAttribution` 傳遞給 `<SvelteFlow />` 元件。

```svelte filename="App.svelte"
<script>
  import { SvelteFlow } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';
</script>

<SvelteFlow
  proOptions={{ hideAttribution: true }}
/>
```
