# 伺服器端渲染、伺服器端生成

import { Callout } from 'nextra/components';

這是一個進階用例,假設你已經熟悉 SvelteFlow。如果你是 SvelteFlow 的新手,請查看我們的[入門指南](/learn/getting-started/key-concepts)。

在本指南中,你將學習如何配置 SvelteFlow 進行伺服器端渲染,使你能夠:

- 為文檔生成靜態 HTML 圖表
- 在非 JavaScript 環境中渲染 SvelteFlow 圖表
- 為社交媒體分享建立動態 Open Graph 圖片

(對於客戶端圖片生成,請查看我們的[下載圖片範例](/examples/misc/download-image)。)

### 為什麼伺服器端渲染很複雜

要理解為什麼 Svelte Flow 中的伺服器端渲染需要特殊配置,讓我們看看 SvelteFlow 通常在客戶端處理的內容:

1. **節點尺寸計算**

   - 節點可以包含任何內容,所以它們的尺寸由瀏覽器的佈局引擎決定
   - 這種動態大小調整在伺服器端渲染期間不可用

2. **控制點位置檢測**

   - 邊連接需要精確的控制點位置
   - 這些位置是基於 CSS 佈局計算的,在伺服器上不可用

3. **容器大小適應**
   - SvelteFlow 適應其容器的尺寸
   - 伺服器端渲染需要明確的尺寸

### 節點尺寸

伺服器端渲染最關鍵的方面是指定節點尺寸。在客戶端,SvelteFlow 會自動測量節點並將尺寸儲存在 `measured.width` 和 `measured.height` 中。對於伺服器端渲染,你必須使用以下任一方式明確提供這些尺寸:

<Callout type="default">
  <strong>節點尺寸選項:</strong>
  1. `width` 和 `height`: 不會改變的靜態尺寸 <div></div>
  2. `initialWidth` 和 `initialHeight`: 在客戶端水合後可能改變的動態尺寸
</Callout>

```svelte
<script>
  const nodes = [
    {
      id: '1',
      type: 'default',
      position: { x: 0, y: 0 },
      data: { label: 'Node 1' },
      width: 100,
      height: 50,
    },
  ];
</script>
```

### 控制點位置

要在伺服器上渲染邊,你需要明確提供控制點位置。在客戶端,SvelteFlow 會自動計算這些位置,但對於伺服器端渲染,你必須使用 `handles` 屬性指定它們:

```svelte
<script>
  import { Position } from '@xyflow/svelte';

  const nodes = [
    {
      id: '1',
      type: 'default',
      position: { x: 0, y: 0 },
      data: { label: 'Node 1' },
      width: 100,
      height: 50,
      handles: [
        {
          type: 'target',
          position: Position.Top,
          x: 100 / 2,
          y: 0,
        },
        {
          type: 'source',
          position: Position.Bottom,
          x: 100 / 2,
          y: 50,
        },
      ],
    },
  ];
</script>
```

### 在伺服器端渲染中使用 `fitView`

如果你知道容器的尺寸,你可以通過提供容器的寬度和高度在伺服器端渲染期間使用 `fitView`:

```svelte
<script>
  import { SvelteFlow } from '@xyflow/svelte';

  let nodes = $state.raw([/* ... */]);
  let edges = $state.raw([/* ... */]);
</script>

<SvelteFlow {nodes} {edges} fitView width={1000} height={500} />
```

### 生成靜態 HTML

要建立靜態 HTML 輸出,你可以使用 Svelte 的伺服器端渲染功能。這會生成一個 HTML 字串,你可以用於靜態檔案或 HTTP 回應:

```svelte
<script>
  import { SvelteFlow, Background } from '@xyflow/svelte';
  import { render } from 'svelte/server';

  function toHTML({ nodes, edges, width, height }) {
    const { html } = render(SvelteFlow, {
      props: {
        nodes,
        edges,
        width,
        height,
        minZoom: 0.2,
        fitView: true,
      },
      children: [Background],
    });

    return html;
  }
</script>
```
