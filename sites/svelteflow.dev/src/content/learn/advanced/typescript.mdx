# 使用 TypeScript

Svelte Flow 是用 TypeScript 編寫的,因為我們重視它提供的額外安全屏障。我們匯出了你需要的所有類型,用於正確地為傳遞給 Svelte Flow 元件的資料結構和函式定型。我們還提供了一種擴展節點和邊類型的方法。

## 基本用法

讓我們從基本實作所需的基本類型開始。雖然 TypeScript 可以自動推斷某些類型,但為了清楚起見,我們將明確定義它們。

```svelte
<script lang="ts">
  import {
    SvelteFlow,
    Controls,
    Background,
    BackgroundVariant,
    type Node,
    type Edge,
    type FitViewOptions,
    type DefaultEdgeOptions,
  } from '@xyflow/svelte';

  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw<Node[]>([
    {
      id: '1',
      type: 'input',
      data: { label: 'Node 1' },
      position: { x: 5, y: 5 },
    },
    {
      id: '2',
      type: 'default',
      data: { label: 'Node 2' },
      position: { x: 5, y: 100 },
    },
  ]);

  let edges = $state.raw<Edge[]>([
    { id: 'e1-2', source: '1', target: '2' }
  ]);

  const fitViewOptions: FitViewOptions = {
    padding: 0.2,
  };

  const defaultEdgeOptions: DefaultEdgeOptions = {
    animated: true,
  };
</script>

<SvelteFlow
  bind:nodes
  bind:edges
  fitView
  {fitViewOptions}
  {defaultEdgeOptions}
>
  <Controls />
  <Background variant={BackgroundVariant.Dots} />
</SvelteFlow>
```

### 自訂節點

在使用[自訂節點](/learn/customization/custom-nodes)時,你可以擴展基本的 `Node` 類型以包含自訂資料。有兩種主要方法:

1. 對於**多個自訂節點**,將自訂 `Node` 類型指定為 `NodeProps` 的泛型:

```svelte
<script module>
  export type NumberNodeType = Node<{ number: number }, 'number'>;
</script>

<script lang="ts">
  import { Handle, Position, type NodeProps, type Node } from '@xyflow/svelte';

  let { id, data }: NodeProps<NumberNodeType> = $props();
</script>

<div class="custom">
  <div>A special number: {data.number}</div>
  <Handle type="source" position={Position.Right} />
</div>
```

⚠️ 當單獨定義節點資料時,你必須使用 `type`(介面不起作用):

```ts
type NumberNodeData = { number: number };
type NumberNodeType = Node<NumberNodeData, 'number'>;
```

2. 對於**單個自訂節點**,根據節點類型渲染不同內容,使用聯合類型:

```svelte
<script module>
  export type NumberNodeType = Node<{ number: number }, 'number'>;
  export type TextNodeType = Node<{ text: string }, 'text'>;

  export type NodeType = NumberNodeType | TextNodeType;
</script>

<script lang="ts">
  import { Handle, Position, type NodeProps } from '@xyflow/svelte';

  let { data }: NodeProps<NodeType> = $props();
</script>

<div class="custom">
  {#if data.type === 'number'}
    <div>A special number: {data.number}</div>
  {:else}
    <div>A special text: {data.text}</div>
  {/if}
  <Handle type="source" position={Position.Right} />
</div>
```

### 自訂邊

與自訂節點類似,你可以為[自訂邊](/learn/customization/custom-edges)擴展基本的 `Edge` 類型:

```svelte
<script module>
  export type EdgeType = Edge<{ value: number }, 'custom'>;
</script>

<script lang="ts">
  import { getStraightPath, BaseEdge, type EdgeProps } from '@xyflow/svelte';

  let { id, sourceX, sourceY, targetX, targetY }: EdgeProps<EdgeType> = $props();

  let [edgePath] = $derived(getStraightPath({ sourceX, sourceY, targetX, targetY }));
</script>

<BaseEdge {id} path={edgePath} />
```

## 進階用法

在複雜的應用程式中,你可能會有多個具有不同資料結構的自訂節點和邊。在使用內建函式和鉤子時,你需要正確地[縮小](https://www.typescriptlang.org/docs/handbook/2/narrowing.html)類型以防止執行時錯誤。

### `Node` 和 `Edge` 類型聯合

許多函式、回呼和鉤子(包括 SvelteFlow 元件)期望 `NodeType` 或 `EdgeType` 泛型。這些是所有自訂節點和邊類型的聯合。只要你正確地為資料物件定型,你就可以使用它們匯出的類型。

<Callout type="info">
  如果你使用任何內建節點('input'、'output'、'default')或邊('straight'、'step'、'smoothstep'、'bezier'),請在聯合類型中包含來自 `@xyflow/svelte` 的 `BuiltInNode` 和 `BuiltInEdge` 類型。
</Callout>

```svelte
<script module>
  import type { BuiltInNode, BuiltInEdge } from '@xyflow/svelte';

  // 自訂節點
  import type { NumberNodeType } from './NumberNode.svelte';
  import type { TextNodeType } from './TextNode.svelte';

  // 自訂邊
  import type { CustomEdgeType } from './CustomEdge.svelte';

  export type NodeType = BuiltInNode | NumberNodeType | TextNodeType;
  export type EdgeType = BuiltInEdge | CustomEdgeType;
</script>

<script lang="ts">
  import { SvelteFlow, type NodeTypes, type EdgeTypes } from '@xyflow/svelte';
  import NumberNode from './NumberNode.svelte';
  import TextNode from './TextNode.svelte';
  import CustomEdge from './CustomEdge.svelte';

  const nodeTypes: NodeTypes = {
    number: NumberNode,
    text: TextNode,
  };

  const edgeTypes: EdgeTypes = {
    custom: CustomEdge,
  };

  let nodes = $state.raw<NodeType[]>([]);
  let edges = $state.raw<EdgeType[]>([]);
</script>

<SvelteFlow bind:nodes bind:edges {nodeTypes} {edgeTypes} fitView>
  <!-- ... -->
</SvelteFlow>
```

### 鉤子

你可以使用這些類型聯合來正確地為鉤子的返回值定型:

```svelte
<script lang="ts">
  import { useSvelteFlow, useNodeConnections, useNodesData } from '@xyflow/svelte';
  import type { NodeType, EdgeType } from './types';

  // 節點和邊現在已正確定型
  const { getNodes, getEdges } = useSvelteFlow<NodeType, EdgeType>();

  const connections = useNodeConnections({
    handleType: 'target',
  });

  const nodesData = useNodesData<NodeType>(connections.current.map(c => c.source));

  $effect(() => {
    nodesData.current.forEach(({ type, data }) => {
      if (type === 'number') {
        // 類型安全地存取 number 屬性
        console.log(data.number);
      }
    });
  });
</script>
```

### 類型守衛

TypeScript 提供了幾種實作[類型守衛](https://www.typescriptlang.org/docs/handbook/2/narrowing.html#typeof-type-guards)的方法。一種常見的方法是建立類型守衛函式,如 `isNumberNode` 或 `isTextNode`,以從列表中過濾特定節點:

```ts
function isNumberNode(node: NodeType): node is NumberNodeType {
  return node.type === 'number';
}

// numberNodes 現在正確定型為 NumberNodeType[]
let numberNodes = $derived(nodes.filter(isNumberNode));
```
