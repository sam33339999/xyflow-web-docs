# Svelte Flow 0.1.0

這是 Svelte Flow 的一個重大更新,以跟上我們為 React Flow 和 Svelte5 重寫所做的最新變更。最大的變更是將使用者節點(類型 `Node`)和內部節點(類型 `InternalNode`)分離,這包括將 `node.computed` 屬性重新命名為 `node.measured`。在先前的版本中,我們將內部資料儲存在 `node[internalsSymbol]` 中。這已不再存在,但我們只將其新增到 `node.internals.` 中的內部節點。

## ⚠️ Breaking

- 將 `node.computed` 重新命名為 `node.measured` - 此屬性僅包含 `width` 和 `height`,不再包含 `positionAbsolute`。為了接收內部節點,我們新增了輔助函式 [`useInternalNode`](/api-reference/hooks/use-internal-node) 和 [`getInternalNode`](/api-reference/hooks/use-svelte-flow#get-internal-node)
- 將 `node.parentNode` 重新命名為 `node.parentId`

### 更多更新:

- 為 `<Handle />` 元件新增 `isValidConnection`
- 為 `<Controls />` 元件新增 `fitViewOptions`
- 為 `useSvelteFlow` 新增 `getInternalNode`
- 新增 `useInternalNode` hook
- 當 svelte flow 卸載時不重設節點和邊
- 修正節點事件類型
- 讓 handleId 和 isTarget 具有響應性
- 修正觸控裝置的 MiniMap 互動
- 修正 pane:Windows 上的雙指縮放
