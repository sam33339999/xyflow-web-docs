# NodeEventWithPointer

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/events.ts#4)

`NodeEventWithPointer` 類型代表節點互動期間發生的事件，包含指標位置和事件詳細資訊。它擴展了基本節點事件，加入了指標相關的資訊。

```ts
type NodeEventWithPointer<NodeType extends Node = Node> = {
  event: PointerEvent;
  node: NodeType;
};
```
