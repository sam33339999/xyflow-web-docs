# OnConnectStart

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L79)

`OnConnectStart` 類型是在開始建立節點之間的連線時被呼叫的回呼函式。它接收滑鼠或觸控事件以及關於正在開始的連線的參數。

```ts
type OnConnectStart = (
  event: MouseEvent | TouchEvent,
  params: OnConnectStartParams,
) => void;
```
