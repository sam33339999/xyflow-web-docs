# DefaultEdgeOptions

[`Edge`](/api-reference/types/edge) 上的許多屬性都是可選的。當建立新的邊時，未提供的屬性將使用傳遞給 [`<SvelteFlow />`](/api-reference/svelte-flow#defaultedgeoptions) 元件的 `defaultEdgeOptions` 屬性的預設值來填充。
