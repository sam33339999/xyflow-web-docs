# OnConnectEnd

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L89)

`OnConnectEnd` 類型代表在完成或取消連線嘗試時被呼叫的回呼函式。它接收滑鼠或觸控事件以及連線嘗試的最終狀態。

```ts
type OnConnectEnd = (
  event: MouseEvent | TouchEvent,
  connectionState: FinalConnectionState,
) => void;
```
