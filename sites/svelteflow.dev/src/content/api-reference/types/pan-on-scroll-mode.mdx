# PanOnScrollMode

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#167)

`PanOnScrollMode` 枚舉控制當使用者捲動時視口的平移行為。選擇 `Free` 以進行不受限制的平移，`Vertical` 僅限上下移動，或 `Horizontal` 僅限左右移動。

```ts
enum PanOnScrollMode {
  Free = 'free',
  Vertical = 'vertical',
  Horizontal = 'horizontal',
}
```
