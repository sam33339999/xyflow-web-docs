# OnDelete

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/general.ts)

`OnDelete` 類型是在從流程圖中刪除節點或邊時被呼叫的回呼函式。它接收已刪除的節點和邊。

```ts
type OnDelete<
  NodeType extends NodeBase = NodeBase,
  EdgeType extends EdgeBase = EdgeBase,
> = ({ nodes, edges }: { nodes: NodeType[]; edges: EdgeType[] }) => void;
```
