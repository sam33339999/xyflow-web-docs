# OnSelectionDrag

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/events.ts#L74)

`OnSelectionDrag` 類型是在拖曳選取的節點時被呼叫的回呼函式。它接收滑鼠事件和正在拖曳的節點陣列。

```ts
type OnSelectionDrag<NodeType extends Node = Node> = (
  event: MouseEvent,
  nodes: NodeType[],
) => void;
```
