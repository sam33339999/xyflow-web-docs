# OnReconnect

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/general.ts#L83)

`OnReconnect` 類型是在將現有邊重新連接到不同節點或控制點時被呼叫的回呼函式。它接收舊的邊和新的連線詳細資訊。

```ts
type OnReconnect<EdgeType extends EdgeBase = EdgeBase> = (
  oldEdge: EdgeType,
  newConnection: Connection,
) => void;
```
