# IsValidConnection

[GitHub 原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/general.ts#L43)

`IsValidConnection` 類型是一個函式，用於判斷節點之間的連接是否有效。它接收一個邊或連接物件，並回傳一個布林值，指示該連接是否有效。

```ts
type IsValidConnection = (edge: Edge | Connection) => boolean;
```
