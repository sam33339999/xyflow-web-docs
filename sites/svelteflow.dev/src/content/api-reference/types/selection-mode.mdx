# SelectionMode

[在 GitHub 上查看源碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L223)

`SelectionMode` 列舉決定節點選擇的運作方式。使用 `Full` 要求整個節點都在選擇區域內，或使用 `Partial` 允許重疊。

```ts
enum SelectionMode {
  Partial = 'partial',
  Full = 'full',
}
```
