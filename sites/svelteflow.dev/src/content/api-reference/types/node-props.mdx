# NodeProps

當你實作[自訂節點](/learn/customization/custom-nodes)時，它會被包裝在一個元件中，該元件提供拖曳、選取和移除等基本功能。自訂節點會收到以下屬性：

<APIDocs typeName="NodeProps" />

## 注意事項

- 如果你的自訂節點中有控制項（如滑桿或輸入框）或其他**不應該拖曳節點**的元素，你可以為這些元素加入 `nodrag` 類別。這可以防止預設的拖曳行為，以及點擊帶有此類別的元素時的預設節點選取行為。

  ```svelte filename="CustomNode.svelte"
  <div>
    <input className="nodrag" type="range" min={0} max={100} />
  </div>
  ```

- 如果你的自訂節點中有捲動容器，你可以加入 `nowheel` 類別來**停用在自訂節點內捲動時的預設畫布平移行為**。

  ```svelte filename="CustomNode.svelte"
  <div className="nowheel" style={{ overflow: 'auto' }}>
    <p>可捲動的內容...</p>
  </div>
  ```

- 建立自訂節點時，你還需要記得為它們設定樣式！與內建節點不同，自訂節點沒有預設樣式，因此你可以使用任何你喜歡的[樣式設定方法](/learn/customization/theming)。
