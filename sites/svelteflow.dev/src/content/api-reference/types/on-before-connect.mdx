# OnBeforeConnect

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/lib/types/general.ts#L31)

`OnBeforeConnect` 類型是在建立連線前被呼叫的回呼函式。它可以透過回傳 `false` 或修改後的連線來阻止連線或修改它。

```ts
type OnBeforeConnect = (connection: Connection) => Promise<boolean | Connection>;
```
