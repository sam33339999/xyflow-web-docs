# PanelPosition

此類型主要用於幫助在流程視口上定位元素。例如，
[`<MiniMap />`](/api-reference/components/mini-map) 和
[`<Controls />`](/api-reference/components/controls) 元件都接受此類型的 `position`
屬性。

```ts
export type PanelPosition =
  | 'top-left'
  | 'top-center'
  | 'top-right'
  | 'bottom-left'
  | 'bottom-center'
  | 'bottom-right'
  | 'center-left'
  | 'center-right';
```
