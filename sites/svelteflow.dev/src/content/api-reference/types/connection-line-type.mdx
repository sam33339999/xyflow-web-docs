# ConnectionLineType

使用 [`<SvelteFlow />`](/api-reference/svelte-flow#connection-connectionLineType) 元件的 `connectionLineType` 屬性，您可以配置連接線的類型。Svelte Flow 內建支援以下類型：'default'（貝茲曲線）、'straight'、'step'、'smoothstep' 和 'simplebezier'。

```ts
export enum ConnectionLineType {
  Bezier = 'default',
  Straight = 'straight',
  Step = 'step',
  SmoothStep = 'smoothstep',
  SimpleBezier = 'simplebezier',
}
```
