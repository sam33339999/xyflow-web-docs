# OnError

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L88)

`OnError` 類型是在 SvelteFlow 中發生錯誤時被呼叫的回呼函式。它接收錯誤 ID 和描述錯誤的訊息。

```ts
type OnError = (id: string, message: string) => void;
```
