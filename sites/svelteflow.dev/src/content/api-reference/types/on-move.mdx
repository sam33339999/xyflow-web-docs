# OnMove

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L86)

`OnMove` 類型是一個回呼，在視口移動時觸發，無論是透過使用者互動還是程式控制。它接收觸發事件和新的視口狀態。

```ts
type OnMove = (event: MouseEvent | TouchEvent | null, viewport: Viewport) => void;
```
