# CoordinateExtent

座標範圍表示座標系統中的兩個點：一個在左上角，一個在右下角。它用於表示流程中節點的邊界或視窗的邊界。

```ts
export type CoordinateExtent = [[number, number], [number, number]];
```

## 注意事項

- 需要 `CoordinateExtent` 的屬性（如 nodeExtent 或 translateExtent）通常預設為 `[[-∞, -∞], [+∞, +∞]]` 來表示無限範圍。
