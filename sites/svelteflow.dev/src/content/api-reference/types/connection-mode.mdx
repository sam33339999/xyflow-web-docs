# ConnectionMode

[GitHub 原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L68)

`ConnectionMode` 列舉定義了連接節點的可用策略。使用 `Strict` 只允許連接到有效的控制點，或使用 `Loose` 允許更靈活的連接。

```ts
enum ConnectionMode {
  Strict = 'strict',
  Loose = 'loose',
}
```
