# Node\<NodeData, NodeType>

`Node` 類型代表 Svelte Flow 需要知道的關於給定節點的所有資訊。

## 注意事項

- 你不應該嘗試直接設定節點的 `measured.width` 或 `measured.height`。它們由 Svelte Flow 內部測量，並在視口中渲染節點時使用。要控制節點的大小，你應該使用 `width` 和 `height` 屬性。
