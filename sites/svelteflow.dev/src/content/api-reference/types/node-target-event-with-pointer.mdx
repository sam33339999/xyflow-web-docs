# NodeTargetEventWithPointer

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/events.ts#20)

`NodeTargetEventWithPointer` 類型代表目標節點互動期間發生的事件，包含指標位置和事件詳細資訊。它擴展了基本節點事件，加入了指標相關資訊和目標節點資料。

```ts
type NodeTargetEventWithPointer<NodeType extends Node = Node> = {
  event: PointerEvent;
  node: NodeType;
  targetNode: NodeType;
};
```
