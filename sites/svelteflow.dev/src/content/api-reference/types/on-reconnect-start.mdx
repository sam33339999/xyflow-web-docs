# OnReconnectStart

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/general.ts#L84)

`OnReconnectStart` 類型是在重新連接現有邊時被呼叫的回呼函式。它接收滑鼠或觸控事件、正在重新連接的邊以及正在使用的控制點類型。

```ts
type OnReconnectStart<EdgeType extends EdgeBase = EdgeBase> = (
  event: MouseEvent | TouchEvent,
  edge: EdgeType,
  handleType: HandleType,
) => void;
```
