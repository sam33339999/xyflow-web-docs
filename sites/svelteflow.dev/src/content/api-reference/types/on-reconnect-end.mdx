# OnReconnectEnd

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/types/general.ts#L89)

`OnReconnectEnd` 類型是在邊的重新連接過程完成或取消時觸發的回呼。它接收觸發事件、邊、控制點類型以及最終連線狀態。

```ts
type OnReconnectEnd<EdgeType extends EdgeBase = EdgeBase> = (
  event: MouseEvent | TouchEvent,
  edge: EdgeType,
  handleType: HandleType,
  connectionState: FinalConnectionState,
) => void;
```
