## JavaScript 使用者注意事項

Svelte Flow 是用 TypeScript 編寫的，但我們知道並非每個人都使用它。我們鼓勵開發者使用最適合他們的技術，在整個文件中，TypeScript 和 JavaScript 範例混合使用。

然而，對於我們的 API 參考文件，我們使用 TypeScript 的語法來記錄 props 和函數的類型。以下是如何閱讀它的快速入門：

• `?` 表示該欄位或參數是可選的。

• 類型定義中的 `<T>` 代表泛型類型參數。就像函數參數，但用於類型！定義 `type Array<T> = ...` 意味著一個名為 `Array` 的類型接受一個泛型類型參數 `T`。

• 引用類型時的 `<T>` 就像是「填入」泛型類型參數。就像呼叫函數，但用於類型！類型 `Array<number>` 是類型 `Array`，其中泛型類型參數 `T` 被填入類型 `number`。

• `T | U` 表示類型是 `T` 或 `U`：這通常稱為_聯合_。

• `T & U` 表示類型同時是 `T` 和 `U`：這通常稱為_交集_。

TypeScript 官方有他們自己的[閱讀類型的實用指南](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)，你可能會覺得有用。如果你仍然對某些內容感到困惑，歡迎到我們的 [Discord](https://discord.com/invite/RVmnytFmGW) 尋求協助！
