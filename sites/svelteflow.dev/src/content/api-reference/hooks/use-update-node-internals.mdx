# useUpdateNodeInternals()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useUpdateNodeInternals.svelte.ts/#L6)

當你以程式方式新增或移除節點的控制點，或更新節點的控制點位置時，你需要使用此 hook 來通知 Svelte Flow。這會更新節點的內部尺寸，並在必要時正確重新定位畫布上的控制點。

```svelte
<script lang="ts">
  import { Handle, useUpdateNodeInternals } from '@xyflow/svelte';

  const updateNodeInternals = useUpdateNodeInternals();
</script>
```
