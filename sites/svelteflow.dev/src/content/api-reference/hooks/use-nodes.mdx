# useNodes()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useNodesEdgesViewport.svelte.ts)

此 hook 會回傳目前的節點陣列。當你訂閱時，它會在節點陣列變化時觸發。這發生在節點被新增、移除或更新時（例如拖曳）。

```svelte
<script lang="ts">
  import { useNodes } from '@xyflow/svelte';

  const nodes = useNodes();
</script>
```
