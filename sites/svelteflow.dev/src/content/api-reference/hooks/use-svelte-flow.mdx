# useSvelteFlow()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useSvelteFlow.svelte.ts)

此 hook 會回傳用於更新視窗、轉換位置或取得節點交集等功能的函式。

```svelte
<script lang="ts">
  import { useSvelteFlow } from '@xyflow/svelte';

  const { screenToFlowPosition, zoomIn } = useSvelteFlow();
</script>
```
