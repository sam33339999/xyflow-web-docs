# useNodesInitialized()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useInitialized.svelte.ts)

此 hook 可用於檢查所有節點是否已初始化。它會回傳一個帶有布林值的信號。

```svelte
<script lang="ts">
  import { useNodesInitialized } from '@xyflow/svelte';

  const useNodesInitialized = useNodesInitialized();
</script>
```
