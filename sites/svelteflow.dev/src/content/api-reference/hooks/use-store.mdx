# useStore()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/store/index.ts/)

此 hook 可用於存取 Svelte Flow 的內部儲存狀態。

<Callout type="info">
  此 hook 僅適用於進階使用情境。只有在沒有其他方式可以存取內部狀態時才應使用它。對於許多常見的使用情境，都有專門的 hook 可用，例如 [`useConnection`](/api-reference/hooks/use-connection)、[`useNodes`](/api-reference/hooks/use-nodes) 等。
</Callout>

```svelte
<script lang="ts">
  import { useStore } from '@xyflow/svelte';

  // 你傳遞給 <SvelteFlow> 元件的許多 props 最終會進入內部儲存狀態。
  // 這裡我們正在存取目前的 connectionMode。
  const { connectionMode } = useStore();
</script>
```
