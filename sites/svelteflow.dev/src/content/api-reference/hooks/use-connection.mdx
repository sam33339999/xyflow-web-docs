# useConnection()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useConnection.svelte.ts)

`useConnection` hook 會在有活躍的連接互動時回傳目前的連接。如果沒有活躍的連接互動，則每個屬性都會回傳 `null`。此 hook 的典型使用情境是根據特定條件（例如連接是否有效）來為控制點著色。

```svelte
<script lang="ts">
  import { useConnection } from '@xyflow/svelte';

  const connection = useConnection();
</script>
```
