# useOnSelectionChange()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useOnSelectionChange.svelte.ts)

此 hook 讓你可以監聽節點和連線的選取變化。顧名思義，當節點或連線的選取狀態發生變化時，你提供的回呼函式就會被呼叫。

```svelte filename="Component.svelte"
<script>
  import { useOnSelectionChange } from '@xyflow/svelte';

  let selectedNodes = $state.raw([]);
  let selectedEdges = $state.raw([]);

  useOnSelectionChange(({ nodes, edges }) => {
    selectedNodes = nodes.map((node) => node.id);
    selectedEdges = edges.map((edge) => edge.id);
  });
</script>

<div>
    <p>選取的節點：{selectedNodes.join(', ')}</p>
    <p>選取的連線：{selectedEdges.join(', ')}</p>
</div>
```
