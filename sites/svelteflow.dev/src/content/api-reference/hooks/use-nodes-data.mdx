# useNodesData()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useNodesData.svelte.ts)

使用此 hook 你可以取得傳入的節點 ID 的資料。

```svelte
<script lang="ts">
  import { useNodesData } from '@xyflow/svelte';

  const nodeData = useNodesData(['node-id-a', 'node-id-b']);

  $effect(() => {
    // 當傳入的節點 ID 的資料更新時，nodeData 會變化
    console.log(nodeData.current);
  });
</script>
```
