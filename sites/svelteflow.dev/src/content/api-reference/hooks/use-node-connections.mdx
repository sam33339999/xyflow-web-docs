# useNodeConnections()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useNodeConnections.svelte.ts)

此 hook 會回傳特定節點、控制點類型（'source'、'target'）或控制點 ID 上的連接陣列。

```svelte
<script>
  import { useNodeConnections } from '@xyflow/svelte';
  const connections = useNodeConnections({ handleType: 'target', handleId: 'my-handle' });
</script>

<div>目前有 {connections.length} 個傳入連接！</div>
```
