# useInternalNode()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/hooks/useInternalNode.svelte.ts)

`useInternalNode` hook 會回傳一個內部節點。內部節點用於進階使用情境，例如自訂連線或布局。

```svelte
<script lang="ts">
  import { useInternalNode } from '@xyflow/svelte';

  const node = useInternalNode(id);
</script>
```
