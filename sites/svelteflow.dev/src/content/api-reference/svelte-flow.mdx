# \<SvelteFlow />

[在 Github 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/container/SvelteFlow/SvelteFlow.svelte)

`<SvelteFlow />` 元件是你的 Svelte Flow 應用程式的核心。

```svelte
<script>
  import { SvelteFlow } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([
    { id: 'a', data: { label: 'node a' }, position: { x: 0, y: 0 } },
    { id: 'b', data: { label: 'node b' }, position: { x: 0, y: 100 } }
  ]);

  let edges = $state.raw([
    { id: 'e1-2', source: 'a', target: 'b' }
  ]);
</script>

<SvelteFlow
  bind:nodes
  bind:edges
  fitView
/>
```

這個元件接受許多不同的 props，其中大部分是可選的。我們試圖將它們分組記錄，以幫助你找到所需的內容。
