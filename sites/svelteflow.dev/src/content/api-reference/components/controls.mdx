# \<Controls />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/plugins/Controls/Controls.svelte)

`<Controls />` 元件會渲染一個小面板，包含方便的按鈕來
放大、縮小、調整視圖和鎖定視口。

```svelte
<script lang="ts">
  import { SvelteFlow, Controls } from '@xyflow/svelte';

  let nodes = $state.raw([]);
  let edges = $state.raw([]);
</script>

<SvelteFlow bind:nodes bind:edges>
  <Controls />
</SvelteFlow>
```

## 屬性

`<Controls />` 元件的屬性類型導出為 `ControlsProps`。
此外，它擴展了 `<div />` 的屬性。

<APIDocs componentName="Controls" groupKeys="HTMLAttributes<HTMLDivElement>" />

## 注意事項

- 若要擴展或自訂控制項，你可以使用 [`<ControlButton />`](/api-reference/components/control-button)
  元件
