# \<NodeResizer />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/487b13c9ad8903789f56c6fcfd8222f9cb74b812/packages/svelte/src/lib/plugins/NodeResizer/NodeResizer.svelte)

`<NodeResizer />` 元件可用於為你的節點加入調整大小的功能。
它會在節點周圍渲染可拖曳的控制點，以便在所有方向調整大小。

```svelte filename="CustomNode.svelte"
<script lang="ts">
  import { Handle, Position, NodeResizer, type NodeProps } from '@xyflow/svelte';

  let { data } : NodeProps = $props();
</script>

<NodeResizer minWidth={100} minHeight={30} />

<Handle type="target" position={Position.Left} />
<div style={{ padding: 10 }}>{data.label}</div>
<Handle type="source" position={Position.Right} />
```

## 屬性

`<NodeResizer />` 元件的屬性類型導出為 `NodeResizerProps`。此外，它擴展了 `<div />` 的屬性。

<APIDocs componentName="NodeResizer" groupKeys="HTMLAttributes<HTMLDivElement>" />

## 範例

前往[範例頁面](/examples/nodes/node-resizer)查看如何實作。

<RemoteCodeViewer

### 自訂調整大小控制點

若要建立自訂調整大小控制點，你可以使用 [NodeResizeControl](/api-reference/components/node-resize-control) 元件並自訂它。

- 查看 [`NodeProps`](/api-reference/types/node-props) 類型的文件或
  [自訂節點](/learn/customization/custom-nodes)指南，了解如何
  實作你自己的節點。
