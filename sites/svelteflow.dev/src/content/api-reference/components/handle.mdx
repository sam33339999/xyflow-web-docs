# \<Handle />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/components/Handle/Handle.svelte)

`<Handle />` 元件用於你的[自訂節點](/learn/customization/custom-nodes)中
定義連接點。

```svelte filename="CustomNode.svelte"
<script lang="ts">
  import { Handle, Position, type NodeProps } from '@xyflow/svelte';

  let { data } : NodeProps = $props();
</script>

<div>
  {data.label}
</div>

<Handle type="target" position={Position.Left} />
<Handle type="source" position={Position.Right} />
```

## 屬性

`<Handle />` 元件的屬性類型導出為 `HandleProps`。此外，它擴展了 `<div />` 的屬性。

## 範例

### 帶驗證的自訂控制點

你可以透過包裝 `<Handle />` 元件來建立自己的自訂控制點。
此範例展示了一個自訂控制點，只在連接來源符合給定 id 時才允許連接。

```svelte
<script lang="ts">
	import { Handle, type HandleProps  } from '@xyflow/svelte';

	let { source, ...rest } : HandleProps = $props();

	function isValidConnection(connection) {
		return connection.source === source;
	}
</script>

<Handle
	type="target"
	{isValidConnection}
	{...rest}
/>
```

### 連接時為控制點設定樣式

當連接線位於控制點上方時，控制點會接收額外的 `connecting` 類別名稱，
如果連接有效則會接收 `valid` 類別名稱。你可以在[這裡](/examples/interaction/validation)找到
使用這些類別的範例。

### 多個控制點

如果你需要多個來源或目標控制點，可以透過建立自訂節點來實現。
通常你只使用節點的 id 作為連線的 `source` 或 `target`。
如果你有多個來源或目標控制點，則需要為這些控制點傳遞一個 id。
這些 id 可以透過連線的 `sourceHandle` 和 `targetHandle` 選項使用，
以便你可以連接到特定的控制點。如果你有一個 `id: 'node-1'` 的節點和
一個 `id: 'handle-1'` 的控制點，你可以透過定義 `source: 'node-1'` 和
`sourceHandle: 'hadnle-1'` 來將連線連接到此控制點。

### 動態控制點

如果你在自訂節點中以程式方式更改控制點的位置或數量，
你需要使用 [`useUpdateNodeInternals`](/api-reference/hooks/use-update-node-internals) hook
來更新節點內部。

你可以在[自訂節點指南](/learn/customization/custom-nodes)或
[自訂節點範例](/examples/nodes/custom-node)中找到如何實作具有多個控制點的自訂節點的範例。

### 自訂控制點樣式

由於控制點是一個 div，你可以使用 CSS 來設定其樣式，或傳遞一個 style 屬性來
自訂控制點。你可以在
[在連線上加入節點](/examples/nodes/add-node-on-edge-drop)和
[簡單浮動連線](/examples/edges/simple-floating-edges)範例中看到這點。
