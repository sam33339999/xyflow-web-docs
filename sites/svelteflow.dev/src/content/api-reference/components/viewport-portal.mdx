# &lt;ViewportPortal />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/react/src/components/ViewportPortal/index.tsx)

`<ViewportPortal />` 元件可用於將元件加入到流程視口中，與節點和連線在相同位置渲染。
當你想要渲染自己的元件並讓它們遵循與節點和連線相同的座標系統，且同樣受到縮放和平移影響時，這非常有用。

```svelte
<script lang="ts">
import { ViewportPortal } from '@xyflow/svelte';
</script>

<ViewportPortal>
  <div style:transform="translate(100px, 100px)" style:position="absolute">
    This div is positioned at [100, 100] on the flow.
  </div>
</ViewportPortal>
```

你也可以使用 `target` 屬性來定義要將元件渲染在節點和連線的下方還是上方。

```svelte
<script lang="ts">
import { ViewportPortal } from '@xyflow/svelte';
</script>

<ViewportPortal target="front">
  <div style:transform="translate(100px, 100px)" style:position="absolute">
    This div is positioned at [100, 100] on the flow.
  </div>
</ViewportPortal>
```

## 屬性

`<ViewportPortal />` 元件的屬性類型導出為 `ViewportPortalProps`。此外，它擴展了 `<div />` 的屬性。
