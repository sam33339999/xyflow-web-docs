# \<BaseEdge />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/components/edges/BaseEdge.svelte)

`<BaseEdge />` 元件在內部用於所有連線。它可以在自訂連線中使用，
並為你處理不可見的輔助連線和連線標籤。

```svelte filename="CustomEdge.svelte"
<script lang="ts">
  import { BaseEdge, getBezierPath, type EdgeProps } from '@xyflow/svelte';

  let { sourceX, sourceY, targetX, targetY, ...props } : EdgeProps = $props();

  const [edgePath] = $derived(getBezierPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
  }));

  const {
    markerStart,
    markerEnd,
    interactionWidth,
    label,
    labelStyle,
  } = props;
</script>

<BaseEdge
  path={edgePath}
  {markerStart}
  {markerEnd}
  {interactionWidth}
  {label}
  {labelStyle}
/>
```

## 屬性

`<BaseEdge />` 元件的屬性類型導出為 `BaseEdgeProps`。
此外，它擴展了 `<svg />` 的屬性。

<APIDocs
  componentName="BaseEdge"
  groupKeys="Omit<HTMLAttributes<SVGPathElement>, 'd' | 'path' | 'markerStart' | 'markerEnd'>"
/>

## 注意事項

- 如果你想要在 `<BaseEdge />` 元件中使用連線標記，可以將傳遞給自訂連線的
  `markerStart` 或 `markerEnd` 屬性傳遞給 `<BaseEdge />` 元件。
  你可以透過查看 [`EdgeProps`](/api-reference/types/edge-props) 類型來查看
  傳遞給自訂連線的所有屬性。
