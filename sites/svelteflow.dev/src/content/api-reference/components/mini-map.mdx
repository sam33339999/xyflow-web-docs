# \<MiniMap />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/plugins/Minimap/Minimap.svelte)

`<MiniMap />` 元件可用於渲染你的流程概覽。它將每個節點渲染為 SVG 元素，
並視覺化顯示目前視口相對於流程其他部分的位置。

```svelte
<script lang="ts">
  import { SvelteFlow, MiniMap } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([]);
  let edges = $state.raw([]);
</script>

<SvelteFlow bind:nodes bind:edges>
  <MiniMap nodeStrokeWidth={3} />
</SvelteFlow>
```

## 屬性

`<MiniMap />` 元件的屬性類型導出為 `MiniMapProps`。此外，它擴展了 `<div />` 的屬性。

<APIDocs componentName="MiniMap" groupKeys="HTMLAttributes<HTMLDivElement>" />

## 範例

### 讓小地圖可互動

預設情況下，小地圖是不可互動的。若要允許使用者透過平移或縮放小地圖來與視口互動，
你可以將 `zoomable` 或 `pannable`（或兩者！）屬性設定為 `true`。

```svelte
<script lang="ts">
  import { SvelteFlow, MiniMap } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([]);
  let edges = $state.raw([]);
</script>


<SvelteFlow bind:nodes bind:edges>
  <MiniMap pannable zoomable />
</SvelteFlow>
```

### 自訂小地圖節點顏色

`nodeColor`、`nodeStrokeColor` 和 `nodeClassName` 屬性可以是一個函數，
它接受一個 [`Node`](/api-reference/types/node) 並計算該屬性的值。這可以用來
自訂每個小地圖節點的外觀。

此範例展示如何根據節點類型為每個小地圖節點著色：

```svelte
<script lang="ts">
  import { SvelteFlow, MiniMap } from '@xyflow/svelte';
  import '@xyflow/svelte/dist/style.css';

  let nodes = $state.raw([]);
  let edges = $state.raw([]);

  function nodeColor(node) {
    return node.type === 'input' ? 'blue' : 'red';
  }
</script>

<SvelteFlow bind:nodes bind:edges>
  <MiniMap nodeColor={nodeColor} />
</SvelteFlow>
```
