# &lt;EdgeReconnectAnchor />

如果你想要讓連線可以更新，可以使用 `<EdgeReconnectAnchor />` 元件。此元件用於在你的自訂連線上建立重新連接點。它們的行為類似於控制點：

1. 你可以在 `<EdgeReconnectAnchor />` 上開始拖曳
2. 這會從連線的另一側開始一個新的連接過程
3. 你可以像從控制點開始一樣完成連接

```svelte filename="CustomEdge.svelte"
<script lang="ts">
  import {
    BaseEdge,
    EdgeReconnectAnchor,
    getBezierPath,
    type EdgeProps,
  } from '@xyflow/svelte';

  let { sourceX, sourceY, targetX, targetY, selected, data, ...props }: EdgeProps = $props();

  const [edgePath] = $derived(getBezierPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
  }));

  let reconnecting = $state(false);
</script>

<!-- We want to hide the initial edge while reconnecting -->
{#if !reconnecting}
  <BaseEdge path={edgePath} {...props} />
{/if}

<!-- We only want to be able to reconnect when an edge is selected  -->
{#if selected}
  <EdgeReconnectAnchor
    bind:reconnecting
    type="source"
    position={{ x: sourceX, y: sourceY }}
  />
  <EdgeReconnectAnchor
    bind:reconnecting
    type="target"
    position={{ x: targetX, y: targetY }}
  />
{/if}
```

此範例會渲染不可見的重新連接點。當然，你也可以在 `<EdgeReconnectAnchor />` 元件內渲染圖示。

## 屬性

`<EdgeReconnectAnchor />` 元件的屬性類型導出為 `EdgeReconnectAnchorProps`。此外，它擴展了 `<div />` 的屬性。
