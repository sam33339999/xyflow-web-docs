# &lt;Background />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/plugins/Background/Background.svelte)

`<Background />` 元件讓你能夠方便地渲染節點式 UI 中常見的不同類型背景。
它提供三種變體：`lines`、`dots` 和 `cross`。

```svelte
<script lang="ts">
  import { SvelteFlow, Background, BackgroundVariant } from '@xyflow/svelte';

  let nodes = $state.raw([]);
  let edges = $state.raw([]);
</script>

<SvelteFlow bind:nodes bind:edges>
  <Background bgColor="#ccc" variant={BackgroundVariant.Dots} />
</SvelteFlow>
```

## 屬性

`<Background />` 元件的屬性類型導出為 `BackgroundProps`。
