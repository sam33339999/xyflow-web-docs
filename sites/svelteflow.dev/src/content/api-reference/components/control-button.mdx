# \<ControlButton />

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/svelte/src/lib/plugins/Controls/ControlButton.svelte)

`<ControlButton />` 元件用於為 `<Controls />` 元件渲染自訂或額外的按鈕。

```svelte
<script lang="ts">
  import { Controls, ControlButton } from '@xyflow/svelte';
</script>

<Controls>
  <ControlButton onclick={() => console.log('⚡️')}>
    ⚡️
  </ControlButton>
</Controls>
```

## 屬性

`<ControlButton />` 元件的屬性類型導出為 `ControlButtonProps`。此外，它擴展了 `<button />` 的屬性。
