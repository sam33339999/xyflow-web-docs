# getOutgoers()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L79-L80)

此工具函式用於告訴你哪些節點（如果有的話）作為邊緣的目標節點，連接到給定的節點。

```ts
import { getOutgoers } from '@xyflow/svelte';

let nodes = $state.raw([]);
let edges = $state.raw([]);

const incomers = getOutgoers(
  { id: '1', position: { x: 0, y: 0 }, data: { label: 'node' } },
  nodes.value,
  edges.value,
);
```
