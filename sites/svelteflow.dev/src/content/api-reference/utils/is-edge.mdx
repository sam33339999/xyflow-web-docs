# isEdge()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/v11/packages/core/src/utils/graph.ts/#L19)

測試一個物件是否可作為 [`Edge`](/api-reference/types/edge) 使用。在 TypeScript 中，這是一個型別守衛，如果返回 `true`，將會把你傳入的任何類型縮窄為 [`Edge`](/api-reference/types/edge) 型別。

```js
import { isEdge } from '@xyflow/svelte';

const edge = {
  id: 'edge-a',
  source: 'a',
  target: 'b',
};

if (isEdge(edge)) {
  // ..
}
```
