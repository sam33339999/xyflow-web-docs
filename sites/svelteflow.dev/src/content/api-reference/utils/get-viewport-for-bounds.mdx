# getViewportForBounds()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/general.ts/#L293-L294)

此工具函式會返回給定邊界的視窗。你可以使用它在伺服器上預先計算給定節點集合的視窗，或者在不直接變更視窗的情況下計算給定邊界的視窗。

```js
import { getViewportForBounds } from '@xyflow/svelte';

const { x, y, zoom } = getViewportForBounds(
  {
    x: 0,
    y: 0,
    width: 100,
    height: 100,
  },
  1200,
  800,
  0.5,
  2,
);
```

## 注意事項

- 這是一個相當低階的工具函式。你可能會想要查看 [`fitView`](/api-reference/hooks/use-svelte-flow#fitview) 或 [`fitBounds`](/api-reference/hooks/use-svelte-flow#fitbounds) 方法，以獲得更實用的 API。
