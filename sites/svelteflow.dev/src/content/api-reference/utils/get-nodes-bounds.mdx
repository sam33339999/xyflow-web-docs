# getNodesBounds()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L195-L229)

返回包含陣列中所有給定節點的邊界框。這在與 [`getViewportForBounds`](/api-reference/utils/get-viewport-for-bounds) 結合使用時很有用，可以計算正確的轉換以將給定的節點適配到視窗中。

<Callout type="info">
  此函式先前稱為 `getRectOfNodes`，將在 v12 中移除。
</Callout>

```js
import { getNodesBounds } from '@xyflow/svelte';

let nodes = $state.raw([
  {
    id: 'a',
    position: { x: 0, y: 0 },
    data: { label: 'a' },
    width: 50,
    height: 25,
  },
  {
    id: 'b',
    position: { x: 100, y: 100 },
    data: { label: 'b' },
    width: 50,
    height: 25,
  },
]);

const bounds = getNodesBounds(nodes.value);
```
