# getSmoothStepPath()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/edges/smoothstep-edge.ts/#L244-L245)

`getSmoothStepPath` 工具函式會返回在兩個節點之間渲染階梯路徑所需的所有內容。`borderRadius` 屬性可用於選擇這些階梯的圓角程度。

```js
import { Position, getSmoothStepPath } from '@xyflow/svelte';

const source = { x: 0, y: 20 };
const target = { x: 150, y: 100 };

const [path, labelX, labelY, offsetX, offsetY] = getSmoothStepPath({
  sourceX: source.x,
  sourceY: source.y,
  sourcePosition: Position.Right,
  targetX: target.x,
  targetY: target.y,
  targetPosition: Position.Left,
});

console.log(path); //=> "M0 20L20 20L 70,20Q 75,20 75,25L 75,95Q ..."
console.log(labelX, labelY); //=> 75, 60
console.log(offsetX, offsetY); //=> 75, 40
```

## 注意事項

- 此函式返回一個元組（即固定大小的陣列），讓你更容易同時處理多個邊緣路徑。
- 你可以將 `borderRadius` 屬性設定為 `0` 來獲得階梯邊緣路徑。
