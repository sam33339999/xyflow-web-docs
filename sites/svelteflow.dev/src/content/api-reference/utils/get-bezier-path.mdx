# getBezierPath()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/edges/bezier-edge.ts/#L95)

`getBezierPath` 工具函式會返回在兩個節點之間渲染貝茲曲線邊緣所需的所有內容。

```js
import { Position, getBezierPath } from '@xyflow/svelte';

const source = { x: 0, y: 20 };
const target = { x: 150, y: 100 };

const [path, labelX, labelY, offsetX, offsetY] = getBezierPath({
  sourceX: source.x,
  sourceY: source.y,
  sourcePosition: Position.Right,
  targetX: target.x,
  targetY: target.y,
  targetPosition: Position.Left,
});

console.log(path); //=> "M0,20 C75,20 75,100 150,100"
console.log(labelX, labelY); //=> 75, 60
console.log(offsetX, offsetY); //=> 75, 40
```

## 注意事項

- 此函式返回一個元組（即固定大小的陣列），讓你更容易同時處理多個邊緣路徑。
