# isNode()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/v11/packages/core/src/utils/graph.ts/#L22)

測試一個物件是否可作為 [`Node`](/api-reference/types/node) 使用。在 TypeScript 中，這是一個型別守衛，如果返回 `true`，將會把你傳入的任何類型縮窄為 [`Node`](/api-reference/types/node) 型別。

```js
import { isNode } from '@xyflow/svelte';

const node = {
  id: 'node-a',
  data: {
    label: 'node',
  },
  position: {
    x: 0,
    y: 0,
  },
};

if (isNode(node)) {
  // ..
}
```
