# addEdge()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/edges/general.ts/#L104-L138)

此工具函式是一個便利函式，用於將新的 [`Edge`](/api-reference/types/edge) 加入到邊緣陣列中。它還會執行一些驗證，以確保你不會加入無效的邊緣或重複現有的邊緣。

```js
import { addEdge } from '@xyflow/svelte';

let edges = $state.raw([]);

const onAddEdge = () => {
  const newEdge = {
    id: '1-2',
    source: '1',
    target: '2',
  };
  edges = addEdge(newEdge, edges.current);
};
```

## 注意事項

- 如果已經存在具有相同 `target` 和 `source` 的邊緣（以及相同的 `targetHandle` 和 `sourceHandle`，如果有設定的話），那麼即使 `id` 屬性不同，此工具函式也不會加入新的邊緣。
