# getConnectedEdges()

[在 GitHub 上查看原始碼](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L327-L337)

給定一個可能相互連接的節點陣列以及所有邊緣的陣列，此工具函式會返回連接任何給定節點的邊緣陣列。

```js
import { getConnectedEdges } from '@xyflow/svelte';

let nodes = $state.raw([]);
let edges = $state.raw([]);

const connectedEdges = getConnectedEdges(nodes.value, edges.value);
```
