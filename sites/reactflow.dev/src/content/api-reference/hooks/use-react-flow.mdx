# useReactFlow()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/hooks/useReactFlow.ts)

這個 hook 返回一個 [`ReactFlowInstance`](/api-reference/types/react-flow-instance)，可用於更新節點和連線、操作視窗或查詢流程的當前狀態。

```jsx
import { useCallback, useState } from 'react';
import { useReactFlow } from '@xyflow/react';

export function NodeCounter() {
  const reactFlow = useReactFlow();
  const [count, setCount] = useState(0);
  const countNodes = useCallback(() => {
    setCount(reactFlow.getNodes().length);
    // 如果你在 useEffect 或 useCallback 中使用它，需要將它作為依賴項傳入
    // 因為在第一次渲染時，它尚未初始化，某些函式可能無法運作。
  }, [reactFlow]);

  return (
    <div>
      <button onClick={countNodes}>Update count</button>
      <p>There are {count} nodes in the flow.</p>
    </div>
  );
}
```

## TypeScript

這個 hook 接受自訂節點和連線類型的泛型參數。查看我們 TypeScript 指南中的[此章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)以獲取更多資訊。

```tsx
const reactFlow = useReactFlow<CustomNodeType, CustomEdgeType>();
```

## 注意事項

- 這個 hook 只能在 [`<ReactFlowProvider />`](/api-reference/react-flow-provider) 或 [`<ReactFlow />`](/api-reference/react-flow) 元件的子元件中使用。
- 與 [`useNodes`](/api-reference/hooks/use-nodes) 或 [`useEdges`](/api-reference/hooks/use-edges) 不同，這個 hook 不會在狀態變更時導致元件重新渲染。相反地，你可以在需要時透過這個 hook 返回的 [`ReactFlowInstance`](/api-reference/types/react-flow-instance) 上的方法來查詢狀態。
