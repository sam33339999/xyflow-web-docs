# useStore()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/hooks/useStore.ts)

這個 hook 可用於訂閱 React Flow 元件的內部狀態變更。`useStore` hook 是從 [Zustand](https://github.com/pmndrs/zustand) 狀態管理函式庫重新匯出的，因此你應該查看他們的文件以獲取更多詳細資訊。

<Callout type="info">
  這個 hook 只應在沒有其他方式可以存取內部狀態時使用。對於許多常見的使用情境，都有專門的 hook 可用，例如 [`useReactFlow`](/api-reference/hooks/use-react-flow)、[`useViewport`](/api-reference/hooks/use-viewport) 等。
</Callout>

```jsx
import { ReactFlow, useStore } from '@xyflow/react';

const nodesLengthSelector = (state) =>
  state.nodes.length || 0;

const NodesLengthDisplay = () => {
  const nodesLength = useStore(nodesLengthSelector);

  return <div>The current number of nodes is: {nodesLength}</div>;
};

function Flow() {
  return (
    <ReactFlow nodes={[...]}>
      <NodesLengthDisplay />
    </ReactFlow>
  );
}
```

這個範例會急切地計算節點數量。每當流程中的節點數量變更時，`<NodesLengthDisplay />` 元件都會重新渲染。這與 [`useStoreApi`](/api-reference/hooks/use-store-api) hook 的範例形成對比，後者只在按下按鈕時計算節點數量。

選擇按需計算值或訂閱變更是一種平衡取捨。一方面，在事件處理器中放入太多繁重的計算可能會讓你的應用程式感覺遲緩或無回應。另一方面，急切地計算值可能會導致緩慢或不必要的重新渲染。

我們提供這個 hook 和 [`useStoreApi`](/api-reference/hooks/use-store-api)，讓你可以選擇最適合你使用情境的方法。

## 範例

### 觸發 store 操作

你可以透過 `useStore` hook 觸發內部操作來操作 React Flow 的內部狀態。這些操作已經在整個函式庫內部使用，但你也可以使用它們來實作自訂功能。

```jsx
import { useStore } from '@xyflow/react';

const setMinZoomSelector = (state) => state.setMinZoom;

function MinZoomSetter() {
  const setMinZoom = useStore(setMinZoomSelector);

  return <button onClick={() => setMinZoom(6)}>set min zoom</button>;
}
```

## TypeScript

這個 hook 可以透過對選擇器函式進行型別定義來設定型別。查看我們 TypeScript 指南中的[此章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)以獲取更多資訊。

```tsx
const nodes = useStore((s: ReactFlowState<CustomNodeType>) => s.nodes);
```
