# useInternalNode()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/hooks/useInternalNode.ts)

這個 hook 返回特定節點的內部表示。使用此 hook 的元件會在**任何節點變更時**重新渲染，包括節點被選取或移動時。

```jsx
import { useInternalNode } from '@xyflow/react';

export default function () {
  const internalNode = useInternalNode('node-1');
  const absolutePosition = internalNode.internals.positionAbsolute;

  return (
    <div>
      The absolute position of the node is at:
      <p>x: {absolutePosition.x}</p>
      <p>y: {absolutePosition.y}</p>
    </div>
  );
}
```

## TypeScript

這個 hook 接受自訂節點類型的泛型參數。查看我們 TypeScript 指南中的[此章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)以獲取更多資訊。

```tsx
const internalNode = useInternalNode<CustomNodeType>();
```
