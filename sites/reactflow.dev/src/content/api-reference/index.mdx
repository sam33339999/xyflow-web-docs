## 給 JavaScript 使用者的說明

React Flow 是用 TypeScript 撰寫的，但我們知道並非每個人都使用它。我們鼓勵開發者使用最適合他們的技術，在我們的文件中也混合了 TypeScript 和 JavaScript 的範例。

然而，對於我們的 API 參考，我們使用 TypeScript 的語法來記錄屬性和函式的類型。這裡有一個如何閱讀它的快速入門：

• `?` 表示該欄位或參數是可選的。

• `<T>` 在類型定義中表示一個泛型型別參數。就像函式參數，但用於類型！定義 `type Array<T> = ...` 表示一個名為 `Array` 的類型，它接受一個泛型型別參數 `T`。

• `<T>` 在引用類型時就像是「填入」一個泛型型別參數。就像呼叫一個函式，但用於類型！類型 `Array<number>` 是 `Array` 類型，其泛型型別參數 `T` 填入了類型 `number`。

• `T | U` 表示該類型是 `T` 或 `U`：這通常稱為_聯集（union）_。

• `T & U` 表示該類型同時是 `T` 和 `U`：這通常稱為_交集（intersection）_。

TypeScript 團隊有他們自己的[閱讀類型的實用指南](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html)，您可能會覺得有用。如果您還是卡住了，歡迎到我們的 [Discord](https://discord.com/invite/RVmnytFmGW) 尋求協助！
