# addEdge()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/edges/general.ts/#L100)

這個工具函式可以方便地將新的 [`Edge`](/api-reference/types/edge) 新增到連線陣列中。它還會執行一些驗證，以確保您不會新增無效的連線或重複現有的連線。

```js
import { useCallback } from 'react';
import {
  ReactFlow,
  addEdge,
  useNodesState,
  useEdgesState,
} from '@xyflow/react';

export default function Flow() {
  const [nodes, setNodes, onNodesChange] = useNodesState([]);
  const [edges, setEdges, onEdgesChange] = useEdgesState([]);
  const onConnect = useCallback(
    (connection) => {
      setEdges((oldEdges) => addEdge(connection, oldEdges));
    },
    [setEdges],
  );

  return <ReactFlow nodes={nodes} edges={edges} onConnect={onConnect} />;
}
```

## Notes

- 如果已經存在具有相同 `target` 和 `source` 的連線（如果有設定，還包括相同的 `targetHandle` 和 `sourceHandle`），則即使 `id` 屬性不同，此工具函式也不會新增新的連線。
