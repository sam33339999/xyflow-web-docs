# getNodesBounds()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L133)

返回包含陣列中所有給定節點的邊界框。這在與 [`getViewportForBounds`](/api-reference/utils/get-viewport-for-bounds) 結合使用時很有用，可以計算正確的轉換以使給定的節點適應視窗。

> [!NOTE]
>
> 此函式先前稱為 `getRectOfNodes`

```js
import { getNodesBounds } from '@xyflow/react';

const nodes = [
  {
    id: 'a',
    position: { x: 0, y: 0 },
    data: { label: 'a' },
    width: 50,
    height: 25,
  },
  {
    id: 'b',
    position: { x: 100, y: 100 },
    data: { label: 'b' },
    width: 50,
    height: 25,
  },
];

const bounds = getNodesBounds(nodes);
```
