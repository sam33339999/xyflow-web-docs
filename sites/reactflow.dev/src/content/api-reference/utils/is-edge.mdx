# isEdge()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L39-L40)

測試物件是否可作為 [`Edge`](/api-reference/types/edge) 使用。在 TypeScript 中，這是一個型別守衛，如果返回 `true`，則會將您傳入的任何內容的型別縮小為 [`Edge`](/api-reference/types/edge)。

```js
import { isEdge } from '@xyflow/react';

const edge = {
  id: 'edge-a',
  source: 'a',
  target: 'b',
};

if (isEdge(edge)) {
  // ...
}
```
