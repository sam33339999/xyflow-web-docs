# isNode()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/graph.ts/#L49)

測試物件是否可作為 [`Node`](/api-reference/types/node) 使用。在 TypeScript 中，這是一個型別守衛，如果返回 `true`，則會將您傳入的任何內容的型別縮小為 [`Node`](/api-reference/types/node)。

```js
import { isNode } from '@xyflow/react';

const node = {
  id: 'node-a',
  data: {
    label: 'node',
  },
  position: {
    x: 0,
    y: 0,
  },
};

if (isNode(node)) {
  // ..
}
```
