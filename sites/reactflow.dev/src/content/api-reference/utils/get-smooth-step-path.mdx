# getSmoothStepPath()

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/utils/edges/smoothstep-edge.ts/#L215)

`getSmoothStepPath` 工具函式會返回在兩個節點之間渲染階梯路徑所需的所有資訊。`borderRadius` 屬性可用於選擇這些階梯轉角的圓滑程度。

```js
import { Position, getSmoothStepPath } from '@xyflow/react';

const source = { x: 0, y: 20 };
const target = { x: 150, y: 100 };

const [path, labelX, labelY, offsetX, offsetY] = getSmoothStepPath({
  sourceX: source.x,
  sourceY: source.y,
  sourcePosition: Position.Right,
  targetX: target.x,
  targetY: target.y,
  targetPosition: Position.Left,
});

console.log(path); //=> "M0 20L20 20L 70,20Q 75,20 75,25L 75,95Q ..."
console.log(labelX, labelY); //=> 75, 60
console.log(offsetX, offsetY); //=> 75, 40
```

## Notes

- 此函式返回一個元組（即固定大小的陣列），以便更輕鬆地同時處理多個連線路徑。
- 您可以將 `borderRadius` 屬性設定為 `0` 以獲得階梯連線路徑。
