# \<ReactFlowProvider />

[GitHub 原始碼](https://github.com/xyflow/xyflow/blob/main/packages/react/src/components/ReactFlowProvider/index.tsx/#L9)

`<ReactFlowProvider />` 元件是一個 [context provider](https://react.dev/learn/passing-data-deeply-with-context#)，使得可以在 [`<ReactFlow />`](/api-reference/react-flow) 元件外部存取流程的內部狀態。我們提供的許多 hook 都依賴於此元件才能運作。

```tsx
import { ReactFlow, ReactFlowProvider, useNodes } from '@xyflow/react'

export default function Flow() {
  return (
    <ReactFlowProvider>
      <ReactFlow nodes={...} edges={...} />
      <Sidebar />
    </ReactFlowProvider>
  )
}

function Sidebar() {
  // 此 hook 只有在使用它的元件是 <ReactFlowProvider /> 的子元件時才能運作。
  const nodes = useNodes()

  return (
    <aside>
      {nodes.map((node) => (
        <div key={node.id}>
          節點 {node.id} -
            x: {node.position.x.toFixed(2)},
            y: {node.position.y.toFixed(2)}
        </div>
      ))}
    </aside>
  )
}
```

## 注意事項

- 如果您使用路由器並希望流程狀態在不同路由之間保持，那麼將 `<ReactFlowProvider />` 元件放置在路由器_外部_至關重要。
- 如果您在同一頁面上有多個流程，則需要為每個流程使用單獨的 `<ReactFlowProvider />`。
