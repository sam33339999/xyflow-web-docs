# \<ReactFlow />

[GitHub 原始碼](https://github.com/xyflow/xyflow/blob/main/packages/react/src/container/ReactFlow/index.tsx/#L47)

`<ReactFlow />` 元件是您的 React Flow 應用程式的核心。它會渲染您的節點和連線、處理使用者互動，並且如果用作[非受控流程](/learn/advanced-use/uncontrolled-flow)時，可以管理自己的狀態。

```tsx
import { ReactFlow } from '@xyflow/react'

export default function Flow() {
  return <ReactFlow
    nodes={...}
    edges={...}
    onNodesChange={...}
    ...
  />
}
```

此元件接受許多不同的屬性，其中大多數是可選的。我們嘗試將它們按有意義的群組進行記錄，以幫助您找到所需的內容。

## 鍵盤屬性

React Flow 允許您傳入一些不同的鍵盤快捷鍵，作為與流程互動的另一種方式。我們嘗試設定合理的預設值，例如使用退格鍵刪除任何選取的節點或連線，但您可以使用這些屬性來設定自己的快捷鍵。

要停用任何這些快捷鍵，請將 `null` 傳遞給您想要停用的屬性。

<ReactFlowAPIProps group="keyboard" />
