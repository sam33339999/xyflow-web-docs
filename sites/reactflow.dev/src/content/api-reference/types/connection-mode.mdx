# ConnectionMode

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L68)

`ConnectionMode` 列舉提供了 React Flow 中連接行為的兩個選項：

- `Strict`：連接只能從來源連接點開始，並在目標連接點結束
- `Loose`：連接可以在任何連接點之間建立，不論類型

```ts
enum ConnectionMode {
  Strict = 'strict',
  Loose = 'loose',
}
```
