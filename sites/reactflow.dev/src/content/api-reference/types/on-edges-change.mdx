# OnEdgesChange

此類型用於為 [`onEdgesChange`](/api-reference/react-flow#on-edges-change) 函數進行型別定義。

```tsx
export type OnEdgesChange<EdgeType extends Edge = Edge> = (
  changes: EdgeChange<EdgeType>[],
) => void;
```

## 使用方式

此類型接受自訂連線類型的泛型參數。更多資訊請參閱我們的 [TypeScript 指南中的這個章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)。

```tsx
const onEdgesChange: OnEdgesChange = useCallback(
  (changes) => setEdges((eds) => applyEdgeChanges(changes, eds)),
  [setEdges],
);
```
