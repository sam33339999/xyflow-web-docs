# PanelPosition

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts/#L111-L112)

此類型主要用於幫助在流程視口頂部定位元素。例如，[`<MiniMap />`](/api-reference/components/minimap) 和 [`<Controls />`](/api-reference/components/controls) 元件都接受此類型的 `position` prop。

```ts
export type PanelPosition =
  | 'top-left'
  | 'top-center'
  | 'top-right'
  | 'bottom-left'
  | 'bottom-center'
  | 'bottom-right'
  | 'center-left'
  | 'center-right';
```
