# Edge

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/types/edges.ts/#L34-L353)

[`Connection`](/api-reference/types/connection) 是兩個節點之間連線的最小描述，而 `Edge` 則是包含 React Flow 渲染所需所有資訊的完整描述。

```ts
export type Edge<T> = DefaultEdge<T> | SmoothStepEdge<T> | BezierEdge<T>;
```

## 預設連線類型

你可以透過將 `type` 屬性設定為以下值之一來建立 React Flow 的任何預設連線：

- `"default"`
- `"straight"`
- `"step"`
- `"smoothstep"`
- `"simplebezier"`

如果你完全不設定 `type` 屬性，React Flow 將預設使用 `"default"` 貝茲曲線連線類型。

即使你將 [`edgeTypes`](/api-reference/react-flow#edge-types) 屬性設定為其他值，這些預設連線仍然可用，除非你直接覆寫這些鍵值。
