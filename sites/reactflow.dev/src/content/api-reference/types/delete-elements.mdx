# DeleteElements

DeleteElements 刪除提供的節點和連線，並處理刪除任何相連的連線以及子節點。以非同步方式回傳成功刪除的連線和節點。

```ts
export type DeleteElements = (payload: {
  nodes?: (Partial<Node> & { id: Node['id'] })[];
  edges?: (Partial<Edge> & { id: Edge['id'] })[];
}) => Promise<{
  deletedNodes: Node[];
  deletedEdges: Edge[];
}>;
```
