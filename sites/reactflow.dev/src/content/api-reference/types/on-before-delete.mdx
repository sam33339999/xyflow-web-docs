# OnBeforeDelete

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/types/general.ts#L207)

`OnBeforeDelete` 類型定義了在節點或連線被刪除之前呼叫的回呼函數。此回呼接收一個包含即將被刪除的節點和連線的物件。

```ts
type OnBeforeDelete = (params: {
  nodes: Node[];
  edges: Edge[];
}) => Promise<boolean | {
  nodes: Node[];
  edges: Edge[];
})>;
```
