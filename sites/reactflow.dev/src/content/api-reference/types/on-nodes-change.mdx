# OnNodesChange

此類型用於為 [`onNodesChange`](/api-reference/react-flow#on-nodes-change) 函數進行型別定義。

```tsx
export type OnNodesChange<NodeType extends Node = Node> = (
  changes: NodeChange<NodeType>[],
) => void;
```

## 使用方式

此類型接受自訂節點類型的泛型參數。更多資訊請參閱我們的 [TypeScript 指南中的這個章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)。

```tsx
const onNodesChange: OnNodesChange = useCallback(
  (changes) => setNodes((nds) => applyNodeChanges(changes, nds)),
  [setNodes],
);
```
