# Position

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/utils.ts/#L1)

雖然 [`PanelPosition`](/api-reference/types/panel-position) 可用於將元件放置在容器的角落，但 `Position` 列舉較不精確，主要用於連線和連接點。

```ts
export enum Position {
  Left = 'left',
  Top = 'top',
  Right = 'right',
  Bottom = 'bottom',
}
```
