# Node

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/nodes.ts/#L10)

`Node` 類型代表 React Flow 需要了解的節點所有資訊。這些屬性中許多可以由 React Flow 或您操作，但某些屬性如 `width` 和 `height` 應視為唯讀。

## 預設節點類型

您可以透過將 `type` 屬性設定為以下值之一來建立任何 React Flow 的預設節點：

- `"default"`
- `"input"`
- `"output"`
- `"group"`

如果您完全不設定 `type` 屬性，React Flow 將退回到具有輸入和輸出端口的 `"default"` 節點。

即使您將 [`nodeTypes`](/api-reference/react-flow#node-types) prop 設定為其他內容，這些預設節點仍然可用，除非您直接覆寫任何這些鍵。

## 注意事項

- 您不應嘗試直接設定節點的 `width` 或 `height`。它由 React Flow 內部計算，並在視口中渲染節點時使用。要控制節點的大小，您應該使用 `style` 或 `className` props 來套用 CSS 樣式。
