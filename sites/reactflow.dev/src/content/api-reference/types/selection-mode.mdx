# SelectionMode

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/general.ts#L223)

`SelectionMode` 列舉提供兩種節點選擇行為選項：

- `Full`：只有當選擇矩形完全包含節點時才選中節點
- `Partial`：當選擇矩形部分重疊節點時就選中節點

```ts
enum SelectionMode {
  Partial = 'partial',
  Full = 'full',
}
```
