# NodeProps\<T>

[Source on GitHub](https://github.com/xyflow/xyflow/blob/main/packages/system/src/types/nodes.ts/#L89)

當您實作[自訂節點](/learn/customization/custom-nodes)時，它會被包裝在一個啟用基本功能（如選擇和拖曳）的元件中。

## 使用方式

```tsx
import { useState } from 'react';
import { NodeProps, Node } from '@xyflow/react';

export type CounterNode = Node<
  {
    initialCount?: number;
  },
  'counter'
>;

export default function CounterNode(props: NodeProps<CounterNode>) {
  const [count, setCount] = useState(props.data?.initialCount ?? 0);

  return (
    <div>
      <p>Count: {count}</p>
      <button className="nodrag" onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  );
}
```

記得透過將自訂節點添加到 `<ReactFlow />` 元件的 [`nodeTypes`](/api-reference/react-flow#nodetypes) prop 來註冊它。

```tsx
import { ReactFlow } from '@xyflow/react';
import CounterNode from './CounterNode';

const nodeTypes = {
  counterNode: CounterNode,
};

export default function App() {
  return <ReactFlow nodeTypes={nodeTypes} ... />
}
```

您可以在我們的[自訂節點指南](/learn/customization/custom-nodes)中閱讀更多資訊。
