# \<Handle />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/components/Handle/index.tsx)

`<Handle />` 元件用於在你的[自訂節點](/learn/customization/custom-nodes)中定義連接點。

```jsx
import { Handle, Position } from '@xyflow/react';

export const CustomNode = ({ data }) => {
  return (
    <>
      <div style={{ padding: '10px 20px' }}>
        {data.label}
      </div>

      <Handle type="target" position={Position.Left} />
      <Handle type="source" position={Position.Right} />
    </>
  );
};
```

## Props

對於 TypeScript 使用者，`<Handle />` 元件的 props 類型會以 `HandleProps` 導出。
