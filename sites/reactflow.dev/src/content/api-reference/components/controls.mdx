# \<Controls />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/additional-components/Controls/Controls.tsx)

`<Controls />` 元件渲染一個小面板，包含方便的按鈕可以放大、縮小、適應視圖和鎖定視窗。

```tsx
import { ReactFlow, Controls } from '@xyflow/react'

export default function Flow() {
  return (
    <ReactFlow nodes={[...]} edges={[...]}>
      <Controls />
    </ReactFlow>
  )
}
```

## Props

對於 TypeScript 使用者，`<Controls />` 元件的 props 類型會以 `ControlProps` 導出。

<APIDocs componentName="Controls" />

## 注意事項

- 若要擴展或自訂控制元件，你可以使用 [`<ControlButton />`](/api-reference/components/control-button) 元件
