# \<MiniMap />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/additional-components/MiniMap/MiniMap.tsx)

`<MiniMap />` 元件可用於渲染你的流程概覽。它將每個節點渲染為 SVG 元素，並視覺化顯示當前視窗相對於整個流程的位置。

```jsx
import { ReactFlow, MiniMap } from '@xyflow/react';

export default function Flow() {
  return (
    <ReactFlow nodes={[...]]} edges={[...]]}>
      <MiniMap nodeStrokeWidth={3} />
    </ReactFlow>
  );
}
```

## 範例

### 讓小地圖可互動

預設情況下，小地圖是不可互動的。若要允許使用者透過平移或縮放小地圖來與視窗互動，
你可以將 `zoomable` 或 `pannable`（或兩者！）props 設為 `true`。

```jsx
import { ReactFlow, MiniMap } from '@xyflow/react';

export default function Flow() {
  return (
    <ReactFlow nodes={[...]]} edges={[...]]}>
      <MiniMap pannable zoomable />
    </ReactFlow>
  );
}
```

### 實作自訂小地圖節點

可以將自訂元件傳遞給 `nodeComponent` prop，以改變節點在小地圖中的渲染方式。
如果你這樣做，若要讓它正常運作，**必須**在你的元件中僅使用 SVG 元素。

```jsx
import { ReactFlow, MiniMap } from '@xyflow/react';

export default function Flow() {
  return (
    <ReactFlow nodes={[...]]} edges={[...]]}>
      <MiniMap nodeComponent={MiniMapNode} />
    </ReactFlow>
  );
}

function MiniMapNode({ x, y }) {
  return <circle cx={x} cy={y} r="50" />;
}
```

查看 [`MiniMapNodeProps`](/api-reference/types/mini-map-node-props) 的文檔，
了解傳遞給你的自訂元件的 props。

### 自訂小地圖節點顏色

`nodeColor`、`nodeStrokeColor` 和 `nodeClassName` props 可以是一個函式，
該函式接受一個 [`Node`](/api-reference/types/node) 並計算該 prop 的值。
這可用於自訂每個小地圖節點的外觀。

此範例展示如何根據節點類型為每個小地圖節點著色：

```jsx
import { ReactFlow, MiniMap } from '@xyflow/react';

export default function Flow() {
  return (
    <ReactFlow nodes={[...]]} edges={[...]]}>
      <MiniMap nodeColor={nodeColor} />
    </ReactFlow>
  );
}

function nodeColor(node) {
  switch (node.type) {
    case 'input':
      return '#6ede87';
    case 'output':
      return '#6865A5';
    default:
      return '#ff0072';
  }
}
```

## TypeScript

此元件接受自訂節點類型的泛型類型參數。查看我們的 [TypeScript 指南中的這個章節](/learn/advanced-use/typescript#nodetype-edgetype-unions)以獲取更多資訊。

```tsx
<MiniMap<CustomNodeType> nodeColor={nodeColor} />
```
