# \<BaseEdge />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/components/Edges/BaseEdge.tsx)

`<BaseEdge />` 元件在內部用於所有連線。它可以在自訂連線中使用，並為你處理不可見的輔助連線和連線標籤。

```jsx
import { BaseEdge } from '@xyflow/react';

export function CustomEdge({ sourceX, sourceY, targetX, targetY, ...props }) {
  const [edgePath] = getStraightPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
  });

  const { label, labelStyle, markerStart, markerEnd, interactionWidth } = props;

  return (
    <BaseEdge
      path={edgePath}
      label={label}
      labelStyle={labelStyle}
      markerEnd={markerEnd}
      markerStart={markerStart}
      interactionWidth={interactionWidth}
    />
  );
}
```

## 注意事項

- 如果你想在 [`<BaseEdge />`](/api-reference/components/base-edge) 元件中使用連線標記，
  你可以將傳遞給自訂連線的 `markerStart` 或 `markerEnd` props 透傳到 [`<BaseEdge />`](/api-reference/components/base-edge) 元件。
  你可以透過查看 [`EdgeProps`](/api-reference/types/edge-props) 類型來了解傳遞給自訂連線的所有 props。
