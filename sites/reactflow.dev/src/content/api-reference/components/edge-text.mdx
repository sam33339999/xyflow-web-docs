# \<EdgeText />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/components/Edges/EdgeText.tsx)

你可以使用 `<EdgeText />` 元件作為輔助元件，在自訂連線中顯示文字。

```jsx
import { EdgeText } from '@xyflow/react';

export function CustomEdgeLabel({ label }) {
  return (
    <EdgeText
      x={100}
      y={100}
      label={label}
      labelStyle={{ fill: 'white' }}
      labelShowBg
      labelBgStyle={{ fill: 'red' }}
      labelBgPadding={[2, 4]}
      labelBgBorderRadius={2}
    />
  );
}
```

## Props

對於 TypeScript 使用者，`<EdgeText />` 元件的 props 類型會以 `EdgeTextProps` 導出。

<APIDocs componentName="EdgeText" groupKeys="Omit<SVGAttributes<SVGElement>, 'x' | 'y'>" />

此外，你也可以傳遞任何標準的 React HTML 屬性，如 `onClick`、`className` 等。
