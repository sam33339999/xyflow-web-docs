# \<EdgeToolbar />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/additional-components/EdgeToolbar/EdgeToolbar.tsx)

此元件可以在自訂連線的一側渲染工具列。此工具列不會隨視窗縮放，以便在縮小時內容不會變得太小。

```jsx
import { memo } from 'react';
import { EdgeToolbar, BaseEdge, getBezierPath, type EdgeProps } from '@xyflow/react';

function CustomEdge(props: EdgeProps) {
  const [edgePath, centerX, centerY] = getBezierPath(props);

  return (
    <>
      <BaseEdge id={props.id} path={edgePath} />
      <EdgeToolbar
        edgeId={props.id}
        x={centerX}
        y={centerY}
        isVisible
      >
        <button>
          some button
        </button>
      </EdgeToolbar>
    </>
  );
}

export default memo(CustomEdge);
```

## 注意事項

- 預設情況下，工具列僅在連線被選中時可見。你可以透過將 `isVisible` prop 設為 `true` 來覆蓋此行為。
