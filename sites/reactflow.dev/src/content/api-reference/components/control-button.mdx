# \<ControlButton />

[原始碼於 GitHub](https://github.com/xyflow/xyflow/blob/main/packages/react/src/additional-components/Controls/ControlButton.tsx)

你可以使用 `<ControlButton />` 元件將按鈕添加到控制面板，並將其作為 [`<Controls />`](/api-reference/components/controls) 元件的子元素傳遞。

```jsx
import { MagicWand } from '@radix-ui/react-icons'
import { ReactFlow, Controls, ControlButton } from '@xyflow/react'

export default function Flow() {
  return (
    <ReactFlow nodes={[...]} edges={[...]}>
      <Controls>
        <ControlButton onClick={() => alert('Something magical just happened. ✨')}>
          <MagicWand />
        </ControlButton>
      </Controls>
    </ReactFlow>
  )
}
```

## Props

`<ControlButton />` 元件接受任何在 HTML `<button />` 元素上有效的 prop。
