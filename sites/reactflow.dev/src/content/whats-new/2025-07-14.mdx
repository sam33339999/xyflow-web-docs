我們對 [React Flow UI](/ui)（以前稱為 React Flow 元件）進行了一些重大改進。這些變更增強了元件的功能、視覺外觀和可用性，以改善整體開發者體驗。

## 重新組織元件

一些元件已移至範例，而其他元件則已整合到新結構中：

- **Nodes Utilities**：這些元件可用作建立自訂節點的構建塊。
- **Custom Nodes**：這些是功能齊全的節點，可以直接在你的應用程式中使用。
- **Handles**：這些元件用於在節點內建立連接點。
- **Custom Edges**：功能齊全的連線，可以開箱即用。
- **Controls**：互動控制項集合。
- **Miscellaneous**：不適合其他類別的各種工具元件，如 [`DevTools`](/ui/components/devtools)。

在 [React Flow UI 頁面](/ui)中找到所有這些。

## `BaseNode` 增強功能

我們的 BaseNode 元件已經完全翻新，以提供與 [shadcn UI](https://ui.shadcn.com/) 和我們其餘的 [React Flow UI 元件庫](/ui)更一致的體驗。

新的 `BaseNode` 元件現在包含改進的樣式和包裝元件，符合 shadcn UI 設計原則。

就像 [shadcn UI Card 元件](https://ui.shadcn.com/docs/components/card) 一樣，[`BaseNode`](/ui/components/base-node) 元件現在匯出

- `BaseNodeHeader` 和 `BaseNodeHeaderTitle` 用於標頭部分，
- `BaseNodeContent` 用於主要內容區域，以及
- `BaseNodeFooter` 用於頁尾部分。

這種結構允許更好地組織節點內的內容，使建立複雜的節點布局變得更容易。

## 改進的範例和節點

我們還新增了一些新元件並改進了現有元件。我們的元件頁面現在包含更全面的範例，展示元件的新功能和能力。例如：

- 新的 [`NodeAppendix`](/ui/components/node-appendix) 元件，可用於向節點新增額外資訊或控制項，例如 [`Node Badge`](/ui/components/node-appendix#example-badge)！
- `AnnotationNode` 元件已移至 [`BaseNode` 的範例用法](/ui/components/base-node#example-annotation-node)，以展示如何設定 `BaseNode` 的樣式。
- [`StatusIndicator`](/ui/components/status-indicator) 現在包含一個帶有疊加旋轉器的變體，以及改進的用法範例。
- `TooltipNode` 元件已改進並移至 [`NodeTooltip`](/ui/components/node-tooltip)。它不再是自訂節點，而是一個工具元件，你可以使用它來將自訂節點包裝在工具提示中。

## 不再需要 `selected` prop

你不再需要將 `selected` prop 傳遞給 `BaseNode` 或其相關元件。選擇狀態的樣式現在由 tailwind CSS 選擇器自動處理。

但是，`selected` 仍然是 React Flow 中節點的有效 prop，你仍然可以使用它來確定節點在自訂元件中是否被選擇。如果你不需要 `selected` prop 用於自訂邏輯，而只是將它用於樣式，你可以安全地從元件中刪除它，並且可以按照 `BaseNode` 的實作方式為自訂選擇的節點實現自訂樣式。

```tsx
export const BaseNode = forwardRef<HTMLDivElement, HTMLAttributes<HTMLDivElement>>(
  ({ className, ...props }, ref) => (
    <div
      ref={ref}
      className={cn(
        'relative rounded-md border bg-card text-card-foreground',
        'hover:ring-1',
        // React Flow displays node elements inside of a `NodeWrapper` component,
        // which compiles down to a div with the class `react-flow__node`.
        // When a node is selected, the class `selected` is added to the
        // `react-flow__node` element. This allows us to style the node when it
        // is selected, using Tailwind's `&` selector.
        '[.react-flow\\_\\_node.selected_&]:border-muted-foreground',
        '[.react-flow\\_\\_node.selected_&]:shadow-lg',
        className,
      )}
      tabIndex={0}
      {...props}
    />
  ),
);
BaseNode.displayName = 'BaseNode';
```
