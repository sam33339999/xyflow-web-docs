我們的 [React Flow UI](/ui) 元件已更新以支援最新版本的 shadcn/ui，基於 React 19 和 Tailwind 4！

此更新包含來自最新版本 [shadcn/ui](https://ui.shadcn.com) 的全新外觀，以及一個新的 [UI 元件教學](/learn/tutorials/getting-started-with-react-flow-components)來幫助你入門。

### 如何升級你的專案

要升級你的專案，請按照以下步驟操作。

### 步驟 1：更新依賴項。

```bash copy npm2yarn
npm install react@latest react-dom@latest tailwindcss@latest
```

或在 package.json 中手動執行此操作，然後執行

```bash copy npm2yarn
npm install
```

### 步驟 2：執行 Tailwind CSS 升級 codemod。

在 [shadcn/ui Tailwind CSS 4 升級指南](https://ui.shadcn.com/docs/tailwind-v4)中閱讀更多關於可用 codemod 的資訊。

```bash copy npm2yarn
npx @tailwindcss/upgrade
```

### 步驟 3：將 React Flow 樣式移至 `global.css` 檔案。

**重要：** Tailwind CSS 4 現在完全在 CSS 中配置。你需要在 `global.css` 檔案中匯入 `@xyflow/react/dist/style.css` 檔案，而不是在 `App.tsx` 中匯入它，在匯入 `tailwindcss` 之後。

```diff filename="global.css"
// Tailwind CSS 3
-@tailwind base;
-@tailwind components;
-@tailwind utilities;

// Tailwind CSS 4
+@import "tailwindcss";
+@import "tw-animate-css";
+@layer base {
+  @import "@xyflow/react/dist/style.css";
+}
```

我們建議從專案中移除舊的 `js`/`ts` tailwind 配置，並遷移到新的僅 CSS 變數配置。這可以讓事情變得簡單得多：你可以在單個 CSS 檔案中配置與應用程式設計系統和外觀相關的所有內容。

```diff filename="App.tsx"
-import '@xyflow/react/dist/style.css';
import "./globals.css";

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

### 步驟 4：更新元件

對於你想要更新的每個元件，可以執行以下命令。

如果它是 shadcn/ui 元件：

```bash copy npm2yarn
npx shadcn@latest add component-name
```

如果它是 React Flow UI 元件：

```bash copy npm2yarn
npx shadcn@latest add https://ui.reactflow.dev/component-name
```
