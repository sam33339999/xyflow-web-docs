React Flow 的新版本發布了。透過 12.8.3，你可以獲得許多錯誤修正和連接點的重大改進。現在可以將連接點的子內容定位在連接點本身之外，並仍將其用作連線的起點，如你在此範例中所見：

<RemoteCodeViewer
  route="examples/nodes/detached-handle"
  framework="react"
  showEditor={false}
/>

### 修補變更

- [#5428](https://github.com/xyflow/xyflow/pull/5428) 能夠使用分離的連接點內容作為連線的起點
- [#5419](https://github.com/xyflow/xyflow/pull/5419) 當標記顏色為 null 時，讓連線標記回退到 `--xy-edge-stroke` CSS 變數
- [#5453](https://github.com/xyflow/xyflow/pull/5453) 當啟用對齊網格時，對齊選擇而不是單獨的節點
- [#5444](https://github.com/xyflow/xyflow/pull/5444) 匯出 `MiniMapNode` 以用於自訂縮圖節點
- [#5415](https://github.com/xyflow/xyflow/pull/5415) 允許字串和列舉用於標記類型
- [#5436](https://github.com/xyflow/xyflow/pull/5436) 當 interactionWidth 為 0 時，防止在連線的標記中新增 0
- [#5443](https://github.com/xyflow/xyflow/pull/5443) 使用 1 作為互動式縮圖縮放步驟的預設值
- [#5448](https://github.com/xyflow/xyflow/pull/5448) 為 Handle `onConnect` 使用正確的 `HandleConnection` 類型
- [#5420](https://github.com/xyflow/xyflow/pull/5420) 從 `Node` 的 `domAttributes` 中省略 `defaultValue`，以修正使用 `WritableDraft` 時的類型不相容問題
