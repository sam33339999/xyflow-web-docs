### `fitView` 變得更好了！

你是否曾經在新增或變更節點後難以讓 `fitView` 正常工作？你的程式碼看起來像這樣嗎？

```ts
setNodes((nodes) => [nodes, ...newNode]);
requestAnimationFrame(() => {
  fitView();
});
// 先渲染節點然後再調整視圖 :(
```

好吧，你有福了！不再需要技巧，不再需要 `setTimeout` 或 `requestAnimationFrame`，也不再有短暫的未調整視圖畫面！

```ts
setNodes((nodes) => [nodes, ...newNode]);
fitView(); // 它就是有效。
// 新增新節點和調整視圖同時發生
```

#### 還有一件事

你可能已經意識到 `fitViewOptions` 的 `padding` 值相當奇怪！`padding: 0.3` 甚至是什麼意思？我們也不知道，所以你現在可以傳遞像素值 `'25px'`、視口百分比 `'10%'`，真正的專家現在甚至可以

```ts
const fitViewOptions = {
  padding: {
    /** 水平 */
    x: '100px',
    /** 垂直 */
    y: '50px',
    /** 例如 top 覆寫 x */
    top: '25px',
    /** 混合和匹配單位 */
    left: '15%',
    /** 舊版單位仍然有效 */
    bottom: 0.1,
    /** 右側有一個佔螢幕 50% 的模態框？ */
    right: '50%',
  },
};
```

```ts
setNodes((nodes) => [nodes, ...newNode]);
fitView(); // 它就是有效。
// 新增新節點和調整視圖同時發生
```
