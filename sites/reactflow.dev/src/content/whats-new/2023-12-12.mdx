我們做 React Flow 這件事已經有一段時間了，透過 GitHub 上的 issue 和我們 [Discord 伺服器](https://discord.gg/RVmnytFmGW)上的對話，我們學到了很多關於使用者想要和需要從函式庫中得到什麼。然而，要聽到人們對我們文檔的體驗，或是從大量可能沒有積極參與我們社群的使用者那裡得到回饋，就困難多了。

過去我們曾安排與一些 Pro 訂閱者進行訪談，以了解他們如何使用 React Flow 和 Pro 平台，並發現這些見解非常寶貴。今年我們想擴大範圍，盡可能包含更多使用者，因此我們準備了一份簡短的調查，幫助指導我們進入新的一年的方向。

完成調查只需要幾分鐘，如果你能抽空填寫，我們將非常感激。你可以在[這裡](/developer-survey-2023)找到調查，我們將在新年早期公布結果！
