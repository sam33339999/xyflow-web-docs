我們希望讓 v12 的遷移盡可能順利。這就是為什麼我們為以下工具函式新增了棄用警告：

#### 將 `useReactFlow.project` 重新命名為 `useReactFlow.screenToFlowPosition`

⚠️ **變更**：不再需要減去 react flow 邊界了！

之前：

```js
const reactFlowBounds = reactFlowWrapper.current.getBoundingClientRect();

const position = reactFlowInstance.project({
  x: event.clientX - reactFlowBounds.left,
  y: event.clientY - reactFlowBounds.top,
});
```

之後：

```js
const position = reactFlowInstance.screenToFlowPosition({
  x: event.clientX,
  y: event.clientY,
});
```

#### 將 `getTransformForBounds` 重新命名為 `getViewportForBounds`

⚠️ **變更**：回傳 `{ x: number, y: number, zoom: number }` 而不是 `[number, number, number]`。

之前：

```js
const [x, y, zoom] = getTransformForBounds(bounds, width, height, 0.5, 2);
```

之後：

```js
const { x, y, zoom } = getViewportForBounds(bounds, width, height, 0.5, 2);
```

#### 將 `getRectOfNodes` 重新命名為 `getNodesBounds`

沒有變更，只是重新命名。

### 新功能

- 新增 `useReactFlow.flowToScreenPosition` 以達到完整性

除此之外，我們修正了一些錯誤。你可以在 [v11.10.0 Github 發布](https://github.com/xyflow/xyflow/releases/tag/11.10.0)中找到所有變更。
