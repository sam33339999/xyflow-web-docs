# Hooks 和 Providers

React Flow 提供了幾個 [hooks](/api-reference/hooks) 和一個 context provider，讓你增強流程圖的功能。這些工具可以幫助你更有效地管理狀態、存取內部方法以及建立自訂元件。

## ReactFlowProvider

ReactFlowProvider 是一個 context provider，它允許你從元件樹中的任何地方存取流程圖的內部狀態，例如節點、連線和視窗，即使在 [`ReactFlow`](/api-reference/react-flow) 元件之外也可以。它通常用於應用程式的頂層。

在以下幾種情況下，你可能需要使用 [`ReactFlowProvider`](/api-reference/react-flow-provider) 元件：

- 我們提供的許多 [hooks](/api-reference/hooks) 都依賴此元件才能運作。
- 你想要在 `ReactFlow` 元件之外存取流程圖的內部狀態。
- 你在一個頁面上使用多個流程圖。
- 你正在使用客戶端路由器。
