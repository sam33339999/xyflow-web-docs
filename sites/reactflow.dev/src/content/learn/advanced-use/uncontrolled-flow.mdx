# 非受控流程圖

有兩種方式可以使用 React Flow - 受控或非受控。受控意味著你控制節點和連線的狀態。在非受控流程圖中，節點和連線的狀態由 React Flow 在內部處理。在這部分中，我們將向你展示如何使用非受控流程圖。

非受控流程圖的實作更簡單，因為你不需要傳遞任何處理器：

如你所見，我們傳遞了 `defaultEdgeOptions` 來定義連線是動畫的。這很有幫助，因為你不能再使用 `onConnect` 處理器來為新建立的連線傳遞自訂選項。嘗試將「Node B」與「Node C」連接，你會看到新連線是動畫的。

## 更新節點和連線

由於你的本地狀態中沒有節點和連線，你無法直接更新它們。為此，你需要使用 [React Flow instance](/api-reference/types/react-flow-instance)，它附帶用於更新內部狀態的函式。你可以透過 `onInit` 回呼函式接收實例，或者更好的是使用 [`useReactFlow` hook](/api-reference/hooks/use-react-flow)。讓我們建立一個按鈕，在隨機位置新增一個新節點。為此，我們將用 [`ReactFlowProvider`](/api-reference/react-flow-provider) 包裝我們的流程圖，並使用 [`addNodes` 函式](/api-reference/types/react-flow-instance#nodes-and-edges)。
