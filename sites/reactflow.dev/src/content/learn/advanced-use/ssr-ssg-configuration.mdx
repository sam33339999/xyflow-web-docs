# 伺服器端渲染、伺服器端生成

import { Callout } from 'nextra/components';

<Callout type="info">React Flow 12 開始支援伺服器端渲染</Callout>

這是一個進階用例，假設你已經熟悉 React Flow。如果你是 React Flow 的新手，請查看我們的[入門指南](/learn/getting-started/installation-and-requirements)。

在本指南中，你將學習如何設定 React Flow 在伺服器上渲染流程圖，這將使你能夠

- 在文件中顯示靜態 HTML 圖表
- 在非 JavaScript 環境中渲染 React Flow 圖表
- 動態生成開放圖片圖片，在分享流程圖連結時顯示為嵌入內容

（如果你想下載流程圖的圖片，有一個更簡單的方法可以在客戶端實現，請參閱我們的[下載圖片範例](/examples/misc/download-image)。）

### 節點尺寸

你需要設定一些東西才能讓 React Flow 在伺服器上運作，最重要的是節點尺寸。React Flow 只有在節點有寬度和高度時才會渲染節點。通常你傳遞的節點沒有特定的 `width` 和 `height`，它們會被測量，然後尺寸會被寫入 `measured.width` 和 `measured.height`。由於我們無法在伺服器上測量尺寸，我們需要明確傳遞它們。這可以透過 `width` 和 `height` 或 `initialWidth` 和 `initialHeight` 節點屬性來完成。

```js
const nodes = [
  {
    id: '1',
    type: 'default',
    position: { x: 0, y: 0 },
    data: { label: 'Node 1' },
    width: 100,
    height: 50,
  },
];
```

React Flow 現在知道節點的尺寸，可以在伺服器上渲染它。`width` 和 `height` 屬性會作為內聯樣式用於節點。如果你預期節點在客戶端上有不同的尺寸，或者尺寸應該根據內容動態調整，你可以使用 `initialWidth` 和 `initialHeight` 屬性。它們僅用於第一次渲染（在伺服器或客戶端上），只要節點未被測量且 `measured.width` 和 `measured.height` 未設定。

<Callout type="default">
  <strong>
    有兩種方式可以指定伺服器端渲染的節點尺寸：
  </strong>
  <div>
    1. `width` 和 `height` 用於已知且不會改變的靜態尺寸。
  </div>
  <div>
    2. `initialWidth` 和 `initialHeight` 用於未知或會改變的動態尺寸。
  </div>
</Callout>

### 連接點位置

你可能還想在伺服器上渲染連線。在客戶端，React Flow 會檢查連接點的位置並儲存該資訊以繪製連線。由於我們無法在伺服器上測量連接點位置，我們也需要傳遞這些資訊。這可以透過節點的 `handles` 屬性來完成。

```js
const nodes: Node[] = [
  {
    id: '1',
    type: 'default',
    position: { x: 0, y: 0 },
    data: { label: 'Node 1' },
    width: 100,
    height: 50,
    handles: [
      {
        type: 'target',
        position: Position.Top,
        x: 100 / 2,
        y: 0,
      },
      {
        type: 'source',
        position: Position.Bottom,
        x: 100 / 2,
        y: 50,
      },
    ],
  },
];
```

有了這些額外資訊，React Flow 知道足夠關於連接點的資訊，可以在伺服器上渲染連線。如果你只想渲染節點，可以跳過此步驟。

### 在伺服器上使用 `fitView`

如果你知道 React Flow 容器本身的尺寸，你甚至可以在伺服器上使用 `fitView`。為此，你需要將容器的 `width` 和 `height` 傳遞給 `ReactFlow` 元件。

```js
<ReactFlow nodes={nodes} edges={edges} fitView width={1000} height={500} />
```

這將在伺服器上計算視窗並設定 `transform`，以便在視窗中包含所有節點。

### 與 `<ReactFlowProvider>` 一起使用

如果你使用 `ReactFlowProvider`，你可以傳遞 `initialNodes`、`initialEdges` 和可選的包裝器尺寸（`initialWidth` 和 `initialHeight`）以及 `fitView` 給 provider。

```js
<ReactFlowProvider
  initialNodes={nodes}
  initialEdges={edges}
  initialWidth={1000}
  initialHeight={500}
  fitView
>
  <App />
</ReactFlowProvider>
```

`initial-` 前綴表示這些值僅用於第一次渲染。之後，provider 將使用 context 中的 `nodes` 和 `edges`。

### 建立靜態 HTML

如果你想建立靜態 HTML，可以使用 React 的 `renderToStaticMarkup` 函式。這將把 React Flow 元件渲染為 HTML 字串。然後你可以使用此字串建立靜態 HTML 檔案或作為 HTTP 請求的回應發送。

```js
import React from 'react';
import { renderToStaticMarkup } from 'react-dom/server';
import { ReactFlow, Background } from '@xyflow/react';

function toHTML({ nodes, edges, width, height }) {
  const html = renderToStaticMarkup(
    React.createElement(
      ReactFlow,
      {
        nodes,
        edges,
        width,
        height,
        minZoom: 0.2,
        fitView: true,
      },
      React.createElement(Background, null),
    ),
  );

  return html;
}
```
