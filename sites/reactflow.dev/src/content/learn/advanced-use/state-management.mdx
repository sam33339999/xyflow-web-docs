在本指南中，我們將說明如何使用 React Flow 搭配狀態管理函式庫 [Zustand](https://github.com/pmndrs/zustand)。我們將建構一個小型應用程式，其中每個節點都有一個顏色選擇器來更新其背景顏色。我們為本指南選擇了 Zustand，因為 React Flow 內部已經使用它，但你可以輕鬆使用其他狀態管理函式庫，如 [Redux](https://redux.js.org/)、[Recoil](https://recoiljs.org/) 或 [Jotai](https://jotai.org/)

如先前的指南和範例所示，React Flow 可以輕鬆地與本地元件狀態一起使用來管理圖表中的節點和連線。然而，隨著應用程式的成長，你需要從單個節點內部更新狀態，管理這個狀態可能會變得更加複雜。你可以使用 [React context](https://reactjs.org/docs/context.html)，或整合像 Zustand 這樣的狀態管理函式庫，如本指南所述，而不是透過節點的 data 欄位傳遞函式。

## 安裝 Zustand

如上所述，我們在此範例中使用 Zustand。Zustand 有點像 Redux：你有一個中央儲存區，其中包含用於修改狀態的 actions，以及用於存取狀態的 hooks。你可以透過以下方式安裝 Zustand：

```bash copy npm2yarn
npm install --save zustand
```

## 建立儲存區

Zustand 讓你建立一個 hook 來存取儲存區的值和函式。我們將 `nodes` 和 `edges` 以及 `onNodesChange`、`onEdgesChange`、`onConnect`、`setNodes` 和 `setEdges` 函式放入儲存區，以獲得圖表的基本互動性：

## 實作顏色變更 action

我們新增一個新的 `updateNodeColor` action 來更新特定節點的 `data.color` 欄位。為此，我們將節點 id 和新顏色傳遞給 action，遍歷節點並使用新顏色更新匹配的節點：

```ts
updateNodeColor: (nodeId: string, color: string) => {
  set({
    nodes: get().nodes.map((node) => {
      if (node.id === nodeId) {
        // it's important to create a new object here, to inform React Flow about the changes
        return { ...node, data: { ...node.data, color } };
      }

      return node;
    }),
  });
};
```

這個新的 action 現在可以在 React 元件中這樣使用：

```tsx
const updateNodeColor = useStore((s) => s.updateNodeColor);
...
<button onClick={() => updateNodeColor(nodeId, color)} />;
```

## 新增顏色選擇器節點

在此步驟中，我們實作 `ColorChooserNode` 元件，並在使用者更改顏色時呼叫 `updateNodeColor`。顏色選擇器節點的自訂部分是顏色輸入。

```jsx
<input
  type="color"
  defaultValue={data.color}
  onChange={(evt) => updateNodeColor(id, evt.target.value)}
  className="nodrag"
/>
```

我們新增 `nodrag` class name，這樣使用者在更改顏色時不會誤拖曳節點，並在 `onChange` 事件處理器中呼叫 `updateNodeColor`。
