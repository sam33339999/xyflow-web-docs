通常使用 React Flow 時，開發者會在 React Flow 之外處理他們的資料，例如將資料發送到伺服器或資料庫。然而，在本指南中，我們將向你展示如何直接在 React Flow 內部計算資料流。你可以使用此方法根據連接的資料更新節點，或建構完全在瀏覽器中運行的應用程式。

## 我們要建構什麼？

在本指南結束時，你將建構一個互動式流程圖，該圖從三個獨立的數字輸入欄位（紅色、綠色和藍色）生成一種顏色，並判斷白色或黑色文字在該背景顏色上哪個更易讀。

## 建立自訂節點

讓我們從建立一個自訂輸入節點（`NumberInput.js`）開始，並新增三個實例。我們將使用受控的 `<input type="number" />` 並在 `onChange` 事件處理器中將其限制為 0 - 255 之間的整數。

```jsx
import { useCallback, useState } from 'react';
import { Handle, Position } from '@xyflow/react';

function NumberInput({ id, data }) {
  const [number, setNumber] = useState(0);

  const onChange = useCallback((evt) => {
    const cappedNumber = Math.round(
      Math.min(255, Math.max(0, evt.target.value)),
    );
    setNumber(cappedNumber);
  }, []);

  return (
    <div className="number-input">
      <div>{data.label}</div>
      <input
        id={`number-${id}`}
        name="number"
        type="number"
        min="0"
        max="255"
        onChange={onChange}
        className="nodrag"
        value={number}
      />
      <Handle type="source" position={Position.Right} />
    </div>
  );
}

export default NumberInput;
```

接下來，我們將新增一個新的自訂節點（`ColorPreview.js`），為每個顏色通道新增一個目標連接點，並且背景顯示生成的顏色。我們可以使用 `mix-blend-mode: 'difference';` 讓文字顏色始終保持易讀。

<Callout type="info">
  每當你在單個節點上有多個相同類型的連接點時，別忘了給每個連接點一個獨立的 id！
</Callout>
讓我們同時在 `initialEdges` 陣列中新增從輸入節點到顏色節點的連線。

## 計算資料

如何將資料從輸入節點傳遞到顏色節點？這是一個兩步驟的過程，涉及為此確切目的建立的兩個 hooks：

1. 使用 [`updateNodeData`](/api-reference/types/react-flow-instance#update-node-data) 回呼函式將每個數字輸入值儲存在節點的 `data` 物件中。
2. 使用 [`useNodeConnections`](/api-reference/hooks/use-node-connections) 找出哪些節點已連接，然後使用 [`useNodesData`](/api-reference/hooks/use-nodes-data) 從連接的節點接收資料。

### 步驟 1：將值寫入 data 物件

首先，讓我們在 `initialNodes` 陣列中的 `data` 物件中為輸入節點新增一些初始值，並將它們作為輸入節點的初始狀態使用。
然後我們將從 [`useReactFlow`](/api-reference/hooks/use-react-flow) hook 中取得 [`updateNodeData`](/api-reference/types/react-flow-instance#update-node-data) 函式，並在輸入改變時使用它來更新節點的 `data` 物件為新值。

<Callout type="info">
預設情況下，你傳遞給 [`updateNodeData`](/api-reference/types/react-flow-instance#update-node-data) 的資料會與舊的 data 物件合併。這讓部分更新變得更容易，並在你忘記新增 `{...data}` 時保護你。你可以傳遞 `{ replace: true }` 作為選項來替換物件。
</Callout>

<Callout type="warning">
  <b>
    在處理輸入欄位時，你不應該直接使用節點的 `data` 物件作為 UI 狀態。
  </b>
  更新 data 物件有延遲，游標可能會不規則地跳動並導致不需要的輸入。
</Callout>

### 步驟 2：從連接的節點獲取資料

我們從使用 [`useNodeConnections`](/api-reference/hooks/use-node-connections) hook 確定每個節點的所有連接開始，然後使用 [`updateNodeData`](/api-reference/types/react-flow-instance#update-node-data) 取得第一個連接節點的資料。

<Callout type="info">
  請注意，每個連接點可以有多個節點連接到它，你可能想在應用程式中限制單個連接點的連接數量。查看[連接限制範例](/examples/nodes/connection-limit)了解如何做到這一點。
</Callout>

### 改進程式碼

先取得連接，然後為每個連接點分別取得資料可能看起來很笨拙。對於像這樣有多個連接點的節點，你應該考慮建立一個自訂連接點元件，以隔離連接狀態和節點資料綁定。我們可以在行內建立一個。

```jsx filename="ColorPreview.js"
// {...}
function CustomHandle({ id, label, onChange }) {
  const connections = useNodeConnections({
    handleType: 'target',
    handleId: id,
  });

  const nodeData = useNodesData(connections?.[0].source);

  useEffect(() => {
    onChange(nodeData?.data ? nodeData.data.value : 0);
  }, [nodeData]);

  return (
    <div>
      <Handle
        type="target"
        position={Position.Left}
        id={id}
        className="handle"
      />
      <label htmlFor="red" className="label">
        {label}
      </label>
    </div>
  );
}
```

我們可以將顏色提升為本地狀態，並像這樣宣告每個連接點：

```jsx filename="ColorPreview.js"
// {...}
function ColorPreview() {
  const [color, setColor] = useState({ r: 0, g: 0, b: 0 });

  return (
    <div
      className="node"
      style={{
        background: `rgb(${color.r}, ${color.g}, ${color.b})`,
      }}
    >
      <CustomHandle
        id="red"
        label="R"
        onChange={(value) => setColor((c) => ({ ...c, r: value }))}
      />
      <CustomHandle
        id="green"
        label="G"
        onChange={(value) => setColor((c) => ({ ...c, g: value }))}
      />
      <CustomHandle
        id="blue"
        label="B"
        onChange={(value) => setColor((c) => ({ ...c, b: value }))}
      />
    </div>
  );
}

export default ColorPreview;
```

## 變得更複雜

現在我們有了一個簡單的範例，展示如何透過 React Flow 傳遞資料。如果我們想做一些更複雜的事情，比如沿途轉換資料？或者甚至採取不同的路徑？我們也可以做到！

### 繼續流程

讓我們擴展我們的流程。首先在顏色節點新增一個輸出 `<Handle type="source" position={Position.Right} />` 並移除本地元件狀態。

<Callout type="info">
  因為此節點上沒有輸入欄位，我們根本不需要保留本地狀態。我們可以直接讀取和更新節點的 `data` 物件。
</Callout>

接下來，我們新增一個新節點（`Lightness.js`），它接收一個顏色物件並判斷它是淺色還是深色。我們可以使用[相對亮度公式](https://en.wikipedia.org/wiki/Relative_luminance#Relative_luminance_and_%22gamma_encoded%22_colorspaces)
`luminance = 0.2126 * color.r + 0.7152 * color.g + 0.0722 * color.b`
來計算顏色的感知亮度（0 是最暗的，255 是最亮的）。我們可以假設一切 >= 128 的都是淺色。

### 條件分支

如果我們想根據感知亮度在流程中採取不同的路徑呢？讓我們給亮度節點兩個來源連接點 `light` 和 `dark`，並根據來源連接點 ID 分離節點 `data` 物件。如果你有多個來源連接點，這是必要的，以便區分每個來源連接點的資料。

但是「採取不同路徑」是什麼意思？一個解決方案是假設連接到目標連接點的 `null` 或 `undefined` 資料被視為「停止」。在我們的情況下，如果是淺色，我們可以將傳入的顏色寫入 `data.values.light`，如果是深色則寫入 `data.values.dark`，並將另一個值設為 `null`。

別忘了新增 `flex-direction: column;` 和 `align-items: end;` 來重新定位連接點標籤。

## 總結

你已經學會了如何在流程中移動資料並沿途轉換它。你所需要做的就是

1. 使用 [`updateNodeData`](/api-reference/types/react-flow-instance#update-node-data) 回呼函式將資料儲存在節點的 `data` 物件中。
2. 使用 [`useNodeConnections`](/api-reference/hooks/use-node-connections) 找出哪些節點已連接，然後使用 [`useNodesData`](/api-reference/hooks/use-nodes-data) 從連接的節點接收資料。

你可以透過將傳入的 undefined 資料解釋為「停止」來實作分支。順便說一下，大多數也有分支的流程圖通常會將節點的觸發與連接到節點的實際資料分開。Unreal Engine 的 Blueprints 就是一個很好的例子。

<Callout type="info">
  最後提醒一下：你應該找到一種一致的方式來結構化所有節點資料，而不是像我們剛才那樣混合想法。這意味著，例如，如果你開始按連接點 ID 分割資料，你應該對所有節點都這樣做，無論它們是否有多個連接點。能夠對整個流程中資料的結構做出假設會讓生活變得容易得多。
</Callout>
