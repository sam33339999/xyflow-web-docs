# 白板功能

React Flow 是為建構基於節點的 UI 而設計的，如工作流程編輯器、流程圖和圖表。即使 React Flow 並非專為建立白板應用程式而設計，你可能還是想整合常見的白板功能。這些範例展示了當你需要在節點和連線旁邊進行註解或繪圖時，如何為你的應用程式新增繪圖功能。

## 範例

### ✏️ 手繪（Pro）

在你的 React Flow 畫布上繪製平滑的曲線。適用於註解或在現有節點周圍繪製草圖。

**功能：**

- 滑鼠/觸控繪圖
- 可調整的筆刷大小和顏色
- 將繪製的路徑轉換為自訂節點

**常見用途：**

- 註解流程圖
- 為圖表新增註釋
- 在節點周圍繪製想法草圖

### 🎯 套索選擇

透過繪製自由形狀的選擇區域來選擇多個元素，並可選擇包含部分選中的元素。

**功能：**

- 自由形狀的選擇形狀
- 部分選擇元素

**常見用途：**

- 一起選擇節點和註解
- 在混合內容中進行複雜選擇

### 🧹 橡皮擦

透過「擦除」來移除項目。使用碰撞檢測來決定要刪除的內容。

**功能：**

- 基於碰撞的擦除
- 視覺化橡皮擦游標

**常見用途：**

- 移除流程圖的部分內容

### 📐 矩形繪製

透過點擊和拖曳建立矩形形狀。適合突出顯示區域或為節點群組建立背景。

**功能：**

- 點擊和拖曳矩形建立
- 可自訂顏色

**常見用途：**

- 建立背景容器
- 視覺化地將相關節點分組
- 突出顯示圖表的部分

## 白板函式庫

如果你正在尋找更完整的白板解決方案，請考慮使用專門為白板應用程式設計的函式庫，如 [tldraw](https://tldraw.dev/) 或 [Excalidraw](https://docs.excalidraw.com/)。這些函式庫提供了一整套用於協作繪圖、形狀、文字等的功能。
