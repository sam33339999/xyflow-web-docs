# 子流程

<Callout type="info">
  **`parentNode` 屬性已棄用！** 我們在 11.11.0 版本中將 `parentNode` 選項重新命名為 `parentId`。舊屬性仍然支援，但將在版本 12 中移除。
</Callout>

子流程是節點內部的流程。它可以是一個獨立的流程，也可以是與其父節點外部的其他節點連接的流程。此功能也可用於分組節點。在本文件的這部分，我們將建立一個包含子流程的流程，並展示子節點的特定選項。

<Callout type="warning">
  <strong>節點順序</strong>
  重要的是，你的父節點必須在 `nodes`/ `defaultNodes` 陣列中出現在其子節點之前，才能正確處理。
</Callout>

### 新增子節點

如果你想將一個節點作為另一個節點的子節點新增，你需要使用 `parentId` 選項（在之前的版本中稱為 `parentNode`）（你可以在[節點選項部分](/api-reference/types/node)找到所有選項的列表）。一旦我們這樣做，子節點就會相對於其父節點定位。位置 `{ x: 0, y: 0 }` 是父節點的左上角。

在此範例中，我們透過傳遞 style 選項來設定父節點的固定寬度和高度。此外，我們將子節點的範圍設定為 `'parent'`，這樣我們就無法將子節點移出父節點。

### 使用子節點的特定選項

當你移動父節點時，你可以看到子節點也會移動。使用 `parentId` 選項將節點新增到另一個節點，只做一件事：將其相對於其父節點定位。子節點在標記上並不是真正的子元素。你可以將子節點拖曳或定位到其父節點外部（當未設定 `extent: 'parent'` 選項時），但當你移動父節點時，子節點會隨之移動。

在上面的範例中，我們對父節點使用 `group` 類型，但你也可以使用任何其他類型。`group` 類型只是一個方便的節點類型，沒有附加控制點。

### 連線渲染行為

預設情況下，連線會在節點下方渲染，此行為適用於普通節點和群組節點。但是，連接到具有父節點的節點的連線會在節點上方渲染。

如果你想自訂連線的 z-index，可以使用 `zIndex` 選項。例如：

```tsx
const defaultEdgeOptions = { zIndex: 1 };

<ReactFlow defaultEdgeOptions={defaultEdgeOptions} />;
```

這讓你可以在節點上方渲染連線，或根據需要調整它們的堆疊順序。
