# 平移和縮放

React Flow 的預設平移和縮放行為受到 [slippy maps](https://wiki.openstreetmap.org/wiki/Slippy_map) 的啟發。你可以透過拖曳指標來平移，透過滾動來縮放。你可以輕鬆地使用 `<ReactFlow />` 元件上的[互動](/api-reference/react-flow#interaction-props)和[鍵盤](/api-reference/react-flow#keyboard-props)屬性來自訂此行為。

## 視窗配置

這裡我們將列出並解釋一些其他工具使用的配置。

### 預設視窗控制

如上所述，ReactFlow 的預設控制如下：

- `平移：` 指標拖曳
- `縮放：` 捏合或滾動
- `選取：` shift + 指標拖曳

### 設計工具視窗控制

如果你偏好 figma/sketch/設計工具控制，你可以將 [`panOnScroll`](/api-reference/react-flow#panonscroll) 和 [`selectionOnDrag`](/api-reference/react-flow#selectionondrag) 設為 `true`，並將 [`panOnDrag`](/api-reference/react-flow#panondrag) 設為 `false`：

- `平移：` 滾動、滑鼠中鍵/右鍵拖曳、space + 指標拖曳
- `縮放：` 捏合或 cmd + 滾動
- `選取：` 指標拖曳
