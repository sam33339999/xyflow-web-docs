# 加入互動功能

現在我們已經建立了[第一個流程圖](/learn/concepts/building-a-flow)，讓我們加入互動功能，讓你可以選取、拖曳和移除節點與連線。

## 處理變更事件

預設情況下，React Flow 除了處理視窗之外，不會管理任何內部狀態更新。就像使用 HTML `<input />` 元素一樣，你需要將[事件處理器](/api-reference/react-flow#event-handlers)傳遞給 React Flow，以便將觸發的變更套用到你的節點和連線上。

 <Steps>
 ### 加入 imports

要管理變更，我們將使用 `useState` 以及 React Flow 的兩個輔助函式：[`applyNodeChanges`](/api-reference/utils/apply-node-changes) 和 [`applyEdgeChanges`](/api-reference/utils/apply-edge-changes)。讓我們匯入這些函式：

```jsx
import { useState, useCallback } from 'react';
import { ReactFlow, applyEdgeChanges, applyNodeChanges } from '@xyflow/react';
```

### 定義節點和連線

我們需要定義初始節點和連線。這些將是我們流程圖的起點。

```jsx
const initialNodes = [
  {
    id: 'n1',
    position: { x: 0, y: 0 },
    data: { label: 'Node 1' },
    type: 'input',
  },
  {
    id: 'n2',
    position: { x: 100, y: 100 },
    data: { label: 'Node 2' },
  },
];

const initialEdges = [
  {
    id: 'n1-n2',
    source: 'n1',
    target: 'n2',
  },
];
```

### 初始化狀態

在我們的元件中，我們將呼叫 `useState` hook 來管理節點和連線的狀態：

```jsx {2-3}
export default function App() {
  const [nodes, setNodes] = useState(initialNodes);
  const [edges, setEdges] = useState(initialEdges);

  return (
    <div style={{ height: '100%', width: '100%' }}>
      <ReactFlow>
        <Background />
        <Controls />
      </ReactFlow>
    </div>
  );
}
```

### 加入事件處理器

我們需要建立兩個事件處理器：[`onNodesChange`](/api-reference/react-flow#onnodeschange) 和 [`onEdgesChange`](/api-reference/react-flow#onedgeschange)。它們將用於在發生變更時更新節點和連線的狀態，例如拖曳或刪除元素。繼續將這些處理器加入你的元件：

```jsx
const onNodesChange = useCallback(
  (changes) => setNodes((nodesSnapshot) => applyNodeChanges(changes, nodesSnapshot)),
  [],
);
const onEdgesChange = useCallback(
  (changes) => setEdges((edgesSnapshot) => applyEdgeChanges(changes, edgesSnapshot)),
  [],
);
```

### 將它們傳遞給 ReactFlow

現在我們可以將節點、連線和事件處理器傳遞給 `<ReactFlow />` 元件：

```jsx {2-5}
<ReactFlow
  nodes={nodes}
  edges={edges}
  onNodesChange={onNodesChange}
  onEdgesChange={onEdgesChange}
  fitView
>
  <Background />
  <Controls />
</ReactFlow>
```

### 互動流程圖

就是這樣！你現在有了一個基本的互動流程圖 🎉

當你拖曳或選取節點時，`onNodesChange` 處理器會被觸發。`applyNodeChanges` 函式接著使用這些變更事件來更新節點的當前狀態。這就是它們如何協同運作的。試著點擊並拖曳節點來移動它，並觀察 UI 即時更新。

</Steps>

## 處理連接

還有最後一塊拼圖缺少：互動式連接節點。為此，我們需要實作一個 [`onConnect`](/api-reference/react-flow#onconnect) 處理器。

<Steps>
### 建立 `onConnect` 處理器

`onConnect` 處理器會在兩個節點之間建立新連接時被呼叫。我們可以使用 [`addEdge`](/api-reference/utils/add-edge) 工具函式來建立新連線並更新連線陣列。

```jsx
const onConnect = useCallback(
  (params) => setEdges((edgesSnapshot) => addEdge(params, edgesSnapshot)),
  [],
);
```

### 將它傳遞給 ReactFlow

現在我們可以將 `onConnect` 處理器傳遞給 `<ReactFlow />` 元件：

```jsx {6}
<ReactFlow
  nodes={nodes}
  edges={edges}
  onNodesChange={onNodesChange}
  onEdgesChange={onEdgesChange}
  onConnect={onConnect}
  fitView
>
  <Background />
  <Controls />
</ReactFlow>
```

### 可連接的流程圖

試著從一個連接點拖曳到另一個連接點來連接兩個節點。`onConnect` 處理器會被觸發，新連線將被加入到流程圖中。🥳

這裡發生了什麼事？每當 React Flow 觸發變更（節點初始化、節點拖曳、連線選取等），`onNodesChange` 處理器就會被呼叫。我們匯出一個 `applyNodeChanges` 處理器，這樣你就不需要自己處理變更。`applyNodeChanges` 處理器會回傳一個更新後的節點陣列，這就是你的新節點陣列。現在你有了一個具有以下功能的互動流程圖：

- 可選取的節點和連線
- 可拖曳的節點
- 可透過從一個節點連接點拖曳到另一個來連接節點
- 按下 `shift` 進行多重選取區域——預設的 [`selectionKeyCode`](/api-reference/react-flow#selectionkeycode)
- 按下 `cmd` 進行多重選取——預設的 [`multiSelectionKeyCode`](/api-reference/react-flow#multiselectionkeycode)
- 按下 `backspace` 移除選取的元素——預設的 [`deleteKeyCode`](/api-reference/react-flow#deletekeycode)

如果你想直接開始建立自己的應用程式，我們建議查看自訂化章節。否則繼續閱讀以了解更多關於 React Flow 的功能。
