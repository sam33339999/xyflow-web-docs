# 建立流程圖

在接下來的頁面中，我們將介紹 React Flow 的核心概念，並說明如何建立一個基本的互動流程圖。一個流程圖由[節點](/api-reference/types/node)、[連線](/api-reference/types/edge)和視窗組成。

要跟著本指南進行，你需要建立一個 React 專案並安裝 `@xyflow/react` 套件：

```bash copy npm2yarn
npm install @xyflow/react
```

## 建立流程圖

讓我們從建立一個空的流程圖開始，包含視窗[`<Controls />`](/api-reference/components/controls)和點狀[`<Background />`](/api-reference/components/background)。

<Steps>
### 加入 imports
首先，我們需要從 `@xyflow/react` 套件中匯入一些基本元件和 **CSS 樣式表**，這是 React Flow 運作所**必需**的：

```jsx "import '@xyflow/react/dist/style.css';"
import { ReactFlow, Background, Controls } from '@xyflow/react';
import '@xyflow/react/dist/style.css';
```

### 渲染 ReactFlow

現在我們建立一個 React 元件來渲染流程圖。父容器的**寬度和高度**是**必需**的，因為 React Flow 會使用這些尺寸。

```jsx "height: '100%', width: '100%'"
export default function App() {
  return (
    <div style={{ height: '100%', width: '100%' }}>
      <ReactFlow>
        <Background />
        <Controls />
      </ReactFlow>
    </div>
  );
}
```

### 空的流程圖

就是這樣！你已經建立了你的第一個空流程圖 🎉

</Steps>

## 加入節點

現在流程圖已經設定好了，是時候加入節點了——每個節點代表你圖表中具有特定位置和內容的元素。

<Steps>
### 建立節點物件

在你的 React 元件外部，建立一個[節點](/api-reference/types/node)物件陣列。每個節點物件需要一個唯一的 `id` 和一個 `position`。讓我們也為它們加入一個標籤：

```jsx
const initialNodes = [
  {
    id: 'n1',
    position: { x: 0, y: 0 },
    data: { label: 'Node 1' },
    type: 'input',
  },
  {
    id: 'n2',
    position: { x: 100, y: 100 },
    data: { label: 'Node 2' },
  },
];
```

### 將節點加入流程圖

現在我們可以使用 `nodes` 屬性將 `initialNodes` 陣列傳遞給 `<ReactFlow />` 元件：

```jsx "nodes={initialNodes}"
<ReactFlow nodes={initialNodes}>
  <Background />
  <Controls />
</ReactFlow>
```

這樣我們就有了一個包含兩個帶標籤節點的流程圖 🎉

## 加入連線

現在我們有了兩個節點，讓我們用連線將它們連接起來。

<Steps>
### 建立連線

要建立連線，我們定義一個[連線](/api-reference/types/edge)物件陣列。每個連線物件需要有一個 `id`、一個 `source`（連線開始的位置）和一個 `target`（連線結束的位置）。在這個範例中，我們使用目前建立的兩個節點的 `id` 值（`n1` 和 `n2`）來定義連線：

```js
const initialEdges = [
  {
    id: 'n1-n2',
    source: 'n1',
    target: 'n2',
  },
];
```

這條連線將 `id: 'n1'` 的節點（來源）連接到 `id: 'n2'` 的節點（目標）。

<RemoteCodeViewer aspectRatio="4" route="learn/building-a-flow-3" framework="react" />

### 為連線加上標籤

讓我們為這條連線加上 React Flow 內建的兩個屬性：`label` 和 `type: "step"`。

```jsx {6-7}
const initialEdges = [
  {
    id: 'n1-n2',
    source: 'n1',
    target: 'n2',
    type: 'step',
    label: 'connects with',
  },
];
```

### 將連線加入流程圖

現在我們可以使用 `edges` 屬性將 `initialEdges` 陣列傳遞給 `<ReactFlow />` 元件：

```jsx "edges={initialEdges}"
<ReactFlow nodes={initialNodes} edges={initialEdges}>
  <Background />
  <Controls />
</ReactFlow>
```
