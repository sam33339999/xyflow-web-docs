# 內建元件

React Flow 附帶了幾個內建元件，可以作為 [`<ReactFlow />`](/api-reference/react-flow) 元件的子元件傳遞。

## 小地圖

[`MiniMap`](/api-reference/components/minimap) 提供了流程圖的鳥瞰視圖，使導覽更容易，特別是對於較大的流程圖。你可以透過提供 nodeColor 函式來自訂小地圖中節點的外觀。

<RemoteCodeViewer aspectRatio="2" route="learn/mini-map" framework="react" />

## 控制面板

React Flow 附帶了一組可自訂的視窗 [`Controls`](/api-reference/components/controls)。你可以放大和縮小、調整視窗適應大小，並切換使用者是否可以移動、選取和編輯節點。

<RemoteCodeViewer aspectRatio="2" route="learn/controls" framework="react" />

## 背景

[`Background`](/api-reference/components/background) 元件為你的流程圖加入視覺化網格圖案，幫助使用者保持方向感。你可以從不同的圖案變體中選擇，或者如果你需要更進階的自訂，你可以探索[原始碼](https://github.com/xyflow/xyflow/blob/main/packages/react/src/additional-components/Background/Background.tsx)來實作你自己的圖案。

<RemoteCodeViewer aspectRatio="2" route="learn/background" framework="react" />

## 面板

[`Panel`](/api-reference/components/panel) 元件允許你在流程圖上加入固定的覆蓋層，非常適合標題、控制項或任何其他應該保持靜止的 UI 元素。

<RemoteCodeViewer aspectRatio="2" route="learn/panel" framework="react" />
