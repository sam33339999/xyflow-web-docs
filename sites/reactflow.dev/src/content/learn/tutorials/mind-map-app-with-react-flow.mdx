## <Emoji content="👩🏻‍💻" /> 入門

要完成本教學，你需要具備一些 [React](https://reactjs.org/docs/getting-started.html) 和 [React Flow](/learn/concepts/terms-and-definitions) 的基礎知識（嗨，就是我們！<Emoji content="😁" /> 這是一個用於建立基於節點的使用者介面的開源函式庫，例如工作流程工具、ETL 管道等[更多應用](/showcase/)。）

我們將使用 [Vite](https://vitejs.dev/) 來開發我們的應用程式，但你也可以使用 [Create React App](https://create-react-app.dev/) 或任何你喜歡的工具。要使用 Vite 建立一個新的 React 應用程式，你需要執行：

```bash npm2yarn
npm create vite@latest reactflow-mind-map -- --template react
```

如果你想使用 TypeScript：

```bash npm2yarn
npm create vite@latest reactflow-mind-map -- --template react-ts
```

初始設定完成後，你需要安裝一些套件：

```bash npm2yarn
npm install reactflow zustand classcat nanoid
```

我們使用 [Zustand](https://github.com/pmndrs/zustand) 來管理應用程式的狀態。它有點像 Redux，但更小且需要撰寫的模板程式碼更少。React Flow 也使用 Zustand，所以安裝不會產生額外的成本。（在本教學中我們使用 TypeScript，但你也可以使用純 JavaScript。）

為了保持簡單，我們將所有程式碼放在 `src/App` 資料夾中。為此，你需要建立 `src/App` 資料夾並新增一個 index 檔案，內容如下：

## <Emoji content="🏪" /> 節點和連線的儲存區

如前所述，我們使用 Zustand 來進行狀態管理。為此，我們在 `src/App` 資料夾中建立一個名為 `store.ts` 的新檔案：

#### src/App/store.ts

```ts
import {
  Edge,
  EdgeChange,
  Node,
  NodeChange,
  OnNodesChange,
  OnEdgesChange,
  applyNodeChanges,
  applyEdgeChanges,
} from '@xyflow/react';
import { createWithEqualityFn } from 'zustand/traditional';

export type RFState = {
  nodes: Node[];
  edges: Edge[];
  onNodesChange: OnNodesChange;
  onEdgesChange: OnEdgesChange;
};

const useStore = createWithEqualityFn<RFState>((set, get) => ({
  nodes: [
    {
      id: 'root',
      type: 'mindmap',
      data: { label: 'React Flow Mind Map' },
      position: { x: 0, y: 0 },
    },
  ],
  edges: [],
  onNodesChange: (changes: NodeChange[]) => {
    set({
      nodes: applyNodeChanges(changes, get().nodes),
    });
  },
  onEdgesChange: (changes: EdgeChange[]) => {
    set({
      edges: applyEdgeChanges(changes, get().edges),
    });
  },
}));

export default useStore;
```

看起來程式碼很多，但大部分都是型別定義 <Emoji content="😇" /> 儲存區會追蹤節點和連線並處理變更事件。當使用者拖曳節點時，React Flow 會觸發變更事件，儲存區會套用這些變更，然後渲染更新後的節點。（你可以在我們的[狀態管理函式庫指南](/api-reference/hooks/use-store)中閱讀更多相關資訊。）

如你所見，我們從一個放置在 `{ x: 0, y: 0 }` 位置、類型為 'mindmap' 的初始節點開始。要將儲存區與我們的應用程式連接，我們使用 `useStore` hook：

#### src/App/index.tsx

```tsx
import { ReactFlow, Controls, Panel, NodeOrigin } from '@xyflow/react';
import { shallow } from 'zustand/shallow';

import useStore, { RFState } from './store';

// we have to import the React Flow styles for it to work
import '@xyflow/react/dist/style.css';

const selector = (state: RFState) => ({
  nodes: state.nodes,
  edges: state.edges,
  onNodesChange: state.onNodesChange,
  onEdgesChange: state.onEdgesChange,
});

// this places the node origin in the center of a node
const nodeOrigin: NodeOrigin = [0.5, 0.5];

function Flow() {
  // whenever you use multiple values, you should use shallow to make sure the component only re-renders when one of the values changes
  const { nodes, edges, onNodesChange, onEdgesChange } = useStore(selector, shallow);

  return (
    <ReactFlow
      nodes={nodes}
      edges={edges}
      onNodesChange={onNodesChange}
      onEdgesChange={onEdgesChange}
      nodeOrigin={nodeOrigin}
      fitView
    >
      <Controls showInteractive={false} />
      <Panel position="top-left">React Flow Mind Map</Panel>
    </ReactFlow>
  );
}

export default Flow;
```

我們從儲存區中存取節點、連線和變更處理器，並將它們傳遞給 React Flow 元件。我們也使用 `fitView` 屬性來確保初始節點在視圖中居中，並將節點原點設定為 `[0.5, 0.5]` 以將原點設置在節點的中心。完成後，你的應用程式應該看起來像這樣：

```tsx
import { BaseEdge, EdgeProps, getStraightPath } from '@xyflow/react';
```

## <Emoji content="🆕" /> 新增節點

我們想讓使用者能夠快速建立新節點。使用者應該能夠透過點擊節點並拖曳到應該放置新節點的位置來新增新節點。這個功能並非 React Flow 內建的，但我們可以透過使用 [`onConnectStart` 和 `onConnectEnd`](/api-reference/react-flow#onconnectstart) 處理器來實作它。

我們使用開始處理器來記住被點擊的節點，並使用結束處理器來建立新節點：

#### Add to src/App/index.tsx

```tsx
const connectingNodeId = useRef<string | null>(null);

const onConnectStart: OnConnectStart = useCallback((_, { nodeId }) => {
  connectingNodeId.current = nodeId;
}, []);

const onConnectEnd: OnConnectEnd = useCallback((event) => {
  // we only want to create a new node if the connection ends on the pane
  const targetIsPane = (event.target as Element).classList.contains('react-flow__pane');

  if (targetIsPane && connectingNodeId.current) {
    console.log(`add new node with parent node ${connectingNodeId.current}`);
  }
}, []);
```

由於我們的節點由儲存區管理，我們建立一個動作來新增新節點及其連線。我們的 `addChildNode` 動作如下所示：

#### New action in src/store.ts

```ts
addChildNode: (parentNode: Node, position: XYPosition) => {
  const newNode = {
    id: nanoid(),
    type: 'mindmap',
    data: { label: 'New Node' },
    position,
    parentNode: parentNode.id,
  };

  const newEdge = {
    id: nanoid(),
    source: parentNode.id,
    target: newNode.id,
  };

  set({
    nodes: [...get().nodes, newNode],
    edges: [...get().edges, newEdge],
  });
};
```

我們使用傳遞的節點作為父節點。通常這個功能用於實作[分組](/examples/nodes/dynamic-grouping)或[子流程](/examples/grouping/sub-flows)。在這裡，我們使用它來在父節點移動時移動所有子節點。這使我們能夠清理和重新排序心智圖，而不必手動移動所有子節點。讓我們在 `onConnectEnd` 處理器中使用新動作：

#### Adjustments in src/App/index.tsx

```tsx
const store = useStoreApi();

const onConnectEnd: OnConnectEnd = useCallback(
  (event) => {
    const { nodeLookup } = store.getState();
    const targetIsPane = (event.target as Element).classList.contains('react-flow__pane');

    if (targetIsPane && connectingNodeId.current) {
      const parentNode = nodeLookup.get(connectingNodeId.current);
      const childNodePosition = getChildNodePosition(event, parentNode);

      if (parentNode && childNodePosition) {
        addChildNode(parentNode, childNodePosition);
      }
    }
  },
  [getChildNodePosition],
);
```

首先，我們透過 `store.getState()` 從 React Flow 儲存區取得 `nodeLookup`。`nodeLookup` 是一個包含所有節點及其當前狀態的對應表。我們需要它來取得被點擊節點的位置和尺寸。然後我們檢查 onConnectEnd 事件的目標是否為 React Flow 的窗格。如果是，我們想新增一個新節點。為此，我們使用 `addChildNode` 和新建立的 `getChildNodePosition` 輔助函式。

#### Helper function in src/App/index.tsx

```tsx
const getChildNodePosition = (event: MouseEvent, parentNode?: Node) => {
  const { domNode } = store.getState();

  if (
    !domNode ||
    // we need to check if these properties exist, because when a node is not initialized yet,
    // it doesn't have a positionAbsolute nor a width or height
    !parentNode?.computed?.positionAbsolute ||
    !parentNode?.computed?.width ||
    !parentNode?.computed?.height
  ) {
    return;
  }

  const panePosition = screenToFlowPosition({
    x: event.clientX,
    y: event.clientY,
  });

  // we are calculating with positionAbsolute here because child nodes are positioned relative to their parent
  return {
    x:
      panePosition.x -
      parentNode.computed?.positionAbsolute.x +
      parentNode.computed?.width / 2,
    y:
      panePosition.y -
      parentNode.computed?.positionAbsolute.y +
      parentNode.computed?.height / 2,
  };
};
```

此函式回傳我們想要新增到儲存區的新節點的位置。我們使用 [`project` 函式](/api-reference/types/react-flow-instance#project) 將螢幕座標轉換為 React Flow 座標。如前所述，子節點的位置是相對於其父節點的。這就是為什麼我們需要從子節點位置中減去父節點位置。這需要理解不少內容，讓我們看看它的實際運作：

## <Emoji content="🤝" /> 保持資料同步

我們已經可以更新標籤了，但我們還沒有更新節點的資料物件。這對於保持應用程式同步很重要，例如如果我們想將節點儲存到伺服器上。為了實現這一點，我們在儲存區中新增一個名為 `updateNodeLabel` 的新動作。此動作接受節點 ID 和標籤。實作相當直接：我們遍歷現有節點，並使用傳遞的標籤更新匹配的節點：

#### src/store.ts

```ts
updateNodeLabel: (nodeId: string, label: string) => {
  set({
    nodes: get().nodes.map((node) => {
      if (node.id === nodeId) {
        // it's important to create a new object here, to inform React Flow about the changes
        node.data = { ...node.data, label };
      }

      return node;
    }),
  });
},
```

讓我們在 `MindmapNode` 元件中使用新動作：

#### src/App/MindmapNode/index.tsx

```tsx
import { Handle, NodeProps, Position } from '@xyflow/react';

import useStore from '../store';

export type NodeData = {
  label: string;
};

function MindMapNode({ id, data }: NodeProps<NodeData>) {
  const updateNodeLabel = useStore((state) => state.updateNodeLabel);

  return (
    <>
      <input
        // from now on we can use value instead of defaultValue
        // this makes sure that the input always shows the current label of the node
        value={data.label}
        onChange={(evt) => updateNodeLabel(id, evt.target.value)}
        className="input"
      />

      <Handle type="target" position={Position.Top} />
      <Handle type="source" position={Position.Top} />
    </>
  );
}

export default MindMapNode;
```

很快就完成了！自訂節點的輸入欄位現在會顯示節點的當前標籤。你可以取得節點資料，將其儲存到伺服器上，然後再次載入。

## <Emoji content="💅" /> 更簡單的使用者體驗和更美觀的樣式

從功能角度來看，我們的心智圖應用程式已經完成了！我們可以新增新節點、更新其標籤並移動它們。但使用者體驗和樣式還可以進一步改善。讓我們讓拖曳節點和建立新節點變得更容易！

### 1. 將節點作為控制點

讓我們使用整個節點作為控制點，而不是顯示預設的控制點。這使得建立節點變得更容易，因為可以開始新連接的區域變大了。我們需要設定來源控制點的樣式使其與節點大小相同，並在視覺上隱藏目標控制點。React Flow 仍然需要它來連接節點，但我們不需要顯示它，因為我們是透過在窗格上放置連線來建立新節點。我們使用簡單的 CSS 來隱藏目標控制點並將其定位在節點的中心：

```tsx
import useStore from '../store';

export type NodeData = {
  label: string;
};

function MindMapNode({ id, data }: NodeProps<NodeData>) {
  const updateNodeLabel = useStore((state) => state.updateNodeLabel);

  return (

      <div className="inputWrapper">

          {/* icon taken from grommet https://icons.grommet.io */}

          </svg>
        </div>
        <input
          value={data.label}
          onChange={(evt) => updateNodeLabel(id, evt.target.value)}
          className="input"
        />

      <Handle type="source" position={Position.Top} />
    </>
  );
}

export default MindMapNode;
```

### 2. 焦點時啟動輸入欄位

我們快完成了，但還需要調整一些細節。我們希望從節點的中心開始新連接。為此，我們將輸入欄位的指標事件設為 "none"，並檢查使用者是否在節點上方釋放按鈕。只有在那時我們才想啟動輸入欄位。我們可以使用 `onConnectEnd` 函式來實現這一點：

#### src/App/index.tsx

```tsx
const onConnectEnd: OnConnectEnd = useCallback(
  (event) => {
    const { nodeLookup } = store.getState();
    const targetIsPane = (event.target as Element).classList.contains('react-flow__pane');
    const node = (event.target as Element).closest('.react-flow__node');

    if (node) {
      node.querySelector('input')?.focus({ preventScroll: true });
    } else if (targetIsPane && connectingNodeId.current) {
      const parentNode = nodeLookup.get(connectingNodeId.current);
      const childNodePosition = getChildNodePosition(event, parentNode);

      if (parentNode && childNodePosition) {
        addChildNode(parentNode, childNodePosition);
      }
    }
  },
  [getChildNodePosition],
);
```

如你所見，如果使用者在節點上方釋放滑鼠按鈕，我們會將焦點設置到輸入欄位。現在我們可以新增一些樣式，使輸入欄位只有在獲得焦點時才被啟動（pointerEvents: all）：

```css
/* we want the connection line to be below the node */
.react-flow .react-flow__connectionline {
  z-index: 0;
}

/* pointer-events: none so that the click for the connection goes through */
.inputWrapper {
  display: flex;
  height: 20px;
  position: relative;
  z-index: 1;
  pointer-events: none;
}

/* pointer-events: all so that we can use the drag handle (here the user cant start a new connection) */
.dragHandle {
  background: transparent;
  width: 14px;
  height: 100%;
  margin-right: 4px;
  display: flex;
  align-items: center;
  pointer-events: all;
}

/* pointer-events: none by default */
.input {
  border: none;
  padding: 0 2px;
  border-radius: 1px;
  font-weight: 700;
  background: transparent;
  height: 100%;
  color: #222;
  pointer-events: none;
}

/* pointer-events: all when it's focused so that we can type in it */
.input:focus {
  border: none;
  outline: none;
  background: rgba(255, 255, 255, 0.25);
  pointer-events: all;
}
```

### 4. 置中連線和樣式細節

你可能已經注意到連線並未置中。我們在一開始就為此建立了自訂連線，現在我們可以稍微調整它，使連線從節點的中心開始，而不是從控制點的頂部開始（預設行為）：

#### src/App/MindMapEdge.tsx

```tsx
import { BaseEdge, EdgeProps, getStraightPath } from '@xyflow/react';

function MindMapEdge(props: EdgeProps) {
  const { sourceX, sourceY, targetX, targetY } = props;

  const [edgePath] = getStraightPath({
    sourceX,
    sourceY: sourceY + 20,
    targetX,
    targetY,
  });

  return <BaseEdge path={edgePath} {...props} />;
}

export default MindMapEdge;
```

我們將所有屬性傳遞給 [`getStraightPath`](/api-reference/utils/get-straight-path) 輔助函式，但調整 sourceY 使其位於節點的中心。
