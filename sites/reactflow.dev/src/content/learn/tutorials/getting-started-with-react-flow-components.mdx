_**2025 年 11 月更新**：我們已更新教學以使用最新版本的 shadcn/ui，運行在 React 19 和 Tailwind 4 上！_

_**2025 年 7 月更新**："React Flow UI" 以前稱為 "React Flow Components"。我們重新命名是因為它現在包含元件和模板。此外，由於它是建立在 shadcn/ui 之上的，"UI" 命名讓開發者更容易認識到這種連結並理解我們提供的內容。_

最近，我們推出了一個令人興奮的開源新成員：React Flow UI（以前稱為 React Flow Components）。這些是預先建立的節點、連線和其他使用者介面元素，你可以快速將它們新增到你的 React Flow 應用程式中以快速啟動和執行。需要注意的是，這些元件是建立在 [shadcn/ui](https://ui.shadcn.com) 和 shadcn CLI 之上的。

我們之前在 [xyflow 部落格](https://xyflow.com/blog/react-flow-components)上撰寫了關於我們的經驗以及為什麼選擇 shadcn 的文章，但在本教學中，我們將專注於如何從頭開始使用 shadcn、Tailwind CSS 和 React Flow Components。

<Callout>
**等等，什麼是 shadcn？**

不是什麼，是**誰**！Shadcn 是一系列預先設計的元件集合（稱為 `shadcn/ui`）的作者。注意我們並沒有說它是一個_函式庫_？Shadcn 採用了一種不同的方法，元件會被新增到你專案的原始碼中，並由你「擁有」：一旦你新增了元件，你可以自由地修改它以滿足你的需求！

</Callout>

## 入門

首先，我們將：

### 設定 Tailwind CSS

所有 shadcn 和 React Flow 元件都使用 [Tailwind CSS](https://tailwindcss.com/) 進行樣式設定，所以接下來我們需要安裝它和其他一些相依套件。

我們可以按照 [shadcn 安裝指南](https://ui.shadcn.com/docs/installation)中的說明在新建立的 vite 專案中安裝 shadcn 和 Tailwind CSS。

```bash copy npm2yarn
npm install tailwindcss @tailwindcss/vite
```

現在在 vite 專案中設定 Tailwind CSS 變得更簡單了，Tailwind 4 完全在 CSS 中進行設定。你只需要將生成的 `src/index.css` 檔案替換為這一行：

```css filename="src/index.css"
@import "tailwindcss";
```

### 將 Tailwind CSS 作為 Vite 外掛匯入

從 [Tailwind CSS v4](https://tailwindcss.com/blog/tailwindcss-v4) 開始，你可以使用專用的 Vite 外掛 `@tailwindcss/vite`，而不是傳統的 PostCSS 外掛。此外掛在我們的 `vite.config.ts` 檔案中進行設定，對開發者和編譯器來說都簡單得多。

我們只需要匯入外掛並將其新增到 `vite.config.ts` 檔案中的 `plugins` 陣列。我們還需要將 `alias` 屬性新增到 `resolve` 物件，以告訴 Vite 在哪裡找到我們的原始檔案，因為 shadcn 元件使用 `@` 別名來引用 `src` 目錄。

```ts filename="vite.config.ts" {1-2} {8-13}
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"
 
// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})
```


### 匯入 Tailwind CSS 檔案

現在我們需要確保專案中唯一的 CSS 檔案是 Tailwind CSS 檔案。在生成的 `App.tsx` 中，你可以安全地移除 `App.css` 檔案的匯入，並移除骨架 `App.tsx` 檔案中的其他所有內容。

為了驗證 Tailwind CSS 是否正常運作，我們可以新增一個簡單的 `div` 和 `h1` 元素並使用 Tailwind 類別。

更新後的 `App.tsx` 檔案應該看起來像這樣：

```tsx filename="src/App.tsx"
export function App() {
  return (
    <div className="w-screen h-screen p-8">
      <h1 className="text-2xl font-bold">Hello World</h1>
    </div>
  );
}
export default App;
```

And, the `main.tsx` file should look like this:
```tsx filename="src/main.tsx"
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import './index.css'
import App from './App.tsx'

createRoot(document.getElementById('root')!).render(
  <StrictMode>
    <App />
  </StrictMode>,
)
```

如果你更新了 `index.css` 檔案並設定 Vite 使用 Tailwind CSS 外掛，你應該能夠執行專案並在瀏覽器中看到 "Hello World" 訊息，以美觀、大型、粗體字型顯示。

<Callout>
  類別 `w-screen` 和 `h-screen` 是 Tailwind 實用類別的兩個範例。如果你習慣使用不同的方法為 React 應用程式設定樣式，一開始可能會覺得有點奇怪。你可以將 Tailwind 類別視為增強版的內聯樣式：它們受限於一組設計系統，你可以存取響應式媒體查詢或偽類別，如 `hover` 和 `focus`。
</Callout>

### 設定 shadcn/ui

Vite 在生成 TypeScript 專案時會為我們建立一些 `tsconfig` 檔案，我們需要對這些檔案進行一些更改，以便 shadcn 元件能夠正確運作。shadcn CLI 非常聰明（我們稍後會談到這一點），但它無法考慮到每個專案結構，因此相互依賴的 shadcn 元件會使用 TypeScript 的匯入路徑。

Vite 的當前版本將 TypeScript 設定拆分為三個檔案，其中兩個需要進行編輯。將 `baseUrl` 和 `paths` 屬性新增到 `tsconfig.json` 和 `tsconfig.app.json` 檔案的 `compilerOptions` 部分：

```json filename="tsconfig.json" {3-8}
{
  // ...
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
  // ...
}
```


```json filename="tsconfig.app.json" {4-7}
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
    // ...
  }
}
```


太好了！現在我們準備好設定 `shadcn/ui` CLI 並新增我們的第一個元件。設定好 CLI 後，我們就能夠用單一命令將新元件新增到我們的專案中 - 即使它們有相依性或需要修改現有檔案！

現在我們可以執行以下命令在專案中設定 shadcn/ui：

```bash copy npm2yarn
npx shadcn@latest init
```

```tsx filename="src/App.tsx"
        <BaseNodeContent>
          <NodeTooltipTrigger>Hover</NodeTooltipTrigger>

      </BaseNode>

  );
}

const nodeTypes = {
  tooltip: Tooltip,
};

const initialNodes: Node[] = [
  {
    id: "1",
    position: { x: 0, y: 0 },
    data: {},
    type: "tooltip",

function Flow() {

      <ReactFlow
        nodes={nodes}
        nodeTypes={nodeTypes}
        onNodesChange={onNodesChange}
        fitView
      />
    </div>
  );
}

export default function App() {
  return <Flow />;
}
```

### 數字節點

我們將建立的第一個節點是一個簡單的數字節點，帶有一些用於遞增和遞減值的按鈕，以及一個用於連接到其他節點的控制點。建立一個資料夾 `src/components/nodes`，然後新增一個新檔案 `src/components/nodes/num-node.tsx`。

我們需要安裝以下 `shadcn/ui` 元件：

```bash copy npm2yarn
npx shadcn@latest add dropdown-menu button
```

現在我們可以開始建立節點。我們需要從 `useReactFlow` hook 存取 `updateNodeData` 函式來更新節點的資料，以及存取 `setNodes` 函式來刪除節點。這個 hook 幫助我們建立可以在應用程式其他部分使用的自包含元件，同時仍然能夠快速存取 React Flow 的狀態和函式。

我們需要建立四個回呼函式來處理可以在節點上執行的不同動作。
- 將節點的值重設為 0
- 刪除節點
- 將節點的值遞增 1
- 將節點的值遞減 1

我們還需要存取節點的資料以取得當前值並更新它。

```tsx filename="src/components/nodes/num-node.tsx"
import { type Node, type NodeProps, Position, useReactFlow } from '@xyflow/react';
import { useCallback } from 'react';

import {
  BaseNode,
  BaseNodeContent,
  BaseNodeFooter,
  BaseNodeHeader,
  BaseNodeHeaderTitle,
} from '../base-node';
import { LabeledHandle } from '../labeled-handle';

import { EllipsisVertical } from 'lucide-react';
import { Button } from '../ui/button';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuTrigger,
} from '../ui/dropdown-menu';

export type NumNode = Node<{
  value: number;
}>;

export function NumNode({ id, data }: NodeProps<NumNode>) {
  const { updateNodeData, setNodes } = useReactFlow();

  const handleReset = useCallback(() => {
    updateNodeData(id, { value: 0 });
  }, [id, updateNodeData]);

  const handleDelete = useCallback(() => {
    setNodes((nodes) => nodes.filter((node) => node.id !== id));
  }, [id, setNodes]);

  const handleIncr = useCallback(() => {
    updateNodeData(id, { value: data.value + 1 });
  }, [id, data.value, updateNodeData]);

  const handleDecr = useCallback(() => {
    updateNodeData(id, { value: data.value - 1 });
  }, [id, data.value, updateNodeData]);

  return (
    <BaseNode>
      <BaseNodeHeader className="border-b">
        <BaseNodeHeaderTitle>Num</BaseNodeHeaderTitle>

        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button
              variant="ghost"
              className="nodrag p-1"
              aria-label="Node Actions"
              title="Node Actions"
            >
              <EllipsisVertical className="size-4" />
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent>
            <DropdownMenuLabel className="font-bold">Node Actions</DropdownMenuLabel>
            <DropdownMenuItem onSelect={handleReset}>Reset</DropdownMenuItem>
            <DropdownMenuItem onSelect={handleDelete}>Delete</DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenu>
      </BaseNodeHeader>

      <BaseNodeContent>
        <div className="flex gap-2 items-center">
          <Button onClick={handleDecr}>-</Button>
          <pre>{String(data.value).padStart(3, ' ')}</pre>
          <Button onClick={handleIncr}>+</Button>
        </div>
      </BaseNodeContent>

      <BaseNodeFooter className="bg-gray-100 items-end px-0 py-1 w-full  rounded-b-md">
        <LabeledHandle title="out" type="source" position={Position.Right} />
      </BaseNodeFooter>
    </BaseNode>
  );
}
```

### 加總節點

我們可以建立的第二個節點是一個簡單的加總節點，用於將兩個輸入節點的值相加。建立一個新檔案 `src/components/nodes/sum-node.tsx` 並貼上以下內容：

特別是，我們需要存取 `getNodeConnections` 函式來取得兩個連接的輸入節點的值，以及存取 `updateNodeData` 函式在 `useEffect` hook 內更新節點的資料，並在輸入節點的任一值變更時使用兩個輸入節點的總和進行更新。

```tsx filename="src/components/nodes/sum-node.tsx"
import {
  type Node,
  type NodeProps,
  Position,
  useReactFlow,
  useStore,
} from '@xyflow/react';
import { useCallback, useEffect } from 'react';

import {
  BaseNode,
  BaseNodeContent,
  BaseNodeFooter,
  BaseNodeHeader,
  BaseNodeHeaderTitle,
} from '../base-node';
import { LabeledHandle } from '../labeled-handle';
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuTrigger,
} from '../ui/dropdown-menu';
import { EllipsisVertical } from 'lucide-react';
import { Button } from '../ui/button';

export type SumNode = Node<{
  value: number;
}>;

export function SumNode({ id }: NodeProps<SumNode>) {
  const { updateNodeData, getNodeConnections, setNodes, setEdges } = useReactFlow();
  const { x, y } = useStore((state) => ({
    x: getHandleValue(
      getNodeConnections({ nodeId: id, handleId: 'x', type: 'target' }),
      state.nodeLookup,
    ),
    y: getHandleValue(
      getNodeConnections({ nodeId: id, handleId: 'y', type: 'target' }),
      state.nodeLookup,
    ),
  }));

  const handleDelete = useCallback(() => {
    setNodes((nodes) => nodes.filter((node) => node.id !== id));
    setEdges((edges) => edges.filter((edge) => edge.source !== id));
  }, [id, setNodes, setEdges]);

  useEffect(() => {
    updateNodeData(id, { value: x + y });
  }, [x, y]);

  return (
    <BaseNode className="w-32">
      <BaseNodeHeader className="border-b">
        <BaseNodeHeaderTitle>Sum</BaseNodeHeaderTitle>

        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button
              variant="ghost"
              className="nodrag p-1"
              aria-label="Node Actions"
              title="Node Actions"
            >
              <EllipsisVertical className="size-4" />
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent>
            <DropdownMenuLabel className="font-bold">Node Actions</DropdownMenuLabel>
            <DropdownMenuItem onSelect={handleDelete}>Delete</DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenu>
      </BaseNodeHeader>

      <BaseNodeContent className="px-0">
        <LabeledHandle title="x" id="x" type="target" position={Position.Left} />
        <LabeledHandle title="y" id="y" type="target" position={Position.Left} />
      </BaseNodeContent>
      <BaseNodeFooter className="bg-gray-100 items-end px-0 py-1 w-full rounded-b-md">
        <LabeledHandle title="out" type="source" position={Position.Right} />
      </BaseNodeFooter>
    </BaseNode>
  );
}

function getHandleValue(
  connections: Array<{ source: string }>,
  lookup: Map<string, Node<any>>,
) {
  return connections.reduce((acc, { source }) => {
    const node = lookup.get(source)!;
    const value = node.data.value;

    return typeof value === 'number' ? acc + value : acc;
  }, 0);
}
```

### 資料連線

React Flow UI 不僅提供用於建立節點的元件。我們還提供可以放入流程中以快速建構的預製連線和其他 UI 元素。

### 流程

現在我們可以將所有內容整合在一起並建立我們的流程。

我們將首先定義自訂節點和連線類型，以及將在應用程式中顯示的初始節點和連線。

```tsx filename="src/App.tsx"
import React, { useCallback } from 'react';
import {
  ReactFlow,
  type Node,
  type Edge,
  type OnConnect,
  addEdge,
  useNodesState,
  useEdgesState,
} from '@xyflow/react';

import { NumNode } from './components/nodes/num-node';
import { SumNode } from './components/nodes/sum-node';

import { DataEdge } from './components/data-edge';

import '@xyflow/react/dist/style.css';

const nodeTypes = {
  num: NumNode,
  sum: SumNode,
};

const initialNodes: Node[] = [
  { id: 'a', type: 'num', data: { value: 0 }, position: { x: 0, y: 0 } },
  { id: 'b', type: 'num', data: { value: 0 }, position: { x: 0, y: 200 } },
  { id: 'c', type: 'sum', data: { value: 0 }, position: { x: 300, y: 100 } },
  { id: 'd', type: 'num', data: { value: 0 }, position: { x: 0, y: 400 } },
  { id: 'e', type: 'sum', data: { value: 0 }, position: { x: 600, y: 400 } },
];

const edgeTypes = {
  data: DataEdge,
};

const initialEdges: Edge[] = [
  {
    id: 'a->c',
    type: 'data',
    data: { key: 'value' },
    source: 'a',
    target: 'c',
    targetHandle: 'x',
  },
  {
    id: 'b->c',
    type: 'data',
    data: { key: 'value' },
    source: 'b',
    target: 'c',
    targetHandle: 'y',
  },
  {
    id: 'c->e',
    type: 'data',
    data: { key: 'value' },
    source: 'c',
    target: 'e',
    targetHandle: 'x',
  },
  {
    id: 'd->e',
    type: 'data',
    data: { key: 'value' },
    source: 'd',
    target: 'e',
    targetHandle: 'y',
  },
];

function Flow() {
  const [nodes, , onNodesChange] = useNodesState(initialNodes);
  const [edges, setEdges, onEdgesChange] = useEdgesState(initialEdges);

  const onConnect: OnConnect = useCallback(
    (params) => {
      setEdges((edges) =>
        addEdge({ type: 'data', data: { key: 'value' }, ...params }, edges),
      );
    },
    [setEdges],
  );

  return (
    <div className="h-screen w-screen p-8 bg-gray-50 rounded-xl">
      <ReactFlow
        nodes={nodes}
        edges={edges}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
        nodeTypes={nodeTypes}
        edgeTypes={edgeTypes}
        fitView
      />
    </div>
  );
}

export function App() {
  return <Flow />;
}
```
