# 自訂連線

就像[自訂節點](/learn/customization/custom-nodes)一樣，React Flow 中的自訂連線元件也只是 React 元件。這意味著您可以在連線上渲染任何您想要的內容！本指南將介紹如何實作帶有額外控制項的自訂連線。有關自訂連線可用屬性的完整參考，請參閱 [Edge](/api-reference/types/edge-props) 參考文件。

## 基本的自訂連線

如果連線無法在兩個連接的節點之間渲染路徑，那就沒什麼用處了。這些路徑總是基於 SVG 的，通常使用 [`<BaseEdge />`](/api-reference/components/base-edge) 元件來渲染。為了計算實際要渲染的 SVG 路徑，React Flow 提供了一些方便的工具函式：

- [`getBezierPath`](/api-reference/utils/get-bezier-path)
- [`getSimpleBezierPath`](/api-reference/utils/get-simple-bezier-path)
- [`getSmoothStepPath`](/api-reference/utils/get-smooth-step-path)
- [`getStraightPath`](/api-reference/utils/get-straight-path)

為了開始建立自訂連線，我們先在來源和目標之間渲染一條直線路徑。

<Steps>

### 建立元件

我們首先建立一個名為 `CustomEdge` 的新 React 元件。然後使用計算出的路徑來渲染 [`<BaseEdge />`](/api-reference/components/base-edge) 元件。這樣我們就得到了一條行為與內建預設[連線類型](/api-reference/types/edge#default-edge-types) `"straight"` 相同的直線連線。

```jsx
import { BaseEdge, getStraightPath } from '@xyflow/react';

export function CustomEdge({ id, sourceX, sourceY, targetX, targetY }) {
  const [edgePath] = getStraightPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
  });

  return (
    <>
      <BaseEdge id={id} path={edgePath} />
    </>
  );
}
```

### 建立 `edgeTypes`

在元件外部，我們定義一個 `edgeTypes` 物件。
我們將新的連線類型命名為 `"custom-edge"`，並將剛剛建立的 `CustomEdge` 元件指派給它。

```jsx
const edgeTypes = {
  'custom-edge': CustomEdge,
};
```

### 傳遞 `edgeTypes` 屬性

為了使用它，我們還需要更新 `<ReactFlow />` 元件上的 [`edgeTypes`](/api-reference/react-flow#edge-types) 屬性。

```jsx "edgeTypes={edgeTypes}"
export function Flow() {
  return <ReactFlow edgeTypes={edgeTypes} />;
}
```

### 使用新的連線類型

定義好 `edgeTypes` 物件後，我們可以通過將連線的 `type` 欄位設定為 `"custom-edge"` 來使用新的自訂連線。

```jsx {6}
const initialEdges = [
  {
    id: 'e1',
    source: 'n1',
    target: 'n2',
    type: 'custom-edge',
  },
];
```

## 自訂 SVG 連線路徑

如前所述，如果您想要在 React Flow 中建立自訂連線，您必須使用上面討論的四個路徑建立函式之一（例如 [`getBezierPath`](/api-reference/utils/get-bezier-path)）。但是，如果您想要建立其他路徑形狀，例如正弦波連線或其他連線類型，那麼您就必須自己建立連線路徑。

我們從 [`getBezierPath`](/api-reference/utils/get-bezier-path) 等函式獲得的連線路徑只是一個路徑字串，我們將它傳入 `<BaseEdge />` 元件的 `path` 屬性。它包含繪製該路徑所需的必要資訊，例如它應該從哪裡開始、在哪裡彎曲、在哪裡結束等等。兩點 `(x1, y1)` 到 `(x2, y2)` 之間的簡單直線路徑字串如下所示：

```jsx
M x1 y1 L x2 y2
```

SVG 路徑是一個命令列表的串接，例如 `M`、`L`、`Q` 等，以及它們的值。以下列出了其中一些命令及其支援的值。

- `M x1 y1` 是 Move To（移動到）命令，它將當前點移動到 x1, y1 座標。
- `L x1 y1` 是 Line To（線段到）命令，它從當前點繪製一條線到 x1, y1 座標。
- `Q x1 y1 x2 y2` 是 Quadratic Bezier Curve（二次貝茲曲線）命令，它從當前點繪製一條貝茲曲線到 x2, y2 座標。x1, y1 是曲線的控制點，決定曲線的彎曲程度。

每當我們想要為自訂連線開始一個路徑時，我們使用 `M` 命令將當前點移動到 `sourceX, sourceY`，這是我們在自訂連線元件中作為屬性獲得的。然後根據我們想要的形狀，我們將使用其他命令，例如 `L`（製作線段）、`Q`（製作曲線），最後將路徑結束在 `targetX, targetY`，這也是我們在自訂連線元件中作為屬性獲得的。

如果您想要深入了解 SVG 路徑，可以查看 [SVG-Path-Editor](https://yqnn.github.io/svg-path-editor/)。您可以在那裡貼上任何 SVG 路徑，並通過直觀的使用者介面分析各個路徑命令。

以下是一個包含兩種自訂連線路徑類型的範例：階梯連線和正弦波連線。您應該先查看階梯連線以熟悉自訂 SVG 路徑，因為它很簡單，然後再看看正弦波連線是如何製作的。看完這個範例後，您將具備為自訂連線製作自訂 SVG 路徑的必要知識。
