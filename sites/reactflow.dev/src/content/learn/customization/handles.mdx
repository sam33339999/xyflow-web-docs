# 連接點

連接點是 React Flow 中[節點](/learn/concepts/terms-and-definitions#nodes)上的連接點。我們的內建節點包含一個來源連接點和一個目標連接點，但您可以根據需要為節點自訂任意數量的不同連接點。

## 建立具有連接點的節點

要建立具有連接點的[自訂節點](/learn/customization/custom-nodes)，您可以使用 React Flow 提供的 [`<Handle />`](/api-reference/components/handle) 元件。此元件允許您為自訂節點定義來源和目標連接點。以下是如何實作具有兩個連接點的自訂節點的範例：

```jsx {7-8}
import { Position, Handle } from '@xyflow/react';

export function CustomNode() {
  return (
    <div className="custom-node">
      <div>Custom Node Content</div>
      <Handle type="source" position={Position.Top} />
      <Handle type="target" position={Position.Bottom} />
    </div>
  );
}
```

## 使用多個連接點

如果您想在自訂節點中使用多個來源或目標連接點，您需要為每個連接點指定唯一的 `id`。這允許 React Flow 在連接連線時區分不同的連接點。

```jsx /id="a"/ /id="b"/
  <Handle type="target" position={Position.Top} />
  <Handle type="source" position={Position.Right} id="a" />
  <Handle type="source" position={Position.Bottom} id="b" />
```

要將連線連接到節點的特定連接點，請使用 `sourceHandle`（用於連線的起點）和 `targetHandle`（用於連線的終點）屬性。透過使用適當的連接點 `id` 定義 `sourceHandle` 或 `targetHandle`，您可以指示 React Flow 將連線附加到該特定連接點，確保連接按您的意圖進行。

```js "sourceHandle: 'a'" "sourceHandle: 'b'"
const initialEdges = [
  { id: 'n1-n2', source: 'n1', sourceHandle: 'a', target: 'n2' },
  { id: 'n1-n3', source: 'n1', sourceHandle: 'b', target: 'n3' },
];
```

在這種情況下，兩個連接點的來源節點都是 `n1`，但連接點 `id` 不同。一個來自連接點 id `a`，另一個來自 `b`。兩條連線也有不同的目標節點：

## 自訂連接點

您可以透過將任何自訂元件包裝在 [`<Handle />`](/api-reference/components/handle) 元件中來將其用作連接點。請按照以下步驟整合您的自訂元件：

1. 使用 [`<Handle />`](/api-reference/components/handle) 元件包裝您的自訂元件。
2. 透過將 `border` 和 `background` 設定為 `none` 來隱藏內建 [`<Handle />`](/api-reference/components/handle) 的外觀。
3. 將 [`<Handle />`](/api-reference/components/handle) 的 `width` 和 `height` 設定為與您的自訂元件相符。
4. 使用 `pointer-events: none` 為子元件設定樣式。
5. 然後，如有必要，使用 CSS 位置屬性（如 `top, left`）重新定位子自訂元件，以將其完美定位在 [`<Handle />`](/api-reference/components/handle) 元件內。

這個範例展示了使用 Material UI 圖示 `ArrowCircleRightIcon` 作為連接點。

```jsx
import { Handle, Position } from '@xyflow/react';
import ArrowCircleRightIcon from '@mui/icons-material/ArrowCircleRight';

export function CustomNode() {
  return (
    <div className="react-flow__node-default">
      <Handle
        position={Position.Right}
        type="source"
        style={{
          background: 'none',
          border: 'none',
          width: '1em',
          height: '1em',
        }}
      >
        <ArrowCircleRightIcon
          style={{
            pointerEvents: 'none',
            fontSize: '1em',
            left: 0,
            position: 'absolute',
          }}
        />
      </Handle>
      Custom Node
    </div>
  );
}
```

## 無類型連接點

如果您想建立沒有特定類型（來源或目標）的連接點，您可以在 `<ReactFlow />` 元件中將 [connectionMode](/api-reference/react-flow#connectionmode) 設定為 `Loose`。這允許連接點用於傳入和傳出連接。

## 動態連接點

如果您以程式方式更改自訂節點中連接點的位置或數量，您需要使用 [`useUpdateNodeInternals`](/api-reference/hooks/use-update-node-internals) hook 更新節點內部狀態。

## 自訂連接點樣式

由於連接點是一個 div，您可以使用 CSS 來設定其樣式，或傳遞樣式屬性來自訂連接點。您可以在[在連線上放置時新增節點](/examples/nodes/add-node-on-edge-drop)和[簡單浮動連線](/examples/edges/simple-floating-edges)範例中看到這一點。

### 連接時設定連接點樣式

當連接線位於連接點上方時，連接點會接收額外的類別名稱 `connecting`，如果連接有效，則會接收 `valid`。您可以在[這裡](/examples/interaction/validation)找到使用這些類別的範例。

### 隱藏連接點

如果您需要因某種原因隱藏連接點，您必須使用 `visibility: hidden` 或 `opacity: 0` 而不是 `display: none`。這很重要，因為 React Flow 需要計算連接點的尺寸才能正常工作，使用 `display: none` 會報告寬度和高度為 `0`！
