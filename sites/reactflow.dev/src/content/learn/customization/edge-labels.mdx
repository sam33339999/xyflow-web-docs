# 連線標籤

[自訂連線](/learn/customization/custom-edges)的一個常見用途是沿著連線路徑渲染一些控制項或資訊。在 React Flow 中，我們將其稱為_自訂連線標籤_，與連線路徑不同，連線標籤可以是任何 React 元件！

## 新增連線標籤

要渲染自訂連線標籤，我們必須將其包裝在 [`<EdgeLabelRenderer />`](/api-reference/components/edge-label-renderer) 元件中。這允許我們在連線所在的 SVG 世界之外渲染標籤。連線標籤渲染器是一個入口，所有連線標籤都渲染到單一容器中。

讓我們在自訂連線上新增一個按鈕，該按鈕可用於刪除它所附加的連線：

```jsx
import {
  BaseEdge,
  EdgeLabelRenderer,
  getStraightPath,
  useReactFlow,
} from '@xyflow/react';

export default function CustomEdge({ id, sourceX, sourceY, targetX, targetY }) {
  const { deleteElements } = useReactFlow();
  const [edgePath] = getStraightPath({
    sourceX,
    sourceY,
    targetX,
    targetY,
  });

  return (
    <>
      <BaseEdge id={id} path={edgePath} />
      <EdgeLabelRenderer>
        <button onClick={() => deleteElements({ edges: [{ id }] })}>delete</button>
      </EdgeLabelRenderer>
    </>
  );
}
```

如果我們現在嘗試使用這條連線，我們會看到按鈕渲染在流程的中心（它可能隱藏在「Node A」後面）。由於連線標籤入口的關係，我們需要做一些額外的工作來自行定位按鈕。

幸運的是，我們已經看到的路徑工具可以幫助我們！除了要渲染的 SVG 路徑外，這些函式還返回路徑中點的 `x` 和 `y` 座標。然後我們可以使用這些座標將自訂連線標籤平移到正確的位置！

```jsx
export default function CustomEdge({ id, sourceX, sourceY, targetX, targetY }) {
  const { deleteElements } = useReactFlow();
  const [edgePath, labelX, labelY] = getStraightPath({ ... });

  return (
    ...
        <button
          style={{
            position: 'absolute',
            transform: `translate(-50%, -50%) translate(${labelX}px, ${labelY}px)`,
            pointerEvents: 'all',
          }}
          className="nodrag nopan"
          onClick={() => deleteElements({ edges: [{ id }] })}
        >
    ...
  );
}
```

<Callout type="info">
  為了確保我們的連線標籤是互動的而不僅僅是用於展示，重要的是要將 `pointer-events: all` 新增到標籤的樣式中。這將確保標籤可點擊。

就像自訂節點中的互動控制項一樣，我們需要記得將 `nodrag` 和 `nopan` 類別新增到標籤，以阻止滑鼠事件控制畫布。

</Callout>
