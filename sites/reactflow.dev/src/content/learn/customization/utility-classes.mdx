# 工具類別

React Flow 提供了幾個內建的工具 CSS 類別，幫助您微調自訂元素內的互動方式。

## `nodrag`

將 `nodrag` 類別新增到元素可確保與其互動不會觸發拖曳。這對於按鈕或輸入等元素特別有用，這些元素在點擊時不應啟動拖曳操作。

節點預設具有 `drag` 類別名稱。但是，此類別名稱可能會影響自訂節點內事件監聽器的行為。為了防止意外行為，請將 `nodrag` 類別名稱新增到具有事件監聽器的元素。這可以防止預設拖曳行為以及點擊具有此類別的元素時的預設節點選擇行為。

```tsx
export default function CustomNode(props: NodeProps) {
  return (
    <div>
      <input className="nodrag" type="range" min={0} max={100} />
    </div>
  );
}
```

## `nopan`

如果畫布中的元素不阻止滑鼠事件傳播，點擊並拖曳該元素將平移視口。新增 "nopan" 類別可防止此行為，此屬性允許您更改該類別的名稱。

```tsx
export default function CustomNode(props: NodeProps) {
  return (
    <div className="nopan">
      <p>fixed content...</p>
    </div>
  );
}
```

## `nowheel`

如果您的自訂元素包含可捲動內容，您可以套用 `nowheel` 類別。這會在您在自訂節點內捲動時停用畫布的預設平移行為，確保只捲動內容而不是移動整個畫布。

```tsx
export default function CustomNode(props: NodeProps) {
  return (
    <div className="nowheel" style={{ overflow: 'auto' }}>
      <p>Scrollable content...</p>
    </div>
  );
}
```

套用這些工具類別可協助您在精細層級控制互動。您可以在 React Flow 的 [style props](/api-reference/react-flow/#style-props) 中自訂這些類別名稱。

<Callout type="info">
  建立自己的自訂節點時，您還需要記得為它們設定樣式！與內建節點不同，自訂節點沒有預設樣式，因此請隨意使用您偏好的任何樣式方法，例如 [Tailwind CSS](/examples/styling/tailwind)。
</Callout>
