# 自訂節點

React Flow 的強大功能之一是能夠建立自訂節點。這讓您能夠靈活地在節點中渲染任何您想要的內容。我們通常建議建立您自己的自訂節點，而不是依賴內建節點。使用自訂節點，您可以新增任意數量的來源和目標[連接點](/learn/customization/handles)，甚至可以嵌入表單輸入、圖表和其他互動元素。

在本節中，我們將逐步建立一個具有輸入欄位的自訂節點，該節點可以更新應用程式其他位置的文字。更多範例，建議查看我們的[自訂節點範例](/examples/nodes/custom-node)。

## 實作自訂節點

要建立自訂節點，您只需建立一個 React 元件。React Flow 會自動將其包裝在一個互動容器中，該容器會注入基本屬性，例如節點的 id、position 和 data，並提供選擇、拖曳和連接連接點的功能。有關所有可用節點屬性的完整概述，請參閱 [Node](/api-reference/types/node-props) 參考文件。

<Steps>
### 建立元件

讓我們透過建立一個名為 `TextUpdaterNode` 的自訂節點來深入範例。為此，我們新增了一個簡單的輸入欄位和變更處理函式。

```jsx
export function TextUpdaterNode(props) {
  const onChange = useCallback((evt) => {
    console.log(evt.target.value);
  }, []);

  return (
    <div className="text-updater-node">
      <div>
        <label htmlFor="text">Text:</label>
        <input id="text" name="text" onChange={onChange} className="nodrag" />
      </div>
    </div>
  );
}
```

### 初始化 nodeTypes

您可以透過將新節點類型新增到 `nodeTypes` 屬性來將其新增到 React Flow，如下所示。我們在元件外部定義 `nodeTypes` 以防止重新渲染。

```jsx
const nodeTypes = {
  textUpdater: TextUpdaterNode,
};
```

### 將 nodeTypes 傳遞給 React Flow

```jsx {4}
<ReactFlow
  nodes={nodes}
  edges={edges}
  nodeTypes={nodeTypes}
  onNodesChange={onNodesChange}
  onEdgesChange={onEdgesChange}
  fitView
/>
```

### 更新節點定義

定義好新的節點類型後，您可以透過在節點定義上指定 `type` 屬性來使用它：

```jsx {4}
const nodes = [
  {
    id: 'node-1',
    type: 'textUpdater',
    position: { x: 0, y: 0 },
    data: { value: 123 },
  },
];
```
