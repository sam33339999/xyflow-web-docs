# 主題

React Flow 在建構時充分考慮了深度自訂。我們的許多使用者完全改變了 React Flow 的外觀和感覺，以符合他們自己的品牌或設計系統。本指南將介紹您可以自訂 React Flow 外觀的不同方式。

## 預設樣式

React Flow 的預設樣式足以讓您開始使用內建節點。它們為填充、邊框半徑和動畫連線等樣式提供了一些合理的預設值。您可以在下面看到它們的外觀：

您通常會通過在 `App.jsx` 檔案或其他入口點中匯入這些預設樣式來載入它們：

```js
import '@xyflow/react/dist/style.css';
```

在不深入研究[自訂節點](/examples/nodes/custom-node)和[連線](/examples/edges/custom-edges)的情況下，您可以透過三種方式設定 React Flow 的基本外觀：

- 透過 `style` 屬性傳遞內聯樣式
- 使用自訂 CSS 覆寫內建類別
- 覆寫 React Flow 使用的 CSS 變數

### 內建深色和淺色模式

您可以使用 `colorMode` 屬性（'dark'、'light' 或 'system'）選擇內建顏色模式之一，如[深色模式範例](/examples/styling/dark-mode)所示。

```jsx
import ReactFlow from '@xyflow/react';

export default function Flow() {
  return <ReactFlow colorMode="dark" nodes={[...]} edges={[...]} />
}
```

當您使用 `colorMode` 屬性時，React Flow 會將一個類別新增到根元素（`.react-flow`），您可以使用該類別根據顏色模式設定流程樣式：

```css
.dark .react-flow__node {
  background: #777;
  color: white;
}

.light .react-flow__node {
  background: white;
  color: #111;
}
```

### 使用 `style` 屬性自訂

開始自訂流程外觀和感覺的最簡單方法是使用 React Flow 許多元件上的 `style` 屬性來內聯您自己的 CSS。

```jsx
import ReactFlow from '@xyflow/react'

const styles = {
  background: 'red',
  width: '100%',
  height: 300,
};

export default function Flow() {
  return <ReactFlow style={styles} nodes={[...]} edges={[...]} />
}
```

### 覆寫內建類別

有些人認為大量使用內聯樣式是一種反模式。在這種情況下，您可以使用自己的 CSS 覆寫 React Flow 使用的內建類別。React Flow 中有許多類別附加到各種元素，但您可能想要覆寫的類別如下所示：

| Class name                         | Description                                                                              |
| :--------------------------------- | :--------------------------------------------------------------------------------------- |
| `.react-flow`                      | 最外層容器                                                                  |
| `.react-flow__renderer`            | 內層容器                                                                      |
| `.react-flow__zoompane`            | 縮放和平移窗格                                                                          |
| `.react-flow__selectionpane`       | 選擇窗格                                                                           |
| `.react-flow__selection`           | 使用者選擇                                                                           |
| `.react-flow__edges`               | 包含流程中所有連線的元素                                             |
| `.react-flow__edge`                | 套用於流程中的每個 [`Edge`](/api-reference/types/edge)                          |
| `.react-flow__edge.selected`       | 當 [`Edge`](/api-reference/types/edge) 被選擇時新增                            |
| `.react-flow__edge.animated`       | 當 [`Edge`](/api-reference/types/edge) 的 `animated` 屬性為 `true` 時新增       |
| `.react-flow__edge.updating`       | 當 [`Edge`](/api-reference/types/edge) 透過 `onReconnect` 更新時新增  |
| `.react-flow__edge-path`           | [`Edge`](/api-reference/types/edge) 的 SVG `<path />` 元素                     |
| `.react-flow__edge-text`           | [`Edge`](/api-reference/types/edge) 標籤的 SVG `<text />` 元素               |
| `.react-flow__edge-textbg`         | [`Edge`](/api-reference/types/edge) 標籤後面的 SVG `<text />` 元素           |
| `.react-flow__connection`          | 套用於當前連接線                                                   |
| `.react-flow__connection-path`     | 連接線的 SVG `<path />`                                                  |
| `.react-flow__nodes`               | 包含流程中所有節點的元素                                             |
| `.react-flow__node`                | 套用於流程中的每個 [`Node`](/api-reference/types/node)                          |
| `.react-flow__node.selected`       | 當 [`Node`](/api-reference/types/node) 被選擇時新增                            |
| `.react-flow__node-default`        | 當 [`Node`](/api-reference/types/node) 類型為 `"default"` 時新增                       |
| `.react-flow__node-input`          | 當 [`Node`](/api-reference/types/node) 類型為 `"input"` 時新增                         |
| `.react-flow__node-output`         | 當 [`Node`](/api-reference/types/node) 類型為 `"output"` 時新增                        |
| `.react-flow__nodesselection`      | 節點選擇                                                                          |
| `.react-flow__nodesselection-rect` | 節點選擇矩形                                                                     |
| `.react-flow__handle`              | 套用於每個 [`<Handle />`](/api-reference/components/handle) 元件               |
| `.react-flow__handle-top`          | 當連接點的 [`Position`](/api-reference/types/position) 設定為 `"top"` 時套用    |
| `.react-flow__handle-right`        | 當連接點的 [`Position`](/api-reference/types/position) 設定為 `"right"` 時套用  |
| `.react-flow__handle-bottom`       | 當連接點的 [`Position`](/api-reference/types/position) 設定為 `"bottom"` 時套用 |
| `.react-flow__handle-left`         | 當連接點的 [`Position`](/api-reference/types/position) 設定為 `"left"` 時套用   |
| `.connectingfrom`                  | 當連接線位於連接點上方時新增到連接點                              |
| `.connectingto`                    | 當連接線位於連接點上方時新增到連接點                              |
| `.valid`                           | 當連接線位於連接點上方**且**連接有效時新增到連接點        |
| `.react-flow__background`          | 套用於 [`<Background />`](/api-reference/components/background) 元件        |
| `.react-flow__minimap`             | 套用於 [`<MiniMap />`](/api-reference/components/minimap) 元件              |
| `.react-flow__controls`            | 套用於 [`<Controls />`](/api-reference/components/controls) 元件            |

<Callout type="warning">
  如果您在原始碼中尋找其他要覆寫的類別，請小心。某些類別在內部使用，是函式庫正常運作所必需的。如果您替換它們，可能會遇到意外的錯誤！
</Callout>

## 第三方解決方案

您可以選擇完全退出 React Flow 的預設樣式，改用第三方樣式解決方案。如果您想這樣做，您必須確保仍然匯入基本樣式。

```js
import '@xyflow/react/dist/base.css';
```

<Callout type="warning">
  這些基本樣式是 React Flow 正確運作所**必需**的。如果您不匯入它們或使用自己的樣式覆寫它們，某些功能可能無法正常工作！
</Callout>

### TailwindCSS

自訂節點和連線只是 React 元件，您可以使用任何您喜歡的樣式解決方案來設定它們的樣式。例如，您可能想使用 [Tailwind](https://tailwindcss.com/) 來設定節點樣式：

```jsx
function CustomNode({ data }) {
  return (
    <div className="px-4 py-2 shadow-md rounded-md bg-white border-2 border-stone-400">
      <div className="flex">
        <div className="rounded-full w-12 h-12 flex justify-center items-center bg-gray-100">
          {data.emoji}
        </div>
        <div className="ml-2">
          <div className="text-lg font-bold">{data.name}</div>
          <div className="text-gray-500">{data.job}</div>
        </div>
      </div>

      <Handle
        type="target"
        position={Position.Top}
        className="w-16 !bg-teal-500"
      />
      <Handle
        type="source"
        position={Position.Bottom}
        className="w-16 !bg-teal-500"
      />
    </div>
  );
}
```

<Callout type="warning">
  如果您想覆寫預設樣式，請確保在 React Flow 基本樣式之後匯入 Tailwind 的入口點。
</Callout>

```js
import '@xyflow/react/dist/style.css';
import 'tailwind.css';
```

有關使用 Tailwind 與 React Flow 的完整範例，請查看[範例](/examples/styling/tailwind)！
