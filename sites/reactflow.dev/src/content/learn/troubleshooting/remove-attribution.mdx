# 移除署名

此範例展示如何從渲染器中移除 React Flow 署名。

<Callout type="info">
如果你正在考慮移除署名，我們首先想要提到：

**如果你在組織中使用 React Flow 並從中獲利**，我們依賴你的支援來讓 React Flow 在 MIT 授權下持續開發和維護。在你移除署名之前，[查看你可以支援 React Flow 以保持其運作的方式](/pro)。

**你是為個人專案使用 React Flow 嗎？** 太好了！請繼續移除署名。你可以透過回報你發現的任何錯誤、向我們發送專案截圖，以及在 [Github](https://github.com/xyflow/xyflow) 上給我們星星來支援我們。如果你將來開始使用 React Flow 獲利或在組織中使用它，我們希望你重新新增署名或註冊我們的訂閱之一。

感謝你支援我們 ✌🏻

- [xyflow 團隊](https://xyflow.com/about)

</Callout>
