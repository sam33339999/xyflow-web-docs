# React Flow UI

使用 [shadcn/ui](https://ui.shadcn.com/) 元件和 [Tailwind CSS](https://tailwindcss.com/) 建立的即用型 React Flow 元件。適用於新專案、MVP，或當你需要快速啟動和運行時。

> [!NOTE]
>
> React Flow UI 已更新以支援最新版本的 shadcn/ui，基於 **React 19 和 Tailwind 4**！閱讀更多關於變更和如何升級的資訊[在這裡](/whats-new/2025-10-28)。

## 先決條件

你需要在專案中**配置 shadcn 和 tailwind**。如果你還沒有安裝它，可以按照 [shadcn 安裝指南](https://ui.shadcn.com/docs/installation)中的步驟操作。如果 shadcn 和 tailwind 已經是你專案的一部分，你可以透過執行以下命令來初始化 shadcn-ui：

```bash copy npm2yarn
npx shadcn@latest init
```

如果你想了解更多關於這個專案背後的動機，可以在[這裡](https://xyflow.com/blog/react-flow-components)找到詳細的部落格文章。對於更深入的教學，我們最近還發布了一個關於[開始使用 React Flow UI](/learn/tutorials/getting-started-with-react-flow-components) 的新指南。

> [!IMPORTANT]
>
> 使用 React Flow UI 元件**需要在匯入 shadcn UI 樣式表之前匯入主要的 React Flow CSS 樣式表**。你通常在使用主要 [`<ReactFlow>`](/api-reference/react-flow) 元件的 Typescript 或 Javascript 檔案中執行此操作。

```tsx filename="App.tsx"
import '@xyflow/react/dist/style.css';
```

## 使用方法

找到你喜歡的元件並執行命令將其新增到你的專案中。

```bash copy npm2yarn
npx shadcn@latest add https://ui.reactflow.dev/component-name
```

- 此命令將元件程式碼複製到你的 components 資料夾中。你可以透過在 `components.json` 中新增別名來更改此資料夾。

- 它會自動安裝所有必要的依賴項

- 它利用先前新增甚至修改過的元件，或詢問你是否要覆寫它們。

- 它使用你現有的 tailwind 配置。

- 元件**不是黑盒子**，可以**修改和擴展**以滿足你的需求。

有關更多資訊，請造訪 [shadcn 文檔](https://ui.shadcn.com/docs)。
