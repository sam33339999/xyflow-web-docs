# Node Search

可用於在流程中搜尋節點的搜尋列元件。

它使用來自 [shadcn ui](https://ui.shadcn.com) 的 [Command](https://ui.shadcn.com/docs/components/command) 元件。

預設情況下，它會檢查節點標籤中的小寫字串包含，並在選擇時選擇節點並將視圖適配到節點。你可以透過傳遞自訂 `onSearch` 函式來覆寫此行為。你也可以覆寫預設的 `onSelectNode` 函式以自訂選擇節點時的行為。
