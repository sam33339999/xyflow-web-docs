# Base Node

具有基本樣式的節點包裝器，用於在應用程式中的所有節點之間建立共享設計。類似於 [shadcn ui 的 card](https://ui.shadcn.com/docs/components/card)，元件檔案匯出：

- `BaseNode` 主容器
- `BaseNodeHeader` 容器，通常在其中新增動作和 `BaseNodeHeaderTitle`
- `BaseNodeContent` 容器，在其中新增節點的主要內容
- `BaseNodeFooter` 容器，在其中可能想要新增額外資訊或可見的動作

如果你需要微調拖曳和捲動等互動如何與自訂元件配合使用，React Flow 提供了[數個 CSS 工具類別](/learn/customization/utility-classes)

你應該在節點的互動元件（例如按鈕）中使用 `nodrag` [React Flow 工具類別](/learn/customization/utility-classes)，以在使用者與按鈕或滑桿互動時停用在流程內拖曳節點。

## 主題

要自訂自訂節點的視覺外觀，你可以簡單地使用 [Tailwind CSS](https://tailwindcss.com/) 類別。所有 React Flow 元件都基於 [shadcn UI](https://ui.shadcn.com/)，你應該遵循 [shadcn UI 主題指南](https://ui.shadcn.com/docs/theming)來自訂應用程式中的字體和顏色等方面。

不過，在大多數情況下，開發自訂節點時，你可能只需要新增自訂 Tailwind CSS 類別。所有 `BaseNode` 元件都只是 `<div>` 的輕量包裝器。

例如，要根據假設的執行狀態更改節點的邊框顏色，你可以傳遞額外的 `className`：

```tsx
// 假設你的元件正在接收 `data` prop
export const BaseNodeSimpleDemo = memo(({ data }: NodeProps) => {
  return (
    <BaseNode
      className={cn('w-[350px] p-0 hover:ring-orange-500', {
        'border-orange-500': data.status === 'loading',
        'border-red-500': data.status === 'error',
      })}
    >
      {/* Your custom node definiton goes here */}
    </BaseNode>
  );
});
```
