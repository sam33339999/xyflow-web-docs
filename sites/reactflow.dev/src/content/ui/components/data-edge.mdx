## 額外的型別安全

建立此類型的新連線時，你可以使用 TypeScript 的 `satisfies` 謂詞以及應用程式中節點的特定型別，以確保連線資料的 `key` 屬性是節點資料的有效鍵。

```ts
type CounterNode = Node<{ count: number }>;

const initialEdges = [
  {
    id: 'edge-1',
    source: 'node-1',
    target: 'node-2',
    type: 'dataEdge',
    data: {
      key: 'count',
    } satisfies DataEdge<CounterNode>,
  },
];
```

如果你嘗試使用節點資料中不存在的鍵，TypeScript 將顯示如下錯誤訊息：

> ts: Type '"value"' is not assignable to type '"count"'.
