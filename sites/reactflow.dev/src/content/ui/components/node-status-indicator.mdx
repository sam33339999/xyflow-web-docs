# Node Status Indicator

具有多種狀態以指示節點狀態的節點包裝器。狀態可以是以下之一：`"success"`、`"loading"`、`"error"` 和 `"initial"`。

此外，`NodeStatusIndicator` 元件支援不同的載入變體：`"border"` 和 `"overlay"`，可以使用 `loadingVariant` prop 設定。
- `"border"` 變體是預設值，在節點處於載入狀態時會在節點周圍顯示旋轉邊框。
- `"overlay"` 變體會在節點處於載入狀態時顯示完整覆蓋層，並在節點上顯示動畫旋轉器。
