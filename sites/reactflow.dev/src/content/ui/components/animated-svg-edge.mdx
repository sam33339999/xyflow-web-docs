# Animated SVG Edge

沿著連線路徑動畫自訂 SVG 元素的連線。此元件基於[動畫 SVG 元素範例](/examples/edges/animating-edges)。

<UiComponentViewer id="animated-svg-edge" />

## 自訂形狀

你可以在模組中新增自己的 SVG 形狀。每個形狀應該是一個接受一個 prop `animateMotionProps` 並回傳一些 SVG 的 React 元件。

你可以在單獨的檔案中或與連線元件相同的檔案中定義這些形狀。要使用它們，你需要將它們新增到 `shapes` 記錄中，如下所示：

```tsx
const shapes = {
  box: ({ animateMotionProps }) => (
    <rect width="5" height="5" fill="#ff0073">
      <animateMotion {...animateMotionProps} />
    </rect>
  ),
} satisfies Record<string, AnimatedSvg>;
```

`shapes` 記錄的鍵是連線資料的 `shape` 欄位的有效值：

```ts
const initialEdges = [
  {
    // ...
    type: "animatedSvgEdge",
    data: {
      duration: 2,
      shape: "box",
    },
  } satisfies AnimatedSvgEdge,
];
```

<Callout type="info">
  如果你想渲染常規的 HTML 元素，請確保將它們包裝在 SVG `<foreignObject />` 元素中。確保為 `<foreignObject />` 提供一個 `id` 屬性，並在渲染 `<animateMotion />` 元素時將其用作 `href` 屬性。
</Callout>
