# AI Workflow Editor

AI 工作流程編輯器範本是一個 Next.js 範本，用於快速開始使用 AI 工作流程應用程式。它基於我們的[工作流程編輯器範本](/ui/templates/workflow-editor)、[AI SDK](https://ai-sdk.dev/) 和 [shadcn/ui](https://ui.shadcn.com/)。

## 技術堆疊

- **React Flow UI**：專案使用 [React Flow UI](/ui) 作為節點。這些元件旨在幫助你快速上手專案。

- **shadcn CLI**：專案使用 [shadcn CLI](https://ui.shadcn.com/docs/cli) 管理 UI 元件。此工具建立在 [Tailwind CSS](https://tailwindcss.com/) 和 [shadcn/ui](https://ui.shadcn.com/) 元件之上，使新增和自訂 UI 元素變得容易。

- **AI SDK**：範本使用 [AI SDK](https://ai-sdk.dev/) 在工作流程編輯器中提供 AI 驅動的功能。

- **使用 Zustand 的狀態管理**：AI 工作流程編輯器範本使用 Zustand 進行狀態管理，提供簡單且高效的方式來管理節點、連線和其他工作流程相關資料的狀態。
