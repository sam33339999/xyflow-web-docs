# Workflow Editor

工作流程編輯器範本是一個基於 Next.js 的應用程式，旨在幫助你快速建立、管理和視覺化工作流程。使用 [React Flow UI](/ui) 建構並使用 [Tailwind CSS](https://tailwindcss.com/) 和 [shadcn/ui](https://ui.shadcn.com/) 設計樣式，此專案為建構和擴展工作流程編輯器提供了高度可自訂的基礎。

## 技術堆疊

- **React Flow UI**：專案使用 [React Flow UI](/ui) 建構節點。這些元件旨在幫助你快速上手專案。

- **shadcn CLI**：專案使用 [shadcn CLI](https://ui.shadcn.com/docs/cli) 管理 UI 元件。此工具建立在 [Tailwind CSS](https://tailwindcss.com/) 和 [shadcn/ui](https://ui.shadcn.com/) 元件之上，使新增和自訂 UI 元素變得容易。

- **使用 Zustand 的狀態管理**：應用程式使用 Zustand 進行狀態管理，提供簡單且高效的方式來管理節點、連線和其他工作流程相關資料的狀態。

## 功能

- **自動佈局**：利用 [ELKjs](https://github.com/kieler/elkjs) 佈局引擎自動排列節點和連線。
- **拖放側邊欄**：使用拖放機制新增和排列節點。
- **可自訂元件**：使用 React Flow UI 和 shadcn 函式庫建立高度可自訂的節點和連線。
- **深色模式**：在淺色和深色主題之間切換，透過 Zustand store 管理。
- **執行器功能**：使用工作流程執行器依序執行和監控節點。
