  question="可以簡要描述 Hubql 嗎？"
  answer="Hubql 是一個協作平台，用於一起建立和視覺化資料架構。"

<QandA
  question="你為什麼決定使用 React Flow？"
  answer="我們正在尋找一個 React 函式庫，幫助我們將資料模型轉換為視覺化，而不需要花太多時間建立抽象和互動元素。為了節省開發時間，我們選擇了一個穩定、成熟且功能豐富的函式庫，我們可以用自訂渲染選項來擴展它。"
/>

<QandA
  question="你目前如何使用函式庫？"
  answer="我們使用 React Flow 將資料模型（如 JSON 或 Prisma）轉換為圖表或圖形。我們將 AST（抽象語法樹）資料傳遞給 React Flow，以根據資料關係生成節點和連線。然後使用自訂節點以類似表格的 UI 渲染這些節點，以便更容易理解。"
/>

<QandA
  question="React Flow 中有什麼特別有用的東西？"
  answer="主要是控制節點拖曳和點擊行為的事件非常有用，可以擴展功能。此外，自訂節點的渲染在使用者介面中提供了非常高的靈活性，可以提供豐富的使用者體驗和品牌化。"
/>

<QandA
  question="在過程中你遇到任何問題嗎？"
  answer="實際上我們沒有遇到任何問題，除了我們這邊的效能問題，可以透過優化我們的 React 程式碼來解決。React Flow 本身非常穩定，開箱即用就提供了出色的效能。"
/>

<QandA
  question="到目前為止，React Flow 訂閱的功能如何幫助你？"
  answer="有一個 Pro 範例符合我們的使用案例。這節省了我們在自動布局和分組功能上的實作時間，這對我們來說是關鍵。直接從 React Flow 團隊獲得支援，以及直接回饋給維護者也很棒。"
/>
