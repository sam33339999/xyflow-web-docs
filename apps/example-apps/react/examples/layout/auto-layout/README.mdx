這個範例展示如何自動排列節點。它引入了可重複使用的 `useAutoLayout` 鉤子，並展示三個流行的佈局引擎，你可以在執行時期之間切換：[dagre](https://github.com/dagrejs/dagre)、[d3-hierarchy](https://github.com/d3/d3-hierarchy) 和 [elk](https://github.com/kieler/elkjs)。

<ProExampleViewer slug="auto-layout" />

### 關於此專業版範例

- 依賴套件：[@xyflow/react](https://www.npmjs.com/package/@xyflow/react)、[@dagrejs/dagre](https://www.npmjs.com/package/@dagrejs/dagre)、[d3-hierarchy](https://www.npmjs.com/package/d3-hierarchy)、[elkjs](https://www.npmjs.com/package/elkjs)
- 包含可配置的 `useAutoLayout` 鉤子，可在你的應用程式中重複使用
- 提供不同佈局演算法的比較以及互動控制項
- 注意：在你自己的應用程式中，通常只需要選擇一個佈局引擎
