這個範例展示如何將 [dagre.js](https://github.com/dagrejs/dagre) 與 React Flow 整合以建立簡單的樹狀佈局。如果你正在尋找更進階的佈局函式庫，dagre 的良好替代方案包括 [d3-hierarchy](https://github.com/d3/d3-hierarchy) 或 [elkjs](https://github.com/kieler/elkjs)。

這個範例展示_靜態_佈局。如果圖表中的節點或邊線變更，佈局_不會_重新計算！不過，使用 dagre（和其他函式庫）進行動態佈局是可能的：請參閱[自動佈局](/examples/layout/auto-layout)專業版範例以了解相關範例。
