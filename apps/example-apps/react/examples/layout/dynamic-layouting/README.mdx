這個範例建立一個自組織圖表，節點會自動在樹狀結構中定位自己。主要功能包括：

- **節點建立**：使用者不用手動放置或連接節點，而是點擊佔位符元素來加入新節點
- **多個互動點**：透過點擊節點加入子節點、將佔位符轉換為節點，或使用邊線上的「+」按鈕在現有節點之間插入節點
- **智慧佈局演算法**：當圖表變更時，由 `d3-hierarchy` 驅動的自動佈局鉤子會重新計算所有位置
- **平滑過渡**：節點會動畫移動到新位置，即使複雜度增加也能保持視覺清晰度
