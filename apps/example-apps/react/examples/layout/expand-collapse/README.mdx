這個範例展示如何在階層樹狀結構中實作可展開和可收合的節點。有子節點的節點可以透過點擊來展開或收合，顯示或隱藏其後代節點。實作使用自訂的 `useExpandCollapse` 鉤子，它維護完整的圖表結構，同時只渲染當前可見的部分。

<ProExampleViewer slug="expand-collapse" />

### 關於此專業版範例

- 依賴套件：[@xyflow/react](https://www.npmjs.com/package/@xyflow/react)、[@dagrejs/dagre](https://www.npmjs.com/package/@dagrejs/dagre)
- 實作可重複使用的 `useExpandCollapse` 鉤子來處理可見性邏輯
- 展示動態加入節點並自動重新計算佈局
- 使用節點資料屬性來追蹤展開/收合狀態
- 提供互動控制項來展開/收合節點和加入子節點
