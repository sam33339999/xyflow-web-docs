React Flow 在連接過程中會發出不同的事件，你可以用它們以不同的方式更新你的 UI 或流程圖。下面的範例展示哪些事件被觸發以及何時觸發。

對於透過從連接點拖曳建立的**新連接**，以下事件會按順序被呼叫：

- [`onConnectStart`](/api-reference/react-flow#on-connect-start) 接收滑鼠事件和一個包含來源節點、可能的來源連接點 id 以及連接點類型的物件。

- [`onConnect`](/api-reference/react-flow#on-connect) 只在連接被釋放到[可連接](/api-reference/components/handle#is-connectable)的連接點時被呼叫。它接收一個完整的[連接物件](/api-reference/types/connection)，包含來源和目標節點，以及來源和目標連接點 id（如果存在）。

- [`onConnectEnd`](/api-reference/react-flow#on-connect-end) 在連接被釋放時被呼叫，無論是否成功。它接收滑鼠事件。

當透過拖曳現有邊線來**重新連接**邊線時，以下事件會按順序被呼叫：

- [`onReconnectStart`](/api-reference/react-flow#on-reconnect-start) 在[可重新連接的邊線](/api-reference/types/edge#reconnectable)被拾起時被呼叫。它接收滑鼠事件、正在重新連接的邊線物件以及穩定連接點的類型。

- [`onConnectStart`](/api-reference/react-flow#on-connect-start) 如上所述被呼叫。

- [`onReconnect`](/api-reference/react-flow#on-reconnect) 在邊線被釋放到[可重新連接](/api-reference/types/edge#reconnectable)的連接點時被呼叫。它接收舊的[邊線物件](/api-reference/types/edge)和新的[連接物件](/api-reference/types/connection)。

- [`onConnectEnd`](/api-reference/react-flow#on-connect-end) 如上所述被呼叫。

- [`onReconnectEnd`](/api-reference/react-flow#on-reconnect-end) 在邊線被釋放時被呼叫，無論重新連接是否成功。它接收滑鼠事件、被拾起的邊線以及穩定連接點的類型。
