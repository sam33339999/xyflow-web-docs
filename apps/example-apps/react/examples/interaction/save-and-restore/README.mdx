---
title: 儲存和還原
description: 儲存圖表的狀態，並在重新整理頁面後重新載入
---

如果你想儲存和還原流程圖，可以使用 React Flow 實例的 [`toObject` 函式](/api-reference/types/react-flow-instance#to-object)或你的本地節點和邊線狀態。
在這個範例中，你可以移動節點、加入節點並儲存圖表。然後重新載入頁面並點擊還原來還原你的圖表。
