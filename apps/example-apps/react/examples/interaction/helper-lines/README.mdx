這個範例展示如何實作對齊輔助線。當你拖曳節點時，這些視覺指引會自動出現，協助節點彼此對齊，同時吸附機制確保精確定位。

實作處理水平和垂直對齊，並正確處理視窗的轉換和縮放，確保即使在縮放或平移時，指引仍然保持準確。
