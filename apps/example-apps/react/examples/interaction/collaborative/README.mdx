這個範例展示如何使用 React Flow 和 [yjs](https://github.com/yjs/yjs) 為多個使用者建立協作圖表。在此圖表中所做的變更對本頁面的所有使用者都是可見的。要查看它的運作，你可以在[另一個分頁](/examples/interaction/collaborative)或另一個裝置或瀏覽器中開啟此頁面。
此範例可以作為建立多使用者流程圖和編輯器的起點。
