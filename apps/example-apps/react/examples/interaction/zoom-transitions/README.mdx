---
title: 縮放過渡
description: 變更視窗縮放或移動時的動畫速度
hidden: true
---

從一個視窗平滑過渡到另一個視窗是內建功能。你可以傳遞 `duration` 選項參數，為每個改變視窗的函式（[`zoomIn`、`zoomOut`、`zoomTo`、`setViewport`、`fitView`、`setCenter`、`fitBounds`](/api-reference/types/react-flow-instance#viewport)）定義動畫持續時間。
