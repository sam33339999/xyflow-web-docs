---
title: 驗證
description: 檢查新連接是否有效且應該加入
---

自訂節點需要至少有一個 [`Handle` 組件](/api-reference/components/handle)才能連接。你可以將驗證函式 [`isValidConnection`](/api-reference/react-flow#isvalidconnection-1) 傳遞給 ReactFlow 組件，以檢查新連接是否有效且應該加入。
