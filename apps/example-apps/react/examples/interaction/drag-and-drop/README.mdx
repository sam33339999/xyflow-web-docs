在這些範例中，我們使用自訂的 Sidebar 組件，在從側邊欄拖曳到 React Flow 畫布時建立新節點。

拖放使用者介面在基於節點的工作流程編輯器中非常常見。
React Flow 畫布外的拖放行為不是內建的，但可以透過原生 [HTML 拖放 API](https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API)、[指標事件](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)或第三方函式庫如 [react-draggable](https://github.com/react-grid-layout/react-draggable) 來實作。

## 使用 HTML 拖放 API 進行拖放

HTML 拖放 API 是所有主流瀏覽器都支援的原生 API。
這是一個簡單的 API，允許你在頁面上的不同元素之間拖放元素。

**注意：** HTML 拖放 API 在觸控裝置上無法正常支援。

## 使用指標事件進行拖放

實作拖放的另一種方法是使用**指標事件**。

指標事件 API 是所有主流瀏覽器都支援的現代 API。
它的實作比 HTML 拖放 API 稍微複雜一些，但透過使用指標事件，我們可以確保拖放行為在所有裝置（滑鼠和觸控）上都是一致的。

## 使用 Neodrag 進行拖放

[Neodrag](https://github.com/puruvj/neodrag) 是一個提供簡單易用的拖放 API 的函式庫。
在實際應用中，你可能想使用 Neodrag 函式庫以跨平台相容的方式處理拖放行為，同時支援滑鼠和觸控裝置。
