這個範例展示如何為 React Flow 圖表實作復原和重做功能。使用者可以在移動、加入或刪除節點和邊線時追蹤和還原變更。實作使用基於快照的方法，搭配 `useUndoRedo` 鉤子來管理過去和未來的狀態，讓使用者能透過按鈕點擊或鍵盤快捷鍵（Ctrl+Z 和 Ctrl+Shift+Z）來瀏覽編輯歷程。
