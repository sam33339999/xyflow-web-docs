---
title: 重新連接邊線
description: 點擊拖曳將現有邊線從一個連接點移動到另一個
---

如果你使用 [`onReconnect` 處理器屬性](/api-reference/react-flow#edges)，可以透過將邊線拖曳到另一個連接點來重新連接。處理器會在邊線被放到新連接點後被呼叫。你可以使用 [`reconnectEdge`](/api-reference/utils/reconnect-edge) 輔助函式來相應地更新邊線狀態。

<RemoteCodeViewer route="examples/edges/reconnect-edge" framework="react" />

有幾個屬性相互作用，以確定邊線是否可更新：

- 預設情況下，[`edgesReconnectable`](/api-reference/react-flow#edgesReconnectable) 設定為 `true`。

- 然而，要讓邊線實際上可拖曳，還需要定義 [`onReconnect`](/api-reference/react-flow#onReconnect) 處理器。

- 個別邊線可以透過設定其 [`updatable`](/api-reference/types/edge#updatable) 屬性來細化或覆寫 [`edgesReconnectable`](/api-reference/react-flow#edgesReconnectable) 屬性。

  - `true` 表示邊線可更新，即使 [`edgesReconnectable`](/api-reference/react-flow#edgesReconnectable)

  - `"source"` 或 `"target"` 表示邊線僅可從來源或目標連接點更新，無論 [`edgesReconnectable`](/api-reference/react-flow#edgesReconnectable) 屬性為何。

  - `false` 表示邊線不可更新，即使 [`edgesReconnectable`](/api-reference/react-flow#edgesReconnectable) 設定為 `true`。
