---
title: 多重連接線
description: 從任何選取的節點同時繪製多條連接線。
---

React Flow 通常一次只允許建立一個連接。這個範例基於[自訂連接線](/examples/edges/custom-connectionline)範例，展示如何同時從任何選取的節點繪製多條連接線。

<Callout type="info">
  注意 `onConnect` 處理器。如果你忘記包含它，即使你選取了多個節點，也只會建立一個連接！
</Callout>

<Callout type="warning">
  這個範例使用特殊的 `internalsSymbol` 來存取節點上你通常不需要存取的屬性。隱藏在此符號後面的屬性沒有與公開 API 相同的穩定性保證，因此請謹慎使用。
</Callout>
