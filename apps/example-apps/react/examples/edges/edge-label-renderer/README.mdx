---
title: 邊線標籤渲染器
description: 將邊線標籤渲染為邊線上方的 div
---

如果你想在邊線內跳出 SVG 世界，可以使用 [`<EdgeLabelRenderer />`](/api-reference/components/edge-label-renderer)。這是一個傳送門組件，讓你可以將邊線標籤渲染為邊線上方的 div。如果你想加入滑鼠互動，需要在標籤上設定 `pointer-events: all`。
