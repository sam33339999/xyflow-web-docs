React Flow 為預設邊線類型提供簡單的內建動畫，但透過使用自訂邊線可以建立更進階的動畫。以下是一系列範例，展示邊線路徑可能被使用的不同方式

## 動畫 SVG 元素

可以使用 `<animateMotion />` 元素沿著路徑動畫 SVG 元素。這個範例建立一個自訂邊線，沿著邊線路徑動畫一個圓形。

<RemoteCodeViewer

  framework="react"
/>

## 動畫其他節點

如果你想沿著邊線動畫更多 SVG 以外的內容，可以使用 Web Animations API。這個範例展示如何透過使用 `offsetPath` 屬性並動畫 `offsetDistance` 屬性，沿著邊線路徑動畫流程圖中的另一個節點。

<RemoteCodeViewer route="examples/edges/animating-edges" framework="react" />

在這個範例中有一些需要注意的重要細節：

- 在動畫執行期間，動畫節點的 [`draggable`](/api-reference/types/node#draggable) 屬性設定為 `false`。這可以防止使用者移動節點並破壞動畫路徑。

- 動畫路徑和動畫本身在不同的 `useEffect` 鉤子中設定。這讓動畫即使在邊線路徑重新計算時（例如當來源或目標節點被拖曳時）也能繼續平滑播放。
