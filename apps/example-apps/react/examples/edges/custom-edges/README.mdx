---
title: 自訂邊線
description: 建立具有特殊路由或邊線控制項的邊線
---

React Flow 提供四種不同的邊線類型 - `default`（貝茲）、`straight`、`step` 和 `smoothstep`。如果你需要特殊的邊線路由或邊線控制項，也可以建立[自訂邊線](/api-reference/types/edge-props)。在這個範例中，我們展示如何實作帶有按鈕的邊線、雙向邊線、自連接邊線。在所有範例中，我們都使用 [BaseEdge](/api-reference/components/base-edge) 組件作為輔助。
