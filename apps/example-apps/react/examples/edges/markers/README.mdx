---
title: 邊線標記
description: 將邊線變成箭頭，加入自訂圖示或 SVG
---

React Flow 內建支援邊線的不同標記類型。你也可以加入自己的 [SVG 標記](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/marker)。

標記被定義為 SVG 元素，因此你可以使用任何你想要的 SVG。
React Flow 邊線渲染器會期望標記定義位於 `<defs>` 元素中。

例如，如果你的自訂邊線包裝了內建的 `<BaseEdge/>` 組件，你可以將 `markerStart` 和 `markerEnd` 屬性傳遞給 `<BaseEdge/>` 組件。
內建的 React Flow 邊線組件會期望 `markerStart` 和 `markerEnd` 屬性的格式為 `"url(#markerId)"`，其中 `markerId` 是你的標記定義的 ID。

這讓你可以根據邊線的狀態，為特定邊線自訂標記。
