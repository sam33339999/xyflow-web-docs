title: 父子關係
description: 透過拖放功能動態地將節點附加到父容器或分離
is_pro_example: true
---

這個範例展示如何在節點之間動態建立父子關係。你可以將節點拖曳到群組節點上以將其附加為子節點，並使用工具列的「分離」按鈕來移除它。實作處理了將絕對位置轉換為相對於父節點的座標時所需的複雜位置計算。
