這個範例展示如何在 React Flow 中建立動態節點群組。你可以透過按住 Shift 並點擊來選取多個節點，然後使用出現的工具列中的「群組節點」按鈕將它們群組在一起。當選取群組節點時，會出現「取消群組」按鈕，可分離所有子節點。群組節點完全可調整大小，並會根據其子節點自動調整尺寸。
