---
title: 節點工具列
description: 選取節點時會在旁邊顯示帶有按鈕的工具列
---

對於許多類型的應用程式來說，在選取節點時顯示工具列或一組控制項非常有用。事實上，它非常有用，所以我們建立了 [`<NodeToolbar />`](/api-reference/components/node-toolbar) 組件，讓你可以輕鬆地將此功能加入到自訂節點中！

<Callout type="info">
  工具列中的內容不會隨著流程圖的縮放而縮放：這表示它應該始終保持可見。
</Callout>
