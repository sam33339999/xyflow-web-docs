這個範例展示如何渲染具有流程圖中常用形狀的[自訂節點](/learn/customization/custom-nodes)，如圓形、菱形或六邊形。它還展示如何建立側邊欄組件、自訂縮圖節點，以及用於變更形狀顏色的節點工具列。

此範例使用集中式的 Shape 組件，根據形狀類型渲染不同的 SVG 路徑。透過定義節點資料如 `{ type: 'shape', data: { type: 'diamond', color: '#ff0071' }}`，你可以控制要渲染哪個形狀以及其外觀，同時只使用單一節點類型實作。
