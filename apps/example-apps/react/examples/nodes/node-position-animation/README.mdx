這個範例展示如何在不同的圖表佈局之間建立流暢的動畫過渡。當你點擊「切換佈局」按鈕時，節點會平滑地動畫移動到新位置，創造出一種視覺上吸引人的方式來切換不同的排列。

<ProExampleViewer variant="dark" slug="node-position-animation" />

### 關於此專業版範例

- 依賴套件：[@xyflow/react](https://www.npmjs.com/package/@xyflow/react)、[d3-timer](https://www.npmjs.com/package/d3-timer)
- 實作可重複使用的 `useAnimatedNodes` 鉤子，用於平滑過渡
- 使用線性插值來動畫節點位置
- 展示水平和垂直佈局之間的位置補間
- 提供簡單的切換控制項來切換不同的佈局
- React Flow 從版本 12 開始支援伺服器端渲染
