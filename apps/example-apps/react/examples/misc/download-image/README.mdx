這個範例展示如何使用 [html-to-image](https://github.com/bubkoo/html-to-image) 將流程圖下載為圖片。

<Callout type="info">
  此範例中使用的 [html-to-image](https://www.npmjs.com/package/html-to-image) 套件 `version` 已鎖定為 `1.11.11`，這是該套件最新的可用 `version`。`1.11.11` 之後的近期版本無法正確匯出圖片，Github 上有相關的公開 [issue](https://github.com/bubkoo/html-to-image/issues/516)。
</Callout>
