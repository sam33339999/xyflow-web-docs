這個範例展示如何在伺服器端建立 React Flow 圖表的靜態圖片。應用程式讓你在螢幕左側與節點互動，同時自動生成並在右側顯示相應的流程圖圖片。實作使用 React Flow 的新靜態渲染功能結合 Puppeteer 來擷取螢幕截圖。

<ProExampleViewer slug="server-side-image-creation" />

### 關於此專業版範例

- 依賴套件：[@xyflow/react](https://www.npmjs.com/package/@xyflow/react)、[express](https://www.npmjs.com/package/express)、[puppeteer](https://www.npmjs.com/package/puppeteer)、[react](https://www.npmjs.com/package/react)、[react-dom](https://www.npmjs.com/package/react-dom)、[zustand](https://www.npmjs.com/package/zustand)、[cors](https://www.npmjs.com/package/cors)
- 展示 React Flow 的伺服器端渲染功能（自 v12 起可用）
- 包含完整的後端實作以生成圖片
- 提供 Dockerfile 配置以進行容器化部署
