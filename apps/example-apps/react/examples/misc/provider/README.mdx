---
title: ReactFlowProvider
description: 在頁面上使用多個流程圖時，讓每個流程圖都有獨立的儲存實例
hidden: true
---

如果你在頁面上使用多個流程圖，或者正在使用客戶端路由器，你需要用 [`ReactFlowProvider`](/api-reference/react-flow-provider) 包裝每個流程圖，以便每個流程圖都有自己的儲存實例。
如果你想在 `ReactFlow` 組件外部存取內部狀態，也必須使用 `ReactFlowProvider`。
