這個範例展示如何建立橡皮擦工具，讓你可以透過擦拭來刪除節點和邊線。
它由兩個部分組成：

1. `Eraser` 組件，處理擦除邏輯和橡皮擦軌跡的渲染。
2. 自訂的 `ErasableNode` 和 `ErasableEdge`，對 `toBeDeleted` 標記做出反應。

判斷軌跡是否與節點相交相當直接，但檢測軌跡與邊線之間的相交則更為複雜：
我們透過 SVG 路徑元素的 [`getPointAtLength`](https://developer.mozilla.org/en-US/docs/Web/API/SVGGeometryElement/getPointAtLength) 方法沿邊線採樣點，
建構一條折線，然後可以用它來檢測與橡皮擦軌跡的相交。
這是效能和準確性之間的權衡 - 你可以調整 `sampleDistance` 變數來觀察它對橡皮擦軌跡的影響。
