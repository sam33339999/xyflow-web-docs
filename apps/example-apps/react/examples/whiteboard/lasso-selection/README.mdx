title: 套索選取
description: 使用套索選取工具選取多個項目的範例。
created_at: 2025-06-18
---

在這個範例中，你可以使用套索選取工具在畫布上選取多個項目。點擊並拖曳以建立選取區域，區域內的所有項目都將被選取。

- **套索繪製**：使用滑鼠事件繪製自由形狀的選取區域
- **部分/完整選取**：切換選取套索部分包圍或完全包圍的節點
- **視覺回饋**：繪製選取區域時提供即時視覺回饋
- **Canvas 渲染**：使用 HTML5 Canvas 實現流暢的繪製效能
