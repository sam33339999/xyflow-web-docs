這個範例展示如何在你的 React Flow 應用程式中實現手繪功能。使用者可以在畫布上繪製平滑的曲線，這對於標註或在現有節點周圍繪製草圖很有用。繪製的內容會轉換成自訂節點，可以像一般節點一樣進行樣式設定和操作。
